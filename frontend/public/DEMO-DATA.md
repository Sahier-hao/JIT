# 演示数据来源

`demo-dataset.json` 版本 `demo-v1`，虚构项目“演示项目”，12条人工编写的固定记录。提交标识、日期、标题、风险、变更度量和解释都不来自真实仓库或模型；不包含缺陷标签、SZZ证据或模型贡献值。

包含同风险同时间排序、0/1风险边界、缺失风险、缺失变更量、缺失文件数、缺失解释、UTC跨上海日界线等场景。非法风险、坏来源、重复标识与加载失败由测试替换读取边界，不能从产品菜单开启。

字段 `lines` 表示示例新增行与删除行之和，`files` 表示示例修改文件数。度量只展示存在的条目，不构成已验证的 Kamei14 数据集。版本变化隔离浏览器清单；不运行随机生成或假训练。
