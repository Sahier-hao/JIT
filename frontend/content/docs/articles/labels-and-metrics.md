JIT 的“标签”是后续修复证据，不是人工看代码后直接贴上的“有缺陷”标记。评估必须在观察期、标签状态和分区边界都明确时才有意义。

## 提交的标签状态 {#label-states}

| 页面状态 | 含义 | 能否进入正式评估 |
| --- | --- | --- |
| 有引入证据 | 后续修复回溯到当前提交 | 可作为可靠正例 |
| 观察期内未发现 | 观察期已满，未发现修复证据 | 可作为可靠负例 |
| 观察期未满 | 还要等待后续修复窗口 | 排除 |
| 观察覆盖未知 | 不知道标签是否成熟 | 排除 |
| 未评分 | 模型没有为该提交输出分数 | 不能按 0 分处理 |

“观察期内未发现”不是“确认无缺陷”，而是在声明窗口和证据规则下没有观察到修复证据。“观察期未满”不能提前写成负例。

## 观察期和标签成熟度 {#maturity}

采集数据时会固定样本窗口、修复观察窗口和数据 revision。观察截止可以晚于样本截止，因此后续修复能为旧提交补充证据，但未来提交不能进入当前提交的特征。

成熟度回答的是：对每个候选负标签，是否已经给它足够时间暴露后续修复。标签成熟策略和观察声明会随数据版本保存。缺少成熟度记录的旧数据可能仍可评分，但不能安全进入新训练或正式评估。

同一时间规则需要同时应用于正例和未观察样本。只给负例加观察期、却允许正例提前进入，会改变评估口径。

## 缺陷阈值与两个风险分档 {#thresholds}

页面上有两类容易混淆的数字：

- **缺陷阈值**：在模型评估中使用，默认 `0.50`，可按 `0.01` 调整，用来把分数分成告警与不告警，计算命中、误报、漏报、Precision、Recall 和 F1。
- **分档阈值**：项目风险分布使用 `0.25` 和 `0.10`，把提交分成高、中、低三档。它们不是同一个评估阈值。

`0.25` 以上的“高风险提交”不代表真实缺陷率。缺陷阈值只适用于当前保存分数、标签和评估来源；调阈值不会重新调用模型。

## 评估指标各自回答什么 {#evaluation-metrics}

在固定标签和阈值下：

| 指标 | 计算 | 回答的问题 |
| --- | --- | --- |
| 告警 | TP + FP | 多少样本会被安排检查 |
| 命中 | TP | 多少真实正例被提醒 |
| 误报 | FP | 多少告警没有真实正例标签 |
| 漏报 | FN | 多少真实正例没有被提醒 |
| Precision | TP / (TP + FP) | 告警中有多少命中 |
| Recall | TP / (TP + FN) | 真实正例中找回多少 |
| F1 | Precision 与 Recall 的调和平均 | 两个指标的平衡 |

没有可靠正例或负例时，页面不能生成正式 Precision、Recall 或 F1，也不会把 0 伪装成指标。图表必须与等价表格使用同一模型、分区、阈值和样本数。

训练实验中的测试集 AP、ROC-AUC 等指标回答“模型在冻结分区上的整体排序或分类表现”；阈值工作点回答“在这个审查预算或阈值下会告警多少”；趋势视图回答“同口径已保存结果随时间如何分布”。三者不能互换。

## 正式评估与探索性复核 {#formal-vs-exploratory}

训练来源的评估先在验证集探索缺陷阈值，再在未被用于调参的冻结测试集固定复核。预测批次只有在来源声明固定测试分区、包含可靠正负标签，并且在查看测试结果前确定阈值时，才可标为正式评估。

以下情况通常是探索性复核：

- 批次没有固定测试分区。
- 标签未成熟、未知或缺失。
- 只有单一类别标签。
- 手工填写特征的单条结果。
- 旧批次未保存可靠标签资格。

探索性复核仍可用于核对保存分数，但不能宣称为冻结测试集正式表现。

## 当前仓库结果和模型质量 {#repo-results}

项目分析中的“平均风险分”“高分占比”“优先回查提交”只描述当前固定分析和当前模型输出：

- 不证明项目真实缺陷率。
- 不证明模型比其他模型更好。
- 不证明低分提交安全。
- 未评分和未覆盖必须单独显示。

评价模型是否发布时，需要看冻结测试分区、标签资格、基线比较和人工发布决定。模型卡片上的收益指标与当前项目的一次分析不是同一件事。

## 未覆盖、未评分和标签不足 {#uncovered}

| 情况 | 页面应当表现 | 不能怎么做 |
| --- | --- | --- |
| 提交未评分 | 显示未评分或未知 | 当成 0 分 |
| 分析范围未完整加载 | 说明覆盖和缺失 | 宣称完整分布 |
| 标签观察期未满 | 排除并显示数量 | 提前算正式指标 |
| 缺少可靠正负例 | 正式评估不可用 | 用 0 填指标 |
| 趋势样本不足 | 比例不可用 | 画成没有风险 |

理解分数本身见[怎么看风险分和代码线索](#/docs/reading-results?section=commit-score)；理解训练和评估入口见[从数据到训练、预测与评估](#/docs/data-training-evaluation?section=evaluation)。
