# JIT 缺陷预测 · 提交评审

面向评审员的桌面课程项目：从提交的模型风险出发，查看原始改动度量并维护个人优先审查清单。数据来源有三类：公开历史数据集回放、明确的人工演示，以及从公开 Git 仓库同步采集的提交。

仓库同步在「数据来源」页发起：填写公开 HTTP(S) 地址、分支、日期范围与提交上限，后台依次完成采集、登记、训练（或按数据量降级到通用模型）与打分；完成后在「提交工作台」按这次同步查看风险列表与 14 个原始特征。采集使用简化 SZZ 倒推标签，最新提交没有标签，风险只是估计。
