# 覆盖率与运行证据

- `backend-coverage.html/`、`frontend-coverage.html/`：coverage.py 与 Vitest 生成的交互式 HTML。
- `backend-coverage.pdf`、`frontend-coverage.pdf`：coverage.py 原始英文界面快照，仅作底稿。
- `backend-junit.xml`、`frontend-results.json`：原始测试结果。
- `backend-coverage.json`、`frontend-coverage-final.json`：机器可读覆盖率。
- `report-zh.html`、`report-zh.pdf`、`report-zh.png`：中文提交版报告。
- `report.md`、`report.json`：中文 Markdown 报告与机器可读报告；人工复核未完成时状态为未通过。
- `clean-checkout.json`、`clean-checkout-report.*`：隔离副本运行证据。
