# 设计：统一工作区控件与状态表面

## Context

工作区已经有两套并存的表面：审查队列与 PR 工作单使用重建后的三栏布局与统一组件，其余页面仍保留改版前的原生控件与页面级分隔线。用户在项目详情页与审查抽屉里直接看到浏览器原生的复选框、数字输入和文件选择，与相邻的新组件在高度、边框、焦点环上不一致。

主题变量集中在 `frontend/src/styles/tokens.css`，antd 通过 `frontend/src/ui/AntdProvider.tsx` 读取这些变量，所以两套表面可以共享同一组色值。

## Goals / Non-Goals

- 目标：同一动作在全站使用同一种控件与层级；主按钮色与产品既有主操作一致；抽屉内不再出现页面级分隔线；原生文件选择控件完全隐藏。
- 非目标：不重做项目详情页与管理区的信息结构，不改动后端契约，不引入新的视觉主题。

## Decisions

- **主按钮取深墨色而非强调绿。** 产品原有的主要操作（打开审查、开始分析、新建项目）是深墨色，强调绿只用于选中态、链接与状态点。antd 的 `colorPrimary` 因此绑定 `--btn`，`colorLink`、`colorSuccess` 保留 `--accent`。
- **两个汉字的按钮关闭自动空格。** antd 默认在「刷新」这类两字按钮中间插入空格，可访问名称随之变成「刷 新」。在 `ConfigProvider` 的 `button` 配置里关闭，并对刷新按钮单独声明，避免依赖上下文。
- **隐藏文件输入由 `[hidden]` 兜底。** 旧样式表里有一条 `.pr-backups input[type=file] { display: block }`，作者样式的优先级高于浏览器对 `hidden` 属性的默认规则，导致隐藏失效。删除该规则并在 `base.css` 增加 `[hidden] { display: none !important }`。
- **抽屉内的区块改用局部间距。** `.pr-delivery/.pr-backups/.pr-feedback` 原本为页面内联区块设计，带 35px 上外边距与顶部分隔线；在抽屉里会留下一段空白与一条孤立横线。改为只在抽屉内去掉顶部分隔线，反馈区块保留一条分隔线。
- **数据版本用折叠面板。** 原生 `<details>` 的三角标记在各浏览器表现不一致，改用统一折叠面板，展开状态与其它设置项一致。

## Risks / Trade-offs

- 关闭两字按钮空格后，部分场景的中文按钮看起来更紧凑；这是与产品既有按钮一致的取舍。
- 抽屉内样式通过 `.ant-drawer` 前缀限定，若以后把同样的区块移回页面，需要恢复页面级间距。

## Migration Plan

不涉及数据迁移。旧的草稿备份、计划备份与反馈导出文件格式保持不变，仍可直接导入。
