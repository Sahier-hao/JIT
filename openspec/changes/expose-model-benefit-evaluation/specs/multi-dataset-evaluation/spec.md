## ADDED Requirements

### Requirement: MDE-08 冻结测试分区上的审查收益评估

系统 SHALL 在冻结测试分区上以只读方式评估模型审查收益，不重新训练、不使用测试分区调参。评估 MUST 在相同标签、成本与 20% LOC 预算下比较模型分数、时间顺序和固定种子随机顺序，复用 Recall@20%LOC、Popt 与 IFA。报告 MUST 记录样本量、正例数、随机次数与种子、均值/波动、模型与运行身份、参数选择说明、标签限制和文件校验值。缺失或条件不足的指标 MUST 显示为未定义及原因，MUST NOT 以零代替；MUST NOT 把风险分数表述为缺陷概率或据此宣布最佳模型。

#### Scenario: 固定种子可复现

- **WHEN** 使用同一产物、随机次数和种子重复评估
- **THEN** 策略结果、结论与样本统计一致，只有生成时间变化

#### Scenario: 模型帮助有限

- **WHEN** 模型排序的 Recall@20%LOC 低于时间或随机顺序
- **THEN** 报告和界面如实显示不利结果，不通过改参数或更换测试数据掩盖

#### Scenario: 指标条件不足

- **WHEN** 测试分区没有正例、总工作量为零或存在零成本提交
- **THEN** 对应指标返回未定义与原因，不写成 0

#### Scenario: 标签解释

- **WHEN** 报告使用发布者观测或简化 SZZ 标签
- **THEN** 报告写明标签限制，使用「历史标记」而不是「已确认缺陷」
