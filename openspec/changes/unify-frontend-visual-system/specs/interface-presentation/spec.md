# Spec Delta

## ADDED Requirements

### Requirement: IP-29 界面样式的单一来源

界面 SHALL 由一套共享设计令牌、工具类和组件层实现外观。页面 MUST 复用共享组件与工具类，MUST NOT 为单个页面引入会覆盖其他页面的样式层；第三方内容（代码差异、Markdown、图表）的样式 MUST 限定在其容器内。

#### Scenario: 新增页面不引入第二套样式

- **WHEN** 新增页面或区块
- **THEN** 只组合共享组件与工具类，不新增页面级样式表，四种主题下外观与既有页面一致

#### Scenario: 第三方内容不泄漏

- **WHEN** 在页面中嵌入代码差异、Markdown 或图表
- **THEN** 容器外的排版、颜色与间距不受影响，四种主题下均如此

#### Scenario: 样式来源可追溯

- **WHEN** 核对任一页面的外观来源
- **THEN** 可追溯到共享组件与设计令牌，仓库中不存在无人引用的页面样式层

### Requirement: IP-30 统一的视觉基线与表面层级

界面 SHALL 以统一的字号、行高、间距、圆角与阴影档位呈现同一层级的内容：页面标题、区块标题、正文、元信息与表格数字在各页面使用相同档位；页面底色、下沉区、卡片与强调面保持可辨且层级一致。密度切换 MUST 只调整间距，不改变字号档位的语义。

#### Scenario: 同一层级跨页面一致

- **WHEN** 比较项目、审查、报告与管理页面中同层级的标题、正文和元信息
- **THEN** 字号、行高、字重与间距处于同一档位，没有页面自成一格

#### Scenario: 表面层级可辨

- **WHEN** 查看包含页面底、下沉区、卡片与选中态的页面
- **THEN** 各层表面与边界可区分，同一层级在不同页面的处理一致

#### Scenario: 密度切换保持档位

- **WHEN** 在默认与紧凑密度之间切换
- **THEN** 行距与内边距变化，字号档位与语义不变，主要文字仍满足可读性下限

### Requirement: IP-31 管理工作区共享用户工作区的控件语言

管理工作区 SHALL 与用户工作区使用同一套按钮、输入、选择、对话框、表格、卡片、标签与空状态形态。独立外壳 MUST 只体现分区与导航，不得引入第二套视觉语言；相同操作与状态在两个工作区呈现相同的形状、尺寸档位与反馈。

#### Scenario: 同一操作跨工作区一致

- **WHEN** 分别在用户工作区与管理模型、数据页面执行主操作、危险操作与筛选
- **THEN** 控件的形状、尺寸、悬停与聚焦反馈一致

#### Scenario: 列表与空状态一致

- **WHEN** 查看项目、分析记录与管理端模型、数据、训练列表
- **THEN** 表头、行高、分隔线与空状态结构一致，密度切换同时作用于两处

#### Scenario: 对话框结构一致

- **WHEN** 打开用户工作区与管理端的确认、表单或详情对话框
- **THEN** 标题区、关闭方式与底部操作区结构一致
