# 设计：收敛重复入口与隐式状态变更

## Context

2026-11-08 的系统审查（`docs/审计/2026-11-08-system-duplication-review.md`）确认：用户可见的重复入口集中在项目分析、PR 审查和管理训练三条流程；实现层的重复集中在取数、路由构造、错误文案与标签常量。本变更只处理用户可见、可独立验证的部分，并把“动作后果可见”写成展示层要求，防止同类问题再次出现。

## Goals / Non-Goals

**Goals**

- 每个会改变全局状态或写入个人草稿的动作，在可见文案中说明后果。
- 同一对象在同一流程中只保留一个规范入口；其他入口必须带上下文。
- 去掉一处隐式的分析记录行切换、一处右栏复制、一处双控件写同一状态。
- 修正按模块查询提交时的版本条件。

**Non-Goals**

- 不迁移全部读取到 react-query，不合并三套后端任务引擎，不删除退役端点。
- 不重做视觉主题，不调整模型评分、分析结果或训练产物。
- 不合并 `/models/register` 与 `/experiment-runs/promote` 的后端语义；本次只让入口文案可区分并补跳转。

## Decisions

1. **记录行切换仍保留整行点击**：`IP-20` 要求非当前记录整行可点击并切换当前结果，因此不改交互模型，只把非当前记录的可见标题从状态词改为“设为当前结果”，状态移到元信息；切换成功后由项目页显示一条 `role=status` 的提示，菜单保留同名入口。
2. **创建分析入口**：页头的 `AnalysisLauncher` 是唯一创建入口；概览右上只在已有结果时显示“查看分析结果”，删除“发起第一次分析”和底部重复 callout。项目卡片文案与去向对齐为“打开项目”。
3. **数据集构建完成**：保留跳转管理工作区的现有链路，按钮文案改为“进入管理工作区查看并训练”，并加一行必要说明“需要管理员会话；不会自动训练”。不新增用户侧数据集详情页。
4. **轮询**：`RepositoryUpdates` 的职责是检查远端仓库更新，不是分析进度，改为固定 15 秒；`useRepository` 与 `useRepositorySyncs` 的合并留到后续实现债批次，避免本次同时改读取模型。
5. **提交查询**：`count_by_entity` / `commits_by_entity` 增加可选 `dataset_version` 条件，`/api/v1/commits` 始终传入请求的 `version`；模块过滤不再跨版本聚合。
6. **PR 右栏**：`recordRows` 改为只包含“分析中 / 需处理失败 / 尚无分析”的 PR，标题改为“待处理 PR”；为空时显示“没有待处理 PR”。左栏仍是唯一完整清单。
7. **训练后续入口**：训练任务详情在成功态提供“查看实验登记”（按未登记、完整产物筛选）与“查看模型”（已登记时）链接；模型管理页的登记按钮文案改为“登记本机产物”，与实验登记页的“登记实验运行”区分。
8. **PR 只读模式**：`pr-work` 路由增加 `mode=preview`；工作单头部提供“查看只读版本”。只读模式即使已有工作单也渲染 `PullRequestPreview`，但“创建审查工作单”在已有工作单时改为“进入工作单”。固定快照页的合并留到后续批次。
9. **趋势来源**：主表单只保留“来源范围”下拉；自由输入“单次固定分析”收进“手动指定分析”折叠项。手填值与下拉不一致时给出提示并允许清除。
10. **模型比较**：删除选择器旁无可见效果的“比较”按钮（选择后自动加载）。从模型详情“加入比较”只带一个模型时，第二选择留空并提示“请选择模型 B”，不再自动挑对手。
11. **时间语义**：分析栏左侧文案改为“当前审查所用结果”；当当前结果不是最近一次成功分析时，在结果标题旁加“历史固定结果”标签。

## Risks / Trade-offs

- 记录行仍整行切换当前结果，标题改为动作词后需要确认状态词在元信息中仍可读；切换提示不能遮挡列表或改变卡片高度。
- 删除概览底部 callout 后，空状态少一个显眼按钮；页头与概览右上的入口仍在，需在验收中确认可发现性。
- 右栏改为待处理子集后，用户不能再从右栏浏览全部已完成 PR；左栏完整清单保留，且右栏不再重复。
- 预览模式增加一个地址参数，旧链接不带参数时行为不变。
- 训练任务链接依赖现有查询参数；若筛选参数与后端不完全匹配，退化为不带筛选的实验登记列表，不伪造条目。
