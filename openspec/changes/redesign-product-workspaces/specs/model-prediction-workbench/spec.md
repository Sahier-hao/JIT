# Spec Delta

## MODIFIED Requirements

### Requirement: MPW-01 独立可达的模型与预测入口

系统 SHALL 在实验室中提供独立可达的模型目录、手工特征预测、历史验证与按批次重开入口，不依赖仓库或历史批次先成功加载。手工预测 MUST 被明确命名，与仓库自动采集分析区分。既有来源、详情、保存结果与清单隔离规则继续有效；不能为了收拢导航删除已实现能力或让其他空间的失败阻塞当前任务。

#### Scenario: 历史服务失败时使用新页面
- **WHEN** 历史批次不可用而目录服务可用
- **THEN** 用户仍可打开实验室模型与手工预测，历史错误不自动切换演示或阻止目录使用

#### Scenario: 返回旧工作台
- **WHEN** 从实验室模型/预测返回历史验证、演示或原仓库工作区
- **THEN** 对应来源与清单/计划按各自规则恢复，新预测记录不混入仓库、历史或示例提交

### Requirement: MPW-02 凭据输入与服务端权限反馈

系统 SHALL 在连接设置提供掩码凭据输入和清除入口，并允许受保护页面带返回目标进入。凭据仅在当前页面运行期内存使用，不写入 URL、持久存储、日志、导出或证据。受保护请求 MUST 服务端鉴权；无凭据不自动发送，自报角色不能解锁操作。401、403 和配置失效分别提供反馈，公开历史数据无需该凭据。

#### Scenario: 输入凭据并清除
- **WHEN** 从目标页面进入设置输入有效凭据，随后清除或刷新整个页面
- **THEN** 输入后可返回同一目标并在导航期间使用凭据；清除/刷新后需重新输入，旧受保护内容不作为已授权数据展示，链接只保留非秘密对象身份

#### Scenario: 成员打开登记入口
- **WHEN** 合法成员访问登记操作而服务返回 403
- **THEN** 显示需要管理员权限，不展示候选或发起登记；成员仍可使用有权限的模型和预测功能

#### Scenario: 认证或服务器配置失败
- **WHEN** 服务返回 401 或 ACCESS_CONFIG_INVALID
- **THEN** 分别提示重新输入或联系维护者，不称为模型空列表，不泄露凭据值

## ADDED Requirements

### Requirement: MPW-12 实验室资源与真实能力对应

实验室 SHALL 只展示实际可读取的历史运行、已登记模型、受控候选和已保存批次；只有一个历史运行时不制造多运行选择器。评价与分区必须绑定同一数据、运行与模型；缺失时说明未提供。打开保存结果 MUST 保持只读，不因模型当前不可用而重算。训练平台、全量预测历史、自动模型排名等未实现能力 MUST 不由静态样例冒充。

#### Scenario: 模型无评价或历史运行单一
- **WHEN** 目录模型没有可用测试摘要，或系统只提供一个固定历史运行
- **THEN** 显示真实模型与未提供评价的原因，历史验证直接呈现该运行，不生成原型里的候选评估数字或虚假运行列表

#### Scenario: 三类模型任务完整保留
- **WHEN** 管理员登记已有候选，成员完成六字段预测并按旧或新 batchId 链接重开
- **THEN** 仍分别经过既有准入、真实推理与保存结果查询契约，结果来源、支持解释和不可变内容继续可核对
