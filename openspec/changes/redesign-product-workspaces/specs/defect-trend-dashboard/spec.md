# Spec Delta

## MODIFIED Requirements

### Requirement: DTD-01 趋势视图独立可达

系统 SHALL 在实验室的历史验证中提供独立可达的趋势视图，不要求先打开仓库工作区或输入团队凭据。趋势与历史提交回放 MUST 使用同一运行摘要；页面始终标明公开历史来源，不能沿用当前仓库名暗示为仓库趋势。缺少仓库趋势数据时 MUST 如实说明，不能借用历史图表代替。

#### Scenario: 不经工作台直接进入趋势视图
- **WHEN** 用户直接打开新的历史趋势地址或旧趋势兼容地址
- **THEN** 无需成功加载仓库与团队凭据即可查询该历史运行；失败时有可公开原因与重试入口，不自动切换演示

#### Scenario: 返回既有工作台
- **WHEN** 用户从历史趋势返回原仓库或历史提交视图
- **THEN** 返回目标的模式、分析身份、计划、筛选与详情按各自上下文恢复，历史趋势不重置当前仓库

### Requirement: DTD-07 时间桶下钻到提交工作台

系统 SHALL 让历史时间桶下钻到同一历史运行的提交回放，并以桶范围作为初始日期筛选，MUST NOT 下钻到当前仓库。范围按桶自身起止时刻及界面时区换算并包含两端；结束为下一段起点时不能纳入下一段首日。文本视图的下钻操作 MUST 可由键盘到达，稀疏桶同样可下钻，并保留运行与来源身份。

#### Scenario: 下钻得到该桶的范围
- **WHEN** 用户对含记录的历史桶触发下钻
- **THEN** 同一历史运行的提交回放按对应起止日筛选，两端包含当天，不含结束后的首日，也不切换当前仓库分析

#### Scenario: 稀疏桶仍可下钻
- **WHEN** 用户对样本不足且没有风险点的桶下钻
- **THEN** 同一运行的历史提交仍按该范围查询，不因缺少统计量拒绝下钻或改用其他运行

#### Scenario: 仅用键盘完成下钻
- **WHEN** 用户用键盘到达文本视图中的桶下钻操作并触发
- **THEN** 进入同一历史运行的回放，来源、日期范围与焦点状态可读，返回时原仓库或历史状态仍可恢复
