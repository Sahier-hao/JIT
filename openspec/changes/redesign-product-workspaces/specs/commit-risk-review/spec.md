# Spec Delta

## MODIFIED Requirements

### Requirement: CRR-01 演示来源可识别

系统 SHALL 在列表、详情和审查计划中持续展示来源性质、项目与数据版本。仓库审查与实验室中的历史回放、人工演示 SHALL 使用各自明确入口，不混排。仓库结果 MUST 绑定成功分析并披露实际分支、完成时间与模型；历史数据 MUST 展示运行与回顾性限制；示例分数与解释 MUST 标为示例。切换来源必须由用户明确触发，不得静默替换。

#### Scenario: 查看演示工作台
- **WHEN** 用户从实验室的演示入口进入任一主要视图
- **THEN** 项目、数据版本和演示标识可见，分数与解释的示例性质明确，不冒充真实模型成果

#### Scenario: 来源信息不完整
- **WHEN** 演示数据缺少项目标识或版本等必需来源信息
- **THEN** 显示数据不可用反馈，不以猜测的项目或版本继续展示

#### Scenario: 查看真实历史回放
- **WHEN** 用户在历史验证中打开合法的真实模型测试批次
- **THEN** 来源、项目、数据版本、运行与模型可见，分数来自该运行
- **AND** 提示标签来自历史观测、尚未验证历史当时标签可获得性，不宣称实时效果或完整课程验收

#### Scenario: 查看仓库同步工作台
- **WHEN** 用户打开仓库的成功分析
- **THEN** 仓库、该分析实际分支、完成时间、数据版本与模型可核对
- **AND** 新提交尚无可验证标签、分数不等于已确认缺陷的边界可见，不用公开数据集指标描述该仓库效果

#### Scenario: 手动切换模式
- **WHEN** 用户切换仓库分析，或在工作区与实验室的来源间往返
- **THEN** 列表、详情、计划及摘要只接受目标对象和当前凭据上下文的结果
- **AND** 旧请求迟到不能覆盖当前内容，加载或错误状态下仍可选择其他明确入口

### Requirement: CRR-03 风险值边界明确

系统 SHALL 将有限且位于闭区间 [0,1] 的值作为模型分数展示，列表、详情与保存结果使用相同的小数表达并可核对原始精度。未经校准 MUST NOT 表述为缺陷发生概率。缺失值显示暂无预测，非有限或越界值显示风险数据无效，不能改写为零、截断或用于断言缺陷。观测比例和既有评估指标仍按其各自单位展示。

#### Scenario: 合法风险值包含边界
- **WHEN** 分数为 0、1 或区间内的有限数值
- **THEN** 统一展示 0.00、1.00 或对应小数，并明确这是模型分数，底层保存值不因格式化改变

#### Scenario: 缺失或无效风险值
- **WHEN** 分数缺失、非有限或不属于 [0,1]
- **THEN** 显示对应文字反馈，不提供虚假的合法分数或概率

### Requirement: CRR-04 提交标识搜索

系统 SHALL 支持完整提交标识与标题的片段搜索，忽略输入首尾空白和标识大小写；仓库模式 MUST 在所选成功分析的服务端全集查询。清空搜索 SHALL 恢复满足其他筛选条件的提交。搜索 MUST 不改变提交数据、分析身份或审查计划，不能把仅过滤当前页显示为全量搜索。

#### Scenario: 搜索并清空
- **WHEN** 输入带首尾空白的提交标识或标题片段，随后清空
- **THEN** 先得到所选分析内的匹配集合，再恢复符合其他筛选条件的列表

#### Scenario: 没有匹配项
- **WHEN** 搜索没有命中
- **THEN** 显示无匹配及清除筛选入口，不称为加载失败；详情不继续显示不属于当前结果的条目

### Requirement: CRR-06 确定性排序

系统 SHALL 默认按合法分数降序、提交时间降序、完整 ID 升序排序，缺失或无效分数置于最后。时间排序 SHALL 按提交时间降序、完整 ID 升序确定，不在同秒插入隐藏风险排序。改变排序 MUST 不改变提交身份、已选详情或审查计划，跨页规则与服务端一致。

#### Scenario: 风险同分及暂无预测
- **WHEN** 列表包含同分、不同时间以及缺失分数的提交
- **THEN** 按规定顺序稳定呈现，缺失和无效分数在有效分数之后

#### Scenario: 切换排序
- **WHEN** 用户切到时间排序再返回分数排序
- **THEN** 列表按相应规则排列，同秒时间排序按完整 ID 升序，详情与计划成员不随行位置改变

### Requirement: CRR-07 详情与上下文一致

详情 SHALL 展示与所选分析和提交一致的身份、时间、分数、变更度量和来源，并提供可用的原始提交定位。原始特征 MUST 与模型解释分开，未提供解释时明确说明；已提供的解释必须来自同一模型与输入。关闭详情 SHALL 保留有效筛选、排序和计划。不存在的提交、空计划或无搜索结果 MUST 不展示另一条提交代替。

#### Scenario: 打开并返回
- **WHEN** 用户在筛选结果中打开详情再关闭，或从计划打开同一条目
- **THEN** 详情对应完整 ID 与分析来源，返回后有效筛选、排序和计划保持不变

#### Scenario: 提交或解释不可用
- **WHEN** 提交不存在，或可用提交没有解释、度量或可用外链
- **THEN** 分别显示不存在或未提供的原因和可操作返回入口，不编造内容

#### Scenario: 真实度量不冒充归因
- **WHEN** 用户查看首轮真实模型提交的详情
- **THEN** 变更规模与该 schema 的原始度量来自对应记录，未发布的标题或作者显示未提供
- **AND** 没有模型解释时不复用示例、按特征数值大小编写原因或从标签生成解释

#### Scenario: 原始改动入口
- **WHEN** 当前记录提供可核验的原始提交 HTTPS 地址
- **THEN** 用户可明确打开对应外部提交；本地来源或不支持的托管站点只提供完整 ID 与不可外链说明，不显示原型 diff

### Requirement: CRR-08 个人优先审查清单

系统 SHALL 以审查计划呈现个人优先审查清单，支持列表/详情加入、计划移除和打开详情。条目 MUST 保存仓库或来源、分析/运行身份、完整提交 ID 及加入顺序，同一上下文内不得重复。各视图状态与数量一致；计划操作不能修改模型输出、解释或原始标签，也不代表已审、通过或缺陷确认。

#### Scenario: 完成优先审查选择
- **WHEN** 从列表和另一条详情分别加入提交，再打开计划
- **THEN** 计划按加入顺序呈现两条唯一提交，数量一致，可返回各自正确分析下的详情

#### Scenario: 重复加入与移除
- **WHEN** 重复加入同一上下文的提交后再移除
- **THEN** 数量不重复增加，移除后各视图恢复可加入状态，分数和标签不变

#### Scenario: 清单为空
- **WHEN** 尚未加入条目或最后一条被移除
- **THEN** 显示空计划及返回提交列表的入口，详情为空或明确未选择，不残留已移除条目冒充当前计划

### Requirement: CRR-09 清单在同一浏览器恢复

计划 SHALL 在同一浏览器与应用地址恢复条目及顺序；演示按项目/版本、历史按数据/运行、仓库按仓库/成功分析/数据版本隔离。新分析不得静默覆盖或继承旧计划。升级旧存储时 SHALL 保留原数据，仅迁入可验证属于当前上下文的条目，并说明待迁移、无效或缺失内容；不可推断来源，不清理其他上下文存储。

#### Scenario: 刷新后恢复
- **WHEN** 保存计划后刷新或重开同一数据与分析版本
- **THEN** 恢复相同条目与顺序，列表、详情和计划状态一致

#### Scenario: 版本或保存内容不匹配
- **WHEN** 数据版本变化，或保存内容损坏、格式不支持、含不存在的提交
- **THEN** 无效记录不作为当前计划；显示可恢复提示，不因当前仅加载一页而删除其他页条目

#### Scenario: 模式或模型运行改变
- **WHEN** 来源、项目或模型运行改变，即使提交 ID 相同
- **THEN** 当前上下文只恢复自己的计划，返回旧上下文仍可恢复旧计划，其他数据不被清理

#### Scenario: 仓库同步上下文隔离
- **WHEN** 同一仓库有新成功分析，或切换至另一仓库
- **THEN** 分别恢复对应分析的计划，旧分析条目不无提示迁为新分数，用户仍可明确返回旧分析

#### Scenario: 旧格式受控迁移
- **WHEN** 发现合法旧 v1/v2 清单且可核对其来源
- **THEN** 展示待迁入的上下文与数量，由用户显式迁入；保留旧键，重复迁入不生成重复条目，无法核对的条目不自动归到当前仓库

### Requirement: CRR-13 基线摘要可追踪

系统 SHALL 提供与当前来源关联的可展开分析来源：历史验证包含数据校验、schema、分区、运行、模型、评价与局限；仓库分析包含成功作业、实际分支、数据版本、模型与已提供限制。只显示当前记录确有的评价，缺失/未定义项说明原因。字段来源、未提供字段与解释支持状态 MUST 可核对，不用另一运行的指标或同名异义字段补齐。

#### Scenario: 查看同一运行的记录
- **WHEN** 用户展开真实历史批次的基线摘要
- **THEN** 数据、测试区间、schema、模型和运行可核对，指标注明口径与样本数
- **AND** lt/rexp 等未提供字段按该 schema 明确原因，标签有效性限制可读

#### Scenario: 摘要缺失或来自其他运行
- **WHEN** 必需来源信息缺失或与当前分析身份不一致
- **THEN** 显示来源冲突或不可用，不拼接另一运行的效果；仅可选评价缺失时说明未提供而不伪造数值

#### Scenario: 演示来源不显示真实效果
- **WHEN** 用户进入人工演示
- **THEN** 示例分数与说明持续标识，不把真实模型指标当作演示成果

#### Scenario: 仓库不借用公开效果
- **WHEN** 仓库使用兼容通用模型，但没有该仓库的独立有效评价
- **THEN** 披露实际模型、降级与未在该仓库验证，不展示公开历史测试分数作为仓库效果
