# 任务

## 1. 受控参数与训练执行

- [ ] 1.1 `algorithms.py` 为 LR、DT、RF、MLP 声明参数白名单、类型与范围，并提供参数解析与摘要函数；未知参数、越界类型被拒绝。
- [ ] 1.2 `build_run`、`fit_model` 接受实际参数；默认参数保持旧运行配置，显式参数写入 `model` 与 `parameterContract`。
- [ ] 1.3 `check_files` 在有契约时按声明校验参数，无契约时仍与冻结 `params` 完全相等；新增单测覆盖两种路径。
- [ ] 1.4 模型显示名与模型卡投影能区分同一方法的不同参数配置。

## 2. 多方法实验组

- [ ] 2.1 迁移 033 新增 `training_experiment` 与训练任务的 `experiment_id`、`params_json`、`history_json` 字段，前向兼容。
- [ ] 2.2 `TrainingTaskService` 支持一次提交多方法实验：重复请求复用活动任务、参数不同不复用、部分成功/失败/取消/重试均保留。
- [ ] 2.3 API 提供创建实验、实验详情与比较；任务视图包含方法、参数、历史与实验引用。
- [ ] 2.4 单方法训练入口保持可用；既有任务与产物的身份校验语义不变。
- [ ] 2.5 单测覆盖同一数据/切分成员、参数不同不同任务、重试保留参数与切分、实验状态汇总。

## 3. 训练过程历史

- [ ] 3.1 深度分类器按 epoch 记录平均训练损失与耗时，固定 epoch、不早停。
- [ ] 3.2 训练执行写入 `training-history.json` 并回填任务；失败、取消与中断保留已有历史与真实终态。
- [ ] 3.3 非迭代方法不生成历史，界面明确“无逐 epoch 曲线”；旧任务显示“未记录”。

## 4. 实验界面与导出

- [ ] 4.1 管理数据集详情支持多选方法与逐方法参数，先预览切分再提交实验。
- [ ] 4.2 实验详情展示子任务状态、参数、切分身份、指标、耗时与失败原因，活动任务刷新、终态停止。
- [ ] 4.3 实验比较表与导出（JSON）标明口径一致性与不可直接比较原因。
- [ ] 4.4 训练成功仍需显式登记；项目侧可显式选择登记后的模型进行分析。
- [ ] 4.5 前端单测覆盖实验表单、比较表与历史展示。

## 5. PR 候选修复建议与问题草稿

- [ ] 5.1 规则模板为可变默认参数、裸 except、eval/exec 生成针对性建议、修改位置、理由与人工确认项。
- [ ] 5.2 建议可加入既有问题/结论草稿，并复用确认、驳回、暂缓与恢复。
- [ ] 5.3 重复分析不重复堆叠候选；快照更新后原候选与判断保留，不静默迁移行号。
- [ ] 5.4 后端与前端单测覆盖有候选、无候选、解析失败、不支持语言与重复分析。
