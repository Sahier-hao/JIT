- [x] 2.1 建立带来源元信息的12条固定演示记录及 Vitest 行为测试，使用明显的演示标识并说明分数、时间和解释的人工示例来源；验证来源缺失、重复标识、无效必需时间、可选字段缺失，以及风险 0、1、区间值、缺失、非有限和越界值的不同处理（CRR-01、CRR-02、CRR-03、CRR-11），测试不得靠随机数据或假训练得出结果。
- [x] 2.2 实现可替换的异步数据读取边界及加载状态处理，补充加载中、有效结果、空数据、读取异常和重试恢复的行为测试；运行对应 Vitest 用例，确认无效必需信息进入不可用状态、成功重试清除旧错误（CRR-01、CRR-11），不定义未来后端 API。
- [x] 2.3 实现提交标识搜索、按 Asia/Shanghai 日界线的日期筛选和确定性排序，补充大小写与空白、无结果、清除筛选、单侧日期、起止包含、无效范围、组合条件、同分同时间及缺失风险排序用例；对应 Vitest 测试必须验证结果顺序、身份不变和无效日期保留最近有效结果（CRR-04、CRR-05、CRR-06）。

## 3. 桌面评审完整交互

- [x] 3.1 实现中文工作台、演示来源标识、提交表格、搜索、日期及排序控件，加入 Playwright Chromium 测试；实际浏览器验证列表字段与百分比一致，缺失和无效信息有文字反馈，查询空结果与加载空数据可区分，重试可恢复（CRR-01至CRR-06、CRR-11）。
- [x] 3.2 实现按完整标识定位的右侧详情及关闭、返回交互，加入详情行为和浏览器用例；验证列表与详情一致、筛选排序上下文保留、缺失度量或解释显示“未提供”、不存在标识显示“提交不存在”，不出现排序后错开记录（CRR-07）。
- [x] 3.3 实现列表与详情加入、清单按加入顺序查看、移除及从清单打开详情，补充清单行为测试与完整链路的 Playwright 用例；验证两条记录的跨视图状态与数量一致、重复加入唯一、移除后恢复可加入、空清单可返回列表，操作不改写原始记录（CRR-08）。
- [x] 3.4 完成两个目标视口的布局、文字状态、可见焦点和详情关闭后的焦点返回；以 Playwright 在 1280×720、1440×900 的核心链路及仅键盘打开、加入、关闭用例验证，并查看实际截图，确认关键控件不被遮挡且无需页面级横向滚动（CRR-12）。
- [x] 3.5 补充 README 的操作说明，并将本组实际浏览器结果与截图逐项关联到验收索引；按说明复走“搜索 → 详情 → 加入 → 清单 → 移除”链路，核对截图、测试输出和场景标识均存在，明确这是演示原型的交互证据。

## 4. 同一浏览器保存与故障恢复

- [x] 4.1 实现包含项目和演示版本的 localStorage 清单命名空间、标识与顺序保存及恢复，补充行为测试和刷新后的 Playwright 用例；验证同一版本恢复成员与顺序、不同版本隔离、三处加入状态一致，不保存风险值或缺陷标签（CRR-09）。
- [x] 4.2 实现损坏内容、格式不支持、重复及未知标识的恢复处理并补充测试；运行对应 Vitest 和浏览器用例，确认无效成员不进入当前清单、损坏内容有恢复失败提示、用户仍能重新选择，其他应用和版本的存储不被删除（CRR-09）。
- [x] 4.3 实现读写被拒绝时的内存降级与提示，使用测试边界注入读取、写入失败，补充行为及浏览器测试；验证恢复失败时清单仍可操作，保存失败时当前加入或移除立即生效并显示规定提示，列表和详情仍可使用（CRR-10），不增加产品故障模拟菜单。
- [x] 4.4 在 README 说明同浏览器、同地址、同版本的保存边界及刷新丢失风险，更新 CRR-09、CRR-10 的验收证据；核对描述与实际恢复、损坏和拒绝保存测试相符，不宣称账号同步、多标签页同步或跨设备保存。
