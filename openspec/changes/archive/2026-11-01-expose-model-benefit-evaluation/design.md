## Context

现有模型详情展示 AP、ROC-AUC、Recall@20%LOC、Popt、IFA，但这些是排序质量指标，不能直接回答「按模型建议检查 20% 的代码改动，是否比按时间或随机检查覆盖更多历史标记问题」。多项目报告提供宏平均与融合权重，但没有逐条测试记录和三种检查顺序的对照。

`backend/artifacts/<key>` 已保存冻结测试分区（`test-input.json`、`test-labels.json`、`reference-predictions.json`、`metrics.json`），`Snapshot.load` 会校验模型、来源、成员与指标。收益评估可以在不重新训练的前提下复用这些数据。

## Goals / Non-Goals

**Goals**

- 在同一测试分区、同一 20% LOC 预算、同一标签口径下比较模型分数、时间顺序和固定种子随机顺序。
- 复用既有 Recall@20%LOC、Popt、IFA；随机重复记录均值、标准差与范围。
- 报告包含样本、正例、标签限制、参数选择说明和运行身份；不利结果如实显示。
- 管理员在模型详情查看收益；没有报告或报告无效时明确说明。

**Non-Goals**

- 不重新训练、不在测试分区调参、不自动选择或替换默认模型。
- 不把风险分数称为缺陷概率，不宣布全局最佳模型。
- 不提供在线训练编排或多模型收益排名。
- 不修改 `openstack` 或多项目数据与标签生成规则。

## Decisions

### D1 冻结测试分区，关闭测试期调参

收益评估只读取一个已交付产物的冻结测试分区；模型、阈值和策略在评估前固定。报告记录 `parameterSelection = none; frozen artifact; test partition used only for evaluation`，不根据测试结果反向调整任何参数。

### D2 三种检查顺序共用同一预算与标签

- 模型分数：risk 降序，时间降序、ID 升序破同分。
- 时间顺序：提交时间降序、ID 升序；不读取模型分数。
- 随机：对每个测试记录生成 `SHA-256(seed:run:id)` 排序键；固定种子重复指定次数，跨 Python 运行时稳定。

三种顺序都使用测试分区全部记录、同一标签和同一 20% 总 LOC 整提交前缀预算。Recall@20%LOC 与 IFA 直接按顺序计算；Popt 使用既有归一化成本-召回面积公式（oracle/worst 由标签与成本决定），并记录本次排序。既有密度排序 Popt 另列对照，不混用。

### D3 随机重复与可复现

默认 200 次、种子 2026；报告记录 `runs`、`seed`、每次可定义结果的均值、总体标准差、最小值和最大值。相同产物、随机次数和种子产生相同的策略结果、结论句和样本统计；只有 `generatedUtc` 变化。条件不足（无正例、总成本为零、零成本提交）返回 `null` 与原因。

### D4 报告与模型身份

报告记录 artifact runId、模型描述、数据版本、schema、指标集、阈值、测试成员与来源、完整限制、文件哈希与评估环境。服务按 `artifactRunId`（而不是业务 runId）匹配模型；根目录为 `backend/artifacts/benefit` 与仓库 `docs/evidence`，可用 `JIT_BENEFIT_REPORT_ROOT` 覆盖。报告只读，单文件上限 8 MiB；无效报告返回 `REPORT_INVALID`。

### D5 模型详情内的只读区域

模型详情新增「审查收益」区域，显示结论句、三种策略的 Recall@20%LOC/Popt/IFA、覆盖正例、选中提交、使用行数、样本与正例、随机重复与种子、既有运行指标对照和标签限制。无报告时显示原因；读取失败提供重试。页面不提供训练、调参或修改默认模型操作，不使用缺陷概率措辞。

## Risks / Trade-offs

- 回顾性测试分区不能代表在线效果；报告固定写明这一限制。
- 历史标签是发布者观测或简化 SZZ，未观测到缺陷引入不等于已证实无缺陷；UI 使用「历史标记」而非「缺陷」。
- 时间顺序在按时间切分的测试集上可能天然占优；这正是需要如实展示的结果，不据此调整模型。
- Popt 的排序与既有密度排序不同；报告同时给出既有运行指标对照，避免混读。
- 随机排序是基线，不是置信区间；均值与波动只描述该测试分区和固定种子。

## Migration Plan

无数据库迁移。新增 `docs/evidence/benefit-evaluation/` 报告文件和代码；既有模型、数据集、训练任务、默认模型与 API 响应不变。回退恢复旧代码并忽略报告目录即可。
