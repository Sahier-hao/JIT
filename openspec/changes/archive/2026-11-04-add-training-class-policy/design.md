# Design

## Context

训练执行器按时间切分训练、验证和测试分区，当前没有类别策略参数。管理训练页可以创建任务和查看指标，但没有策略配置或前后数量记录。参见 proposal.md。

## Goals / Non-Goals

**Goals:**

- 类别处理只作用于训练分区，测试成员冻结。
- 策略、参数、种子和前后数量可追溯。
- 未选择策略时行为不变。

**Non-Goals:**

- 不改变数据集的标签或成员。
- 不自动选择策略或根据测试指标调参。
- 不对验证或测试分区重采样。

## Decisions

**策略是训练任务的可选字段。** 新增 `classPolicy` JSON，包含类型（无、加权、采样）、参数和随机种子；默认空表示现有行为。策略随任务保存，旧任务为空。

**只在训练分区应用。** 时间切分完成后，对训练记录应用加权或采样；验证和测试记录保持原成员与标签。采样使用固定种子，按提交标识哈希保证可复现；加权作为模型参数传入支持它的方法。

**不支持时明确失败。** 方法不支持所选策略时，任务失败并说明原因，不忽略策略或改用其他策略；不把失败结果登记为模型。

**记录前后数量。** 任务摘要保存策略、参数、种子、训练样本数、正例数和处理后的有效数量；界面显示这些值，并说明测试指标不因训练分区策略而可直接比较。

**迁移。** 训练任务表增加可空字段；旧任务为空，读取时按无策略处理，不需要回填。

## Risks / Trade-offs

- [采样改变训练分布，指标与未处理任务不可直接比较] → 任务详情记录策略和前后数量，报告说明差异来源。
- [部分方法不支持类别权重] → 明确失败并提示更换方法或取消策略。
- [采样可能减少多数类信息] → 保留原始训练分区统计，管理员可对比选择。
- [旧任务没有策略字段] → 按无策略读取，不推断历史配置。

## Migration Plan

1. 新增训练任务策略字段迁移，旧任务为空。
2. 新任务可选策略；不改变既有任务和模型。
3. 回滚时停止读取策略字段并恢复旧代码；已记录的任务保留。
