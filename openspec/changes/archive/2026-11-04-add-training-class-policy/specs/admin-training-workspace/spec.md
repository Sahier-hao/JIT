# Spec Delta

## ADDED Requirements

### Requirement: AWW-07 训练分区类别策略

系统 SHALL 允许管理员为训练任务选择可选的类别加权或采样策略，并 MUST 只作用于训练分区。验证与测试分区 MUST 保持冻结，不因策略改变成员或标签分布。任务 MUST 记录策略、参数、随机种子和处理前后的训练样本数与正例数；未选择策略时 MUST 保持现有训练行为。方法不支持所选策略时 MUST 明确失败，MUST NOT 静默忽略或改用其他策略。

#### Scenario: 训练分区加权

- **WHEN** 管理员为一个训练任务选择类别加权
- **THEN** 只有训练分区的损失权重改变，验证与测试成员和标签保持不变
- **AND** 任务记录策略、参数和处理前后的训练样本数与正例数

#### Scenario: 训练分区采样

- **WHEN** 管理员选择采样策略并指定随机种子
- **THEN** 采样只作用于训练分区，重复运行得到相同训练成员
- **AND** 任务记录种子和采样前后数量，验证与测试成员不变

#### Scenario: 未选择策略

- **WHEN** 管理员没有选择类别处理
- **THEN** 训练行为与现有实现一致，不隐式重采样或加权

#### Scenario: 方法不支持策略

- **WHEN** 所选方法不支持类别加权或采样
- **THEN** 任务以明确错误失败并说明原因，不忽略策略继续训练
