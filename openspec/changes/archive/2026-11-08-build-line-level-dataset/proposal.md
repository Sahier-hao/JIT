# 从 SZZ 证据导出行级训练数据

## Why

完整 SZZ 已经给出“引入提交 + 文件 + 原始行号区间”，但这只是标签证据，不是可训练的数据：行级缺陷预测还需要每一行的文本、上下文、语言/提交特征和负例。没有这一层，行级模型无法开始训练。

## What Changes

- 新增 `line-dataset` 命令：读取数据集描述中的 SZZ 证据，从仓库取出引入提交对应文件的行，生成正例。
- 从数据集中标签为 0 的提交里抽取新增行作为负例，按 `negatives-per-positive` 控制比例，固定随机种子可复现。
- 输出 JSONL（`schema=line-szz-v1`）与摘要：每条含提交、路径、行号、文本、前后文、语言、行级启发式特征、提交级 Kamei 特征、来源与证据区间。
- 正例与负例去重，跳过文档/测试/二进制路径；证据不足或负例不足时如实写入摘要，不补造。
- 只导出数据，不训练模型、不修改数据集或模型目录。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `repository-collection`：新增 RCL-25，规定行级样本导出的来源、正负例、去重、特征与摘要披露；标签事实仍来自 RCL-04。

## Impact

- 后端：新增 `backend/jit_baseline/line_dataset.py` 与 CLI 命令；复用现有 SZZ 证据和 CSV，不新增数据库表。
- 前端：本期无变化。
- 数据：导出的 JSONL 是训练输入，不是新的登记数据集；不改变默认模型或已有分析。
- 依赖：需要本地仓库或缓存的裸克隆路径，仅读取。
