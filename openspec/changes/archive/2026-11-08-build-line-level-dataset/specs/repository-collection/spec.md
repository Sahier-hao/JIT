## ADDED Requirements

### Requirement: RCL-25 行级样本导出

系统 SHALL 从已登记的 SZZ 数据集导出行级训练样本，而不是只保留提交级标签。正例 MUST 来自数据集描述中的行号证据（引入提交、路径、原始行号区间），逐行读取引入提交中的文本；无法读取或越界时 MUST 记入摘要，不得补造。负例 MUST 来自同一数据集中标签为 0 的提交的实际新增行，按声明的比例抽样，固定种子可复现；正负例 MUST 去重，文档、测试与二进制路径 MUST 跳过。每条样本 MUST 至少包含数据集版本、提交、路径、行号、标签、文本、前后上下文、语言、行级启发式特征与提交级特征。导出 MUST 输出 JSONL 与摘要，摘要记录正负例数、提交/文件数、缺失行、跳过文件、截断与负例不足。导出 MUST NOT 写回数据集、目录库或模型。

#### Scenario: 导出正例

- **WHEN** 数据集描述包含一条引入提交、路径与原始行号区间
- **THEN** 导出该区间内每一行作为正例，文本来自引入提交，并带前后上下文与提交特征

#### Scenario: 抽样负例

- **WHEN** 数据集中存在标签为 0 的提交
- **THEN** 从这些提交的新增行抽样负例，数量按 negatives-per-positive 控制
- **AND** 相同种子重复导出的内容一致

#### Scenario: 去重与过滤

- **WHEN** 正例与负例候选指向同一提交、路径与行，或路径属于文档/测试/二进制
- **THEN** 不重复输出，被过滤路径数量记入摘要

#### Scenario: 缺失与不足

- **WHEN** 引入提交中找不到声明的行，或负例候选不足
- **THEN** 摘要记录缺失行数与负例不足，不输出占位样本或伪造标签

#### Scenario: 不写回

- **WHEN** 行级样本导出完成
- **THEN** 数据集描述、目录库、模型与既有分析保持不变
