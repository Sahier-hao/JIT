# Proposal

## Why

当前界面在可读性与信息密度上有可测量的问题，而不只是"不好看"：全站 133 处字号声明中 44 处 ≤ 11px，中文正文长期落在 10–11px；12 组文字的对比度低于 WCAG AA 4.5:1（页脚 2.39:1、表单帮助 2.65:1、表尾 2.97:1，连风险值本身也只有 4.24:1）；两个样式文件里散布 181 个不同的十六进制色值，而只定义了 6 个变量且基本被硬编码绕过；横幅提示有 4 套互不相同的实现（`.demo-notice`／`.notice`／`.status-note`／`.warning`）；1440×900 下表格只显示 6 行、1280×720 下只显示 3 行且第 4 行被硬切，同时页面本身还在滚动，形成嵌套滚动。

这是课程交付的门面，也是评审员会长时间盯着看的工具。需要一套**可验收的呈现标准**，而不是一次性美化；同时必须保留既有的语义与可访问性契约（来源标注、风险边界、键盘流程、无横向滚动），因此设计必须落到"约束"而不是"感觉"。

本变更只处理视觉与材料，不改变产品能力。审查预算工作点由独立变更 `add-review-budget-workpoint` 承担。

## What Changes

- **引入令牌层**：语义色（表面/文字/线/语义色/风险阶）、字号阶梯（6 档）、间距、圆角、阴影收敛为变量；删除全部硬编码色值与重复定义（`.primary-button`、`.sr-only`、`.nav-label` 各定义两次）。
- **四套主题可切换**：石灰（暖中性+墨绿）、钢青（冷中性+深青）、炭黑（深色）、纸墨（单色）。主题与表格密度在设置面板中选择并持久化。**风险色阶不随主题变化**，因为它是语义色。
- **侧栏分层**：214px 深色单栏改为 52px 图标轨 + 188px 上下文栏，可收起；层级由字重（700 强调／400 正文）、色阶与 3px 锚点条共同表达。
- **统一"工程制图"材料**（替换现有生成式素材）：
  - 图标：20 网格、1.5 描边、方头端点、2px 圆角；替换现有圆头描边图标。
  - 图表：刻度画在轴外、网格只横向、分区带用**斜线纹理表示"不参与估计"**、实底表示评估窗口；标记为方块（实心=观测，空心=估计）。
  - 状态：6px 色块 + 文字，替换全部圆角胶囊。
  - 指标：账本式横条（1px 分隔），替换独立指标卡片。
  - 标识：字标 + 细线，替换彩色方块 logo 与填充头像。
  - 上述规则连同禁用清单在 `design.md` 的"材料规范"一节固化，作为验收依据（`IP-09`）。
- **风险编码强化**：风险列改为"等宽两位小数 + 4px 条 + 60% 刻度 + 分档色"，让"为什么这条排在前面"可被核对。
- **修正趋势图的读数缺陷**：提交数柱与比例/风险线拆成上下两张**共享 x 轴**的图（现状柱没有自己的纵轴，"803 次提交"悬空无法读数）；分桶明细去掉与提交数重复的分区计数、逐行重复的"未提供"说明与断行的时间串。
- **信息减量**：删除页头胶囊行（schema／运行号／时区移入详情）、面板元信息行、重复的状态行与底栏；行高 71→40，表头 43→31；1440×900 可见行数 6→16，1280×720 由 3 行提升至 11 行。
- **免责与来源分层披露**：结论标签（"模型估计 · 未校准"）常驻可见；完整来源与限制在详情内一层可达且键盘可达。不削弱 `CRR-01` 的可见性要求。
- **五个页面统一**：提交工作台、历史趋势、模型中心、新建预测、结果页共用同一套令牌、外壳与材料。
- **保留既有 e2e 类名**作为稳定钩子（`.commit-link`、`.risk-number`、`.model-card`、`.trend-table-wrap`、`.field-grid`、`.baseline-scores`、`.status-note`、`.result-section`），改写样式而非重命名，避免测试返工掩盖真实回归。

## Capabilities

### New Capabilities

- `interface-presentation`: 界面的呈现与材料标准——可读性下限（对比度、字号）、信息分层披露的呈现契约、无外部资源约束、主题与密度偏好的行为、动效克制。跨页面长期有效，供后续新增页面复用。

## Impact

**受影响代码**：`frontend/src/` 全部样式（`App.css` 拆分并重写、`index.css`、`trend.css`）、`AppShell.tsx`、`Icon.tsx`、`App.tsx` 以及 `ModelsPage.tsx`／`PredictPage.tsx`／`PredictionsPage.tsx`／`TrendPage.tsx`／`CommitDetail.tsx`／`BaselineRecord.tsx`／`Feedback.tsx`／`credentials.tsx` 的类名与结构。

**不受影响**：后端与数据契约、`openspec/specs/` 下的既有需求、`localStorage` 中清单的键与结构（`CRR-09`）。

**保持不变的契约**（实现验收时必须逐条自证）：
- `CRR-01` 模式、项目与数据版本在列表、详情与清单持续可见。
- `CRR-03` 风险值仍以百分比呈现，缺失显示"暂无预测"，越界显示"风险数据无效"；低风险不使用绿色（避免暗示"已确认安全"）。
- `CRR-12` / `MPW-11` 键盘可完成主链路，焦点可见，Escape 关闭详情并返回触发点。
- `DTD-03` / `DTD-05` / `DTD-06` 观测与估计分别标注、文本视图键盘可达、1280×720 与 1440×900 无页面级横向滚动。
- `MPW-02` 团队凭据输入仍在侧栏可得（本变更**不**把凭据输入移入设置面板；设置面板只承载外观偏好）。

**风险**：e2e 断言依赖类名与精确文本（如 `'100%'`、`'86%'`、`'0%'`），统一小数位会直接使测试失败，需与样式改动同批更新。
