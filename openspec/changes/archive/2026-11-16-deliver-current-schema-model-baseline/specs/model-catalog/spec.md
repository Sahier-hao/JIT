## ADDED Requirements

### Requirement: MC-19 当前 schema 正式基线与发布资格

模型目录 SHALL 分别公开模型的登记状态、产物可加载状态、发布资格、服务兼容性和默认候选状态。只有发布合格且服务兼容的模型 MAY 标为正式可服务模型；训练成功或登记成功 MUST NOT 自动产生发布合格状态。目录 SHALL 能读取当前 `kamei14-git-v2` 正式模型包及其发布报告，新环境初始化时不得用六字段模型替代当前 schema 默认候选。

#### Scenario: 当前 schema 正式模型可用

- **WHEN** 新环境初始化当前 schema 正式模型包
- **THEN** 模型目录显示合格模型、服务兼容状态、发布报告入口和人工批准默认候选
- **AND** 新十四维项目可使用该默认候选

#### Scenario: 已登记但未经过发布门槛

- **WHEN** 模型完成登记但不存在匹配的发布报告
- **THEN** 目录显示“已登记、未发布合格”
- **AND** 不得宣称该模型已达到正式交付质量

#### Scenario: 旧默认模型保持兼容

- **WHEN** 既有环境已经保存默认模型
- **THEN** 导入当前 schema 模型包不覆盖该默认选择
- **AND** 管理员可人工切换为发布合格的当前 schema 默认候选
