# Spec Delta

## MODIFIED Requirements

### Requirement: CUR-01 清洗配方与预览

系统 SHALL 允许管理员或数据所有者针对一个可见的已登记数据集版本定义可排序的清洗与预处理操作序列，至少覆盖重复记录、缺失字段、日期范围、固定数值区间和分位区间。配方 MUST 绑定当前特征 schema，未知字段、非法边界或无效顺序 MUST 在生成前拒绝。生成正式数据前 MUST 提供预览；预览 MUST 为每一步返回应用前后的样本数、正例数、时间范围、排除原因和逐入模字段的样本数、缺失数、均值、中位数、最小/最大值与分位桶分布。预览 MUST NOT 写入正式数据集或改变原版本。系统 MUST 保留既有 v1 配方的规范化结果与哈希语义。

#### Scenario: 预览多步操作

- **WHEN** 管理员或数据所有者提交包含日期、固定区间和分位区间过滤的操作序列
- **THEN** 返回每一步应用前后的数据集统计和排除原因，最终统计与逐步结果一致，原数据集文件不变

#### Scenario: 预览排除规则

- **WHEN** 管理员或数据所有者为一个可见数据集版本选择排除规则并请求预览
- **THEN** 返回保留与排除数量、规则命中数、缺失与正例比例变化，原数据集文件不变

#### Scenario: 查看指定特征逐步变化

- **WHEN** 预览返回逐步骤特征分布
- **THEN** 用户可以切换步骤和任一入模字段，查看该步前后分位桶计数、均值、缺失和范围变化

#### Scenario: 查看指定特征变化

- **WHEN** 预览返回逐特征分布
- **THEN** 用户可选择任一入模字段查看清洗前后分位桶计数与均值、缺失和范围变化

#### Scenario: 分位边界由步骤输入确定

- **WHEN** 一个分位区间过滤位于其他过滤之后
- **THEN** 系统在该步骤开始的保留记录上计算上下界，并保存实际边界供复核

#### Scenario: 配方无效

- **WHEN** 配方包含未知规则、非法参数或与当前 schema 不兼容的字段
- **THEN** 预览以明确错误拒绝，不生成派生版本，也不部分应用规则

### Requirement: CUR-03 清洗前后对比

系统 SHALL 提供来源版本与派生版本的对比，至少包含样本数、正例与零标签数量、字段缺失、时间范围、排除原因分布、操作序列、逐步前后统计、逐入模字段的统计与分位桶变化和配方差异。对比 MUST 只读取已保存数据，MUST NOT 重新执行清洗或改写任一版本；无法比较的字段 MUST 显示原因。

#### Scenario: 对比两个版本

- **WHEN** 管理员或数据所有者选择来源版本和一个派生版本进行对比
- **THEN** 页面并列显示样本、正例、缺失、时间范围、排除原因、操作序列、逐步结果和指定特征前后分布

#### Scenario: 版本不可比较

- **WHEN** 两个版本 schema 不同或派生版本来源不匹配
- **THEN** 对比拒绝或标注不可比原因，不把不同口径的数字直接相减
