## ADDED Requirements

### Requirement: PEX-13 分层证据链与行级贡献核对

固定仓库提交详情和固定 PR 快照 SHALL 按对象实际拥有的证据展示分层链路，包括提交风险、提交级特征解释、行级研究证据、规则命中和历史修复证据。每一种证据 MUST 显示来源及适用边界；对象缺少某类证据时 MUST 说明不可用原因，MUST NOT 用其他对象、当前默认模型、文件级指标或空图补齐。行级研究证据 SHALL 同时提供按行分数排序的候选列表、前 3 个行级特征贡献条形图和等价表格；图表 MUST 显示路径、行号、分数单位、贡献单位、基线或截距口径和模型状态，表格 MUST 可访问且信息不少于图表。

不同解释方法、行分数概率和 `log-odds` 贡献 MUST 分别标注，MUST NOT 相加、统一排名或自动选择“最佳解释”。概率贡献 MUST 在 `[-1,1]` 内；`log-odds` 贡献 MUST 只要求有限数。由模板生成的摘要 MUST 只复述当前已展示并保存或返回的证据，MUST NOT 推断缺陷原因或修复优先级；本轮 MUST NOT 使用自由生成式语言模型补充证据。

#### Scenario: PR 完整证据链

- **WHEN** 一个固定 PR 快照具有提交分、可解释模型、受支持语言源码和规则候选
- **THEN** 页面依次展示风险、提交级解释、行级候选与贡献、规则命中和覆盖说明
- **AND** 每一部分标明其来源，且提交分不因行级证据改变

#### Scenario: 固定提交部分证据缺失

- **WHEN** 一个固定仓库提交具有风险、提交级解释和历史修复证据，但没有可读取的固定 diff
- **THEN** 页面展示可用证据，并在线级区域明确“没有真实代码候选，无法生成行级证据”
- **AND** 页面不显示空条形图、不根据变更行数伪造行号

#### Scenario: 行级贡献可视化

- **WHEN** 一个候选行包含多个非零行级特征贡献
- **THEN** 页面按贡献绝对值展示至多前 3 个非零项，并用等价表格展示特征、值、权重乘积、带符号贡献和方向
- **AND** 行分数作为概率单独展示，不放入 `log-odds` 贡献合计

#### Scenario: 多方法与多单位并列

- **WHEN** 同一提交同时具有遮挡解释、线性 `log-odds` 解释和行级研究证据
- **THEN** 页面分别显示方法、单位、基线或截距和稳定性，不把三者合成为总贡献或最佳结论

#### Scenario: 模板摘要

- **WHEN** 页面生成解释摘要
- **THEN** 每句话只引用当前展示的已保存或已返回贡献项，并明确“行级特征贡献不是缺陷原因”

#### Scenario: 缺失规则或历史来源

- **WHEN** PR 快照没有历史修复来源，或仓库提交详情没有规则运行记录
- **THEN** 对应层级显示不可用原因，不把另一页面的数据复制进来
