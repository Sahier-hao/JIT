## ADDED Requirements

### Requirement: WSN-08 IDE 插件指南入口与地址恢复

系统 SHALL 提供稳定的 IDE 插件指南地址和主导航入口。刷新、浏览器前进后退或重新打开地址时 MUST 回到同一插件指南，不得改选其他工作区页面。桌面和 390px 窄屏下入口 MUST 可见、可操作，页面 MUST 无横向溢出。

#### Scenario: 打开插件指南

- **WHEN** 已登录用户选择主导航中的 IDE 插件入口
- **THEN** 地址包含稳定的插件指南身份，页面标题和导航状态与插件指南一致

#### Scenario: 刷新或后退

- **WHEN** 用户刷新插件指南地址或从后续页面后退
- **THEN** 仍显示插件指南，不跳转到项目、算法库或默认首页

#### Scenario: 窄屏入口

- **WHEN** 用户在 390px 视口打开工作区
- **THEN** IDE 插件入口可见且可操作，页面无横向溢出
