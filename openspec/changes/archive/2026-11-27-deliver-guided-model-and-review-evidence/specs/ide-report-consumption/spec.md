## ADDED Requirements

### Requirement: IDC-07 Web 端插件使用指南

系统 SHALL 提供可被主导航访问的 IDE 插件指南，说明当前支持的 IDE、报告格式、报告生成、显式导入、身份核对和代码定位流程。指南 MUST 区分能力说明、安装入口和实际可下载产物；没有稳定可下载的扩展包时 MUST 只展示真实构建或安装步骤，MUST NOT 显示无效下载入口。指南 MUST 说明只读、不联网、不执行报告内容、不修改源码的信任边界，并列出匹配、工作树改动、提交过期、Git 状态未知和文件不可定位等状态。

#### Scenario: 首次了解插件

- **WHEN** 已登录用户从主导航打开 IDE 插件指南
- **THEN** 页面按顺序展示生成报告、导入报告、核对身份和打开候选的步骤，并明确 VS Code 是当前已交付范围

#### Scenario: 无稳定下载包

- **WHEN** 当前交付不提供可由该页面稳定下载的 VSIX
- **THEN** 页面展示真实安装命令或构建产物说明，不显示看似可点击但没有目标的下载按钮

#### Scenario: 状态解释

- **WHEN** 用户阅读身份状态说明
- **THEN** 页面解释提交不匹配、工作树有改动、无法读取 Git 和文件行无效时为何拒绝定位

#### Scenario: 窄屏阅读

- **WHEN** 用户以 390px 宽度打开插件指南
- **THEN** 导航、步骤、命令和状态说明均可阅读且页面没有横向溢出
