## ADDED Requirements

### Requirement: FPR-13 PR 分析与批次接口错误协议

项目 PR 单条分析、批量分析、批次进度与批次重试接口 MUST 使用与既有业务接口相同的错误信封。非法参数、项目不存在、来源不可用、模型不可用或批次不存在时，服务端 MUST 返回对应状态码、错误码、可执行提示和 requestId，MUST NOT 退化为无结构的服务器内部错误。服务端 MUST 保留可定位日志，但 MUST NOT 向浏览器返回令牌、内部堆栈或文件系统路径。

#### Scenario: 参数或来源无效

- **WHEN** 客户端请求单 PR 分析、批量分析或批次进度时传入非法参数、项目不存在或来源不可用
- **THEN** 服务端返回对应错误码、状态码、可执行提示和 requestId，浏览器不出现统一 500 或内部堆栈

#### Scenario: 模型不可用

- **WHEN** 批量分析或重试请求固定的模型已停用、损坏或与仓库特征不兼容
- **THEN** 请求或对应条目明确失败并说明原因，不替换为其他模型

#### Scenario: 批次不存在

- **WHEN** 客户端读取或重试不属于当前项目或不存在的批次
- **THEN** 服务端返回 404 结构化错误，不披露其他项目的数据
