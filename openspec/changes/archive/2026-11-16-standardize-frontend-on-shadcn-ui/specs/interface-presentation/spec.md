# Spec Delta

## MODIFIED Requirements

### Requirement: IP-31 管理工作区共享用户工作区的控件语言

管理工作区 SHALL 与用户工作区使用同一套按钮、输入、选择、对话框、表格、卡片、标签与空状态形态。独立外壳 MUST 只体现分区与导航，不得引入第二套视觉语言；相同操作与状态在两个工作区呈现相同的形状、尺寸档位与反馈。

#### Scenario: 同一操作跨工作区一致

- **WHEN** 分别在用户工作区与管理模型、数据页面执行主操作、危险操作与筛选
- **THEN** 控件的形状、尺寸、悬停与聚焦反馈一致

#### Scenario: 列表与空状态一致

- **WHEN** 查看项目、分析记录与管理端模型、数据、训练列表
- **THEN** 表头、行高、分隔线与空状态结构一致，密度切换同时作用于两处

#### Scenario: 对话框结构一致

- **WHEN** 打开用户工作区与管理端的确认、表单或详情对话框
- **THEN** 标题区、关闭方式与底部操作区结构一致

#### Scenario: 控件组合与键盘一致

- **WHEN** 用户在两个工作区通过键盘操作选择、筛选、菜单和弹层
- **THEN** 当前选择、焦点与禁用状态可辨，单选操作只保留一个有效选择，关闭弹层后焦点回到触发位置
- **AND** 表单重新打开保留尚未提交的输入，请求失败后仍可修改和重试

#### Scenario: 按动作语义呈现

- **WHEN** 用户进行危险操作、查看侧栏详情或切换页内内容
- **THEN** 危险操作先明确确认，侧栏详情可关闭返回，页内内容切换有可识别的当前项
- **AND** 跨页面导航保持可复制的地址及浏览器前进后退行为
