# Proposal

## Why

行级研究模型已经在完整候选集上完成两轮影子评估：`vue-core` 全部指标超过随机与文件顺序基线，`express` 仅在 Recall@1 和首个正例行数上略低于随机。用户明确要求先把行级排序接进 PR 审查，先形成可用的阅读入口，再继续改进模型。

## What Changes

- 在 PR 文件的代码阅读区新增「行级排序（研究）」页签，只对当前固定快照真实新增/修改的 JavaScript/TypeScript 行排序。
- 行级排序复用现有研究模型打分接口，不新增模型、不写目录库、不改变提交分数、默认模型或合并状态。
- 每个结果显示行号、代码、排序分和特征贡献；固定标注“研究排序，不是缺陷概率”。
- 点击结果只定位到对应目标行，不创建或修改个人草稿。
- 不支持的语言、未取得完整源码、没有新增行或模型失败时显示原因，不静默替换模型。

## Capabilities

### New Capabilities

- `line-level-prediction`: 增加固定 PR 文件的行级研究排序入口。

### Modified Capabilities

- `line-level-prediction`: 允许 PR 文件视图在明确标注研究性质的前提下展示只读行级排序；影子门槛未通过时仍不得宣称定位收益或自动决策。

## Impact

- 影响 PR 只读详情和审查工作单共用的代码阅读区。
- 使用现有 `/api/v1/research/line-model/score` 与 PR 源码上下文接口，不改变数据库、模型目录或分析结果。
- 行级排序不是缺陷概率，不参与合并、阻断、默认模型或提交级风险。
