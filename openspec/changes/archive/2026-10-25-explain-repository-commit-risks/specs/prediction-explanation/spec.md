# Spec Delta

## ADDED Requirements

### Requirement: PEX-06 固定分析的主动解释

仓库提交解释 SHALL 要求明确的项目、成功分析和提交身份，读取仅返回保存结果或尚未生成状态。主动生成 MUST 使用该分析保存的模型及运行身份，核对完整入模特征和保存分数；不一致、缺失或模型不可用时返回可公开原因，MUST NOT 更换模型、修改原风险或读取标签和参考预测。

#### Scenario: 打开未生成解释的历史提交
- **WHEN** 用户打开一条成功分析中尚未生成解释的提交
- **THEN** 读取返回尚未生成，不进行推理；用户主动生成后才计算并保存

#### Scenario: 核对原模型失败
- **WHEN** 原模型损坏、运行身份不匹配、字段缺失或重算分数与保存分数不一致
- **THEN** 返回未支持和原因，原分数不变，不借用当前默认模型

#### Scenario: 跨项目或分析未成功
- **WHEN** 请求未指定分析、指定其他项目的分析或尚未成功的分析
- **THEN** 缺少分析时拒绝输入，跨项目时返回不存在，未成功时说明分析不可用

### Requirement: PEX-07 仓库解释保存与恢复

仓库提交 SHALL 保存成功解释的原模型、运行、分析、数据版本、分数、方法、基线来源及生成时间。成功后的读取和重复生成 MUST 原样返回，无需模型仍可加载。失败生成允许恢复原产物后主动重试；存储失败 MUST 不返回保存成功。解释随分析删除清理。

#### Scenario: 重开成功解释
- **WHEN** 解释已成功保存，用户重开或重复生成，即使原模型后来不可用
- **THEN** 返回同一保存内容，不重新推理，不修改原分数和计划

#### Scenario: 恢复原模型后重试
- **WHEN** 原模型不可用导致生成失败，管理员恢复并校验产物后用户重试
- **THEN** 仍使用原模型身份生成，可保存成功解释并再次读取

#### Scenario: 基线字段不完整
- **WHEN** 原模型绑定数据集仅有部分入模字段均值或全部缺失
- **THEN** 可用字段使用绑定数据均值，缺失字段使用零值，返回混合或零基线来源及字段列表，不称为缺陷原因

#### Scenario: 删除所属分析
- **WHEN** 用户删除该分析
- **THEN** 其解释一并移除，不能以解释请求恢复已删除分析
