# Spec Delta

## ADDED Requirements

### Requirement: FPR-07 提交详情主动生成模型解释

固定分析的提交详情 SHALL 显示已保存解释或主动生成入口，提供加载、失败重读及恢复后重试反馈。已支持时 SHALL 展示至多五条带符号的特征影响、本次值、基线、方法与来源；持续说明解释不代表缺陷、因果或代码定位。切换提交或分析 MUST 不显示旧请求结果，生成不改变风险与个人计划。

#### Scenario: 主动生成并再次打开
- **WHEN** 用户打开提交、生成解释，然后刷新或离开后重开
- **THEN** 初次读取不生成，点击后显示真实解释；重开显示保存内容并明确基线来源

#### Scenario: 网络或模型失败后恢复
- **WHEN** 读取请求失败或原模型暂时无法生成解释
- **THEN** 页面显示可读错误和对应重读或重新尝试入口，原分数与审查操作仍可用

#### Scenario: 切换时旧请求迟到
- **WHEN** 用户在解释请求完成前切换提交或分析
- **THEN** 旧响应不能出现在新上下文，解释来源始终属于当前固定分析和提交

#### Scenario: 小屏阅读特征影响
- **WHEN** 用户在窄屏查看解释
- **THEN** 生成、基线说明和特征表可阅读及操作，不把表格宽度扩展到整个页面之外
