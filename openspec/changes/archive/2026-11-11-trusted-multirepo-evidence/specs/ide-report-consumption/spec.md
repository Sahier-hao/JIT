## ADDED Requirements

### Requirement: IDC-05 真实仓库中的报告重复使用

VS Code 扩展 SHALL 在真实仓库中导入分析报告并核对仓库、提交与版本身份；工作树存在未提交改动、报告过期、分支切换、文件重命名或删除、路径越界与行号异常时 MUST 给出明确状态，不把候选定位到错误代码。用户 MUST 能显式重新核对或重新生成报告。

#### Scenario: 工作树已修改

- **WHEN** 报告对应提交与当前 HEAD 一致，但工作树文件内容已改变
- **THEN** 扩展提示报告与工作树不一致，定位按报告快照只读展示并说明差异

#### Scenario: 分支切换后重复导入

- **WHEN** 用户切换分支后再次导入旧报告
- **THEN** 扩展显示身份不匹配与原因，拒绝把候选定位到当前代码
