# Proposal

## Why

训练方法目录已经提供算法摘要、适用场景、收益、代价和参数，但入口只存在于训练创建弹窗中，页面以文字列表为主。用户无法在进入训练前系统比较 9 种方法的输入、训练结构和输出，也不容易理解线性模型、树集成、概率模型和深度网络之间的差异。

## What Changes

- 新增独立的「算法库」页面和主导航入口。
- 按经典与深度方法分组，展示每个方法的输入、处理阶段和输出结构图。
- 继续以训练方法目录作为算法说明、可用状态、依赖、预处理和参数含义的唯一来源。
- 保持训练弹窗现有快速算法库可用；完整页面不修改训练参数或运行身份。

### Modified Capabilities

- `configurable-training-parameters`: 新增可独立进入、带算法结构图和完整方法比较的算法图库要求。

## Impact

- 后端：方法目录补充可渲染的结构元数据，不新增模型、训练逻辑或数据库表。
- 前端：新增算法库路由、导航、页面、结构图组件和响应式布局。
- 兼容性：训练创建弹窗、参数表单、默认参数和运行身份保持不变。
- 验证：覆盖方法目录结构、路由往返、页面筛选、方法切换、参数展示与窄屏布局。
