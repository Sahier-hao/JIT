# Spec Delta

## ADDED Requirements

### Requirement: FPR-06 取消与原范围重新分析

项目页 SHALL 为进行中的分析提供取消确认、取消提交反馈和持续状态刷新；取消中不可重复取消或删除，结束后显示已取消及原参数重试入口。取消 MUST NOT 清空当前成功结果。恢复参数 SHALL 将保存的时间边界转换成有效日期输入，并保持实际采集范围、分支、上限及已指定模型身份；重新提交生成新记录，保留原记录。

#### Scenario: 排队位置与取消确认
- **WHEN** 用户查看排队记录并点击取消
- **THEN** 记录显示真实位置，先说明影响；确认后提交取消，放弃确认则原分析继续

#### Scenario: 运行中取消反馈
- **WHEN** 服务已接受取消请求但执行尚未完全停止
- **THEN** 页面显示正在取消，取消按钮不可重复提交，不提供删除入口，仍可打开既有成功结果

#### Scenario: 取消失败可恢复
- **WHEN** 取消请求因作业已经结束或网络错误而失败
- **THEN** 页面保留可读错误并刷新记录，不将错误当作取消成功，已有结果不被清空

#### Scenario: 原日期与模型重新分析
- **WHEN** 用户对已取消记录恢复原参数并再次开始分析
- **THEN** 日期字段有效，重新提交的实际起止范围不变，未修改模型时仍使用原模型，新记录完成后原取消和历史记录仍可读取
