# Spec Delta

## MODIFIED Requirements

### Requirement: CUR-01 清洗配方与预览

系统 SHALL 允许管理员或数据所有者针对一个可见的已登记数据集版本选择或定义清洗配方，至少覆盖重复记录、无效时间与数值、缺失字段、异常值边界、排除规则和标签处理。生成正式数据前 MUST 提供预览，列出受影响的提交数、保留与排除数、各规则命中数、字段缺失变化、正例比例和时间范围。预览 MUST 同时给出清洗前后整体统计、逐入模字段的样本数、缺失数、均值、中位数、最小/最大值与分位桶分布。预览 MUST NOT 写入正式数据集或改变原版本。

#### Scenario: 预览排除规则

- **WHEN** 管理员或数据所有者为一个可见数据集版本选择排除规则并请求预览
- **THEN** 返回保留与排除数量、规则命中数、缺失与正例比例变化，原数据集文件不变

#### Scenario: 查看指定特征变化

- **WHEN** 预览返回逐特征分布
- **THEN** 用户可选择任一入模字段查看清洗前后分位桶计数与均值、缺失和范围变化

#### Scenario: 配方无效

- **WHEN** 配方包含未知规则、非法参数或与 schema 不兼容的处理
- **THEN** 预览以明确错误拒绝，不生成派生版本，也不部分应用规则

### Requirement: CUR-03 清洗前后对比

系统 SHALL 提供来源版本与派生版本的对比，至少包含样本数、正例与零标签数量、字段缺失、时间范围、排除原因分布、逐入模字段的统计与分位桶变化和配方差异。对比 MUST 只读取已保存数据，MUST NOT 重新执行清洗或改写任一版本；无法比较的字段 MUST 显示原因。

#### Scenario: 对比两个版本

- **WHEN** 管理员或数据所有者选择来源版本和一个派生版本进行对比
- **THEN** 页面并列显示样本、正例、缺失、时间范围、排除原因、指定特征前后分布，并标明配方差异

#### Scenario: 版本不可比较

- **WHEN** 两个版本 schema 不同或派生版本来源不匹配
- **THEN** 对比拒绝或标注不可比原因，不把不同口径的数字直接相减

### Requirement: CUR-05 权限与不可覆盖

清洗预览、生成、对比和导出 MUST 要求已确认会话，并按数据所有者与显式共享状态限制可见范围；管理员 MAY 操作全局数据，数据所有者 MAY 操作本人版本，普通用户 MUST NOT 读取或操作他人版本。任何操作 MUST NOT 覆盖来源版本、已有派生版本或其他用户的数据。

#### Scenario: 未登录访问

- **WHEN** 未登录用户请求清洗预览或生成
- **THEN** 服务端拒绝，不披露数据集内容或配方

#### Scenario: 他人数据

- **WHEN** 普通用户请求操作其他用户拥有的数据版本
- **THEN** 服务端按无权限拒绝，不披露记录、字段或配方

#### Scenario: 所有者清洗本人数据

- **WHEN** 普通用户对本人数据版本预览并确认清洗
- **THEN** 预览只读取本人版本，派生版本归该用户所有且来源版本保持不变
