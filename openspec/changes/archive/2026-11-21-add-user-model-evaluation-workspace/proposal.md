# Proposal

## Why

普通用户已经能导入、清洗和训练数据，但训练完成后缺少“用真实模型回看整个数据版本、选择告警阈值、核对 Top 风险归因”的产品闭环。清洗预览也只有总量变化，无法回答某个特征在清洗前后如何变化；算法选择仍依赖代码阅读和口头解释。

## What Changes

- 新增用户“模型试算”：选择本人可见的数据版本与兼容模型，固定二者身份后批量评分，保存可重开的阈值计数、标签状态和 Top 风险归因。
- 新增阈值工作点页面：滑动风险阈值，按现有标签查看告警、命中、误报、漏报、精确率、召回率与 F1，并展示指标随阈值变化曲线。
- 扩展清洗预览与派生记录：返回清洗前后整体统计、逐特征分位桶和字段均值/缺失/范围变化，用户端以对比图展示。
- 扩展训练方法目录：返回算法适用场景、收益、代价、预处理、解释口径、参数标签与参数含义，并在训练入口提供算法库。
- 扩展 VS Code 扩展：提供“复制报告生成命令”以减少手写 CLI，将扩展纳入独立 GitHub Actions 打包流程。
- 修正可预测 schema 的声明：无离线语义向量的表格 schema 均可由已登记模型读写 JSON 特征；仍不接受缺失、别名或语义向量伪造。

## Capabilities

### New Capabilities

- `user-model-evaluation`: 普通用户对可见数据版本执行固定模型批量试算、阈值评估和 Top 风险归因，并重开不可变结果。

### Modified Capabilities

- `dataset-curation`: 清洗预览增加逐特征前后分布与统计，且数据所有者可在普通用户工作区对可见版本执行同一预览和派生流程。
- `configurable-training-parameters`: 方法目录增加算法说明、适用边界、参数标签和参数含义；参数身份与实际训练配置保持不变。
- `ide-report-consumption`: 增加报告生成命令向导和 CI 打包入口，同时保持扩展只读、不执行生成命令。

## Impact

- 后端：新增用户预测批次与记录表、用户预测服务和路由；扩展清洗预览响应；扩展训练方法目录字段。
- 前端：新增“模型试算”导航与结果页，扩展“我的数据”入口、清洗对比图和训练算法库。
- 工具与 CI：VS Code 扩展升级到 `0.2.0`，新增命令生成测试和 VSIX 打包工作流。
- 兼容性：旧模型、旧训练与单条预测接口继续可用；无用户所有者的数据仍按共享资源处理。
