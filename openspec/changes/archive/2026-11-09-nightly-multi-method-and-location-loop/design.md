# 设计

## Context

现有训练链路由 `TrainingTaskService` 接受单一 `method`，落地为一个 `training_task` 行；`TrainingExecutor` 调用 `artifacts.build_run`，运行配置里的 `model` 是方法注册表里的冻结 `params`，加载校验要求二者完全相等。`deep.py` 的训练循环按固定 epoch 执行但不保留损失历史。管理端比较页只并列已登记模型。PR 候选由 `candidate.py` 的 Python AST 规则产生，只有位置和证据。离线报告 `pr-check-report` 读取已导出的分析包，没有从仓库提交直接采集与推理的入口。行级实验脚本 `line_train.py` 能训练和报告指标，但报告依赖临时路径与临时脚本。

## Goals / Non-Goals

- Goal：一次提交多方法实验，同一数据/切分身份，参数受控且可核对，真实训练过程可见，结果可比较、可导出、可显式登记。
- Goal：旧方法与旧产物继续按原冻结参数校验，既有运行身份不变。
- Goal：提交触发分析在本地可复现，CI 示例非阻断；IDE 只读消费并核对身份。
- Non-Goal：自动超参数搜索、按测试指标选冠军、任意 estimator 或服务端路径参数。
- Non-Goal：把行级研究模型接入用户主流程，或把提交风险分改写成缺陷概率。
- Non-Goal：自动应用修复补丁、自动评论 PR、自动合并或部署。

## Decisions

### D1 实验组是持久引用，不是新的训练引擎

新增 `training_experiment` 表保存数据版本、manifest 哈希、指标集、切分预设、类别策略、请求身份与创建者；`training_task` 增加 `experiment_id` 引用。每个子任务仍走既有排队、单 worker、超时、取消、重试与产物登记链。实验状态由子任务状态派生，不新增一套状态机。

理由：复用已验证的执行与恢复语义，避免两套任务生命周期不一致。

### D2 参数用版本化契约，默认运行保持旧身份

每个方法可通过 `param_specs(method)` 声明可配置参数的白名单、类型与范围。请求未提供参数时，运行配置与旧运行完全一致，不写入契约版本，runId 不变。请求显式提供参数时：

- 参数先与默认值合并、按声明校验，未知键或越界直接拒绝；
- 运行配置的 `model` 写入实际参数，并写入 `parameterContract: training-params-v1`；
- 加载校验在有契约时按声明校验实际参数，无契约时仍要求与注册表冻结 `params` 完全相等；
- 模型显示名追加参数摘要，便于区分同一方法的不同配置。

理由：满足“旧模型标识不指向另一套参数”和“配置贯通请求、数据库、worker、运行清单、加载校验与模型卡”。

### D3 逐 epoch 历史只记录真实迭代

深度分类器在 `fit` 中记录每个 epoch 的平均训练损失与耗时；训练执行把历史写入产物 `training-history.json`，并回填训练任务行。非迭代方法不生成历史，界面按方法类别显示“无逐 epoch 曲线”。验证缺失、取消或失败时保留已产生的历史与终态。

### D4 比较口径来自冻结运行，不重新训练

实验比较读取各子任务成功运行的 `summary.json` 事实：方法、实际参数、数据/成员指纹、三档指标、训练耗时与状态。口径不同（数据版本、manifest 哈希、切分预设、类别策略或指标集不同）时明确标记不可直接比较。导出为带格式版本的 JSON。

### D5 修复建议是规则模板，不是补丁自动生成

每条候选按规则 ID 映射到确定性的建议：问题证据、建议修改位置、理由、必要的人工确认项、可选的前后示例。只有语义明确的规则（可变默认参数、裸 except、eval/exec）给出示例；无充分上下文不生成补丁。建议加入既有问题/结论草稿，保留确认、驳回、暂缓与恢复。

### D6 提交触发分析只做本地真实链路

新增 `pr-check-analyze`：接受本地仓库路径、base/head、模型键或已登记模型身份；采集 diff 与文件内容、执行真实特征提取、加载受控模型推理、复用候选规则，输出报告并记录仓库 revision、身份和覆盖。同一仓库/提交/模型的内容哈希幂等；缺模型、schema 不匹配、无变更、远端限流和取消有明确退出码。CI 示例只在检出仓库上运行该命令，不访问本机回环服务。

### D7 IDE 扩展消费稳定报告契约

扩展显式导入 JSON 报告，核对报告中的仓库、SHA、路径与行号；不匹配或过期时显示状态而不在错误版本上标注。报告内容一律视为不可信数据，不执行其中的代码或命令。扩展只读，不修改源码。

## Risks / Trade-offs

- 参数契约扩大运行配置体积；通过只记录实际参数和契约版本控制。
- 多方法实验增加排队时间；沿用单 worker，界面显示排队位置与部分成功，不并发训练。
- 深度历史增加产物大小；只保存 epoch 级聚合值。
- 提交触发分析在大型仓库上耗时；命令支持范围限制并在文档中说明成本，不做后台常驻。
- IDE 扩展只做只读冒烟；无法启动宿主时如实记录缺口。

## Migration Plan

- 迁移 033：新增 `training_experiment` 表；`training_task` 增加 `experiment_id`、`params_json`、`history_json` 列与索引。前向增量，不改写既有行。
- `catalog-init` 先备份再迁移；旧任务参数与历史为空时显示“未记录”，不推断。
