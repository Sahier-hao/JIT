- [x] 2.2 保护已入队任务：取消批次不级联取消单 PR 任务；验证批次已取消后，个别任务仍能完成并显示结果

## 3. 已完成 PR 换模型重新分析

- [x] 3.1 单 PR 分析接口对已完成结果支持显式传入不同兼容模型并创建新分析；验证旧结果保留、新结果记录独立模型身份
