# Spec Delta

## ADDED Requirements

### Requirement: IP-19 侧栏导航唯一活动项

用户工作区侧栏同一时刻 MUST 至多有一个导航项标记为当前页。“项目” SHALL 只在项目列表、新建项目、项目详情、分支分析、分析对比、“我的审查”以及带项目身份的项目内 PR 工作单上高亮；在“我的数据”“我的训练”“我的模型”“个人中心”“站内提醒”以及不带项目身份的全局 PR 工作单上 MUST NOT 高亮。

#### Scenario: 用户自助工作区
- **WHEN** 用户打开“我的数据”“我的训练”“我的模型”或个人中心
- **THEN** “项目”不显示为当前页，对应导航项最多只有一个处于选中态

#### Scenario: 项目与审查路由
- **WHEN** 用户打开项目列表、项目详情、分支分析、分析对比或“我的审查”
- **THEN** “项目”显示为当前页

#### Scenario: 项目内 PR 工作单
- **WHEN** 用户从项目进入某个 PR 工作单，或直接打开不带项目身份的全局 PR 工作单
- **THEN** 前者点亮“项目”，后者不点亮任何项目导航项

#### Scenario: 刷新与直达
- **WHEN** 用户在任一上述地址刷新或从书签直达
- **THEN** 活动项与地址一致，不出现双高亮
