## MODIFIED Requirements

### Requirement: PPT-02 快照、意图与任务复用

后台发现 SHALL 读取真实开放 PR 并固定 base/head 快照。分析意图 SHALL 由基项目、PR、快照、真实模型与评分契约共同确定；同快照同模型 MUST 复用在途或成功任务，显式更换模型或新快照才产生新意图。PR 任务 MUST NOT 改变项目当前分支结果。批量分析 SHALL 是可查询的持久批次：从远端分页获取完整开放范围并固定真实兼容模型；逐条刷新快照后复用或入队，区分待处理、已入队、复用、失败和跳过，进度 MUST 使用实际入队与复用数量。发现不完整、部分失败或服务重启 MUST 如实显示，MUST NOT 冒充全部完成；重复发起 MUST 返回活动批次，用户 MUST 能只重试失败项。PR 分析任务 SHALL 独立显示，状态 MUST 如实呈现排队、分析中、完成、失败、取消与中断。

#### Scenario: 重复检查同一快照

- **WHEN** 同一 PR 快照与模型已有在途或成功任务
- **THEN** 不重复入队，复用原任务或结果

#### Scenario: 作者推送新版本

- **WHEN** 远端 head 变化形成新快照
- **THEN** 产生新意图并排队，旧结果保留为历史

#### Scenario: 显式更换自动模型

- **WHEN** 用户明确更换项目自动模型
- **THEN** 同快照下产生新意图，旧模型结果仍可读且不覆盖当前分支结果

#### Scenario: 批量分析全部 PR

- **WHEN** 用户选择模型并确认「分析全部 PR」
- **THEN** 批次从远端分页获取开放 PR 快照，并返回可查询的批次标识
- **AND** 已成功且快照未变化的 PR 复用结果，其余按规则入队；进度显示实际入队、复用与失败数量

#### Scenario: 无本地缓存或超过一页

- **WHEN** 项目从未检查过 PR，或开放 PR 超过一页
- **THEN** 批次读取全部远端分页，不把本地缓存当作完整清单

#### Scenario: 发现范围中断

- **WHEN** 获取开放 PR 清单中途失败
- **THEN** 批次标记范围未完整获取，不显示「全部完成」，已处理条目仍可核对

#### Scenario: 部分成功与失败重试

- **WHEN** 批次中部分 PR 入队或复用成功、部分失败
- **THEN** 逐条显示实际状态，失败项提供仅重试失败项的入口，成功项不重复入队

#### Scenario: 模型失效

- **WHEN** 批次固定的模型在提交或重试时停用或不可用
- **THEN** 对应条目明确失败，不替换为其他模型

#### Scenario: 重复点击批次入口

- **WHEN** 同一项目已有活动批次时再次点击「分析全部 PR」
- **THEN** 返回同一批次及其真实进度，不创建重复活动任务

#### Scenario: 中断任务

- **WHEN** 服务停止导致 PR 分析或批次未完成
- **THEN** 记录显示「已中断」或「待恢复」，不显示「分析中」，可重新发起批量分析补齐
