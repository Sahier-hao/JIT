# Spec Delta

## ADDED Requirements

### Requirement: PEX-12 模板化中文摘要与旧解释兼容

仓库提交解释 SHALL 在成功生成时附带由本次已保存贡献项生成的模板化中文摘要，说明哪些特征推高或拉低对应单位。摘要 MUST 只使用已保存贡献项与既有中文显示名，MUST NOT 补充未出现的特征、推断缺陷原因或自由生成结论。

#### Scenario: 新解释生成摘要

- **WHEN** 成功生成遮挡或 log-odds 解释
- **THEN** 摘要使用贡献项中的中文特征名和方向，不包含未出现在贡献列表中的特征
- **AND** 原方法、单位、基线来源、稳定性与保存路径保持不变

#### Scenario: 旧解释没有摘要字段

- **WHEN** 读取早于本字段的已保存解释
- **THEN** 前端回退到原解释摘要，不重新推理、不改写历史 payload、不替换模型

#### Scenario: 排序不稳定

- **WHEN** 已保存稳定性为不稳定
- **THEN** 摘要明确标注排序不稳定，不把首位特征表述为确定主因
