# 界面呈现

## ADDED Requirements

### Requirement: IP-18 项目详情页的双栏工作台

项目详情页在宽视口（≥1400px）下必须（MUST）把内容分为主栏与窄栏：主栏承载「当前分析结果」与「分析记录」，窄栏承载「仓库更新」与「发起分析」。页头必须（MUST）保持通栏。

窄栏宽度必须（MUST）固定为 360px，且不得（MUST NOT）通过缩小字号来适配；其内部内容必须（MUST）改为纵向堆叠——状态带按「图标 + 文本」两列排布，统计项按标签左、值右逐行排列，表单字段单列。

视口小于 1400px 时页面必须（MUST）回到单列，阅读顺序为「仓库更新 → 发起分析 → 当前分析结果 → 分析记录」，且不得（MUST NOT）出现横向溢出。

#### Scenario: 宽屏分栏

- **WHEN** 视口宽度为 1873px 或 1440px
- **THEN** 「当前分析结果」与「分析记录」位于左侧主栏，「仓库更新」与「发起分析」位于右侧窄栏
- **AND** 页头横跨两栏，两个深色主按钮仍为「打开审查」与「开始分析」

#### Scenario: 窄栏内的状态带

- **WHEN** 窄栏宽度为 360px
- **THEN** 状态带标题与说明各占一行，图标在标题左侧
- **AND** 三项统计逐行排列，标签在左、值在右
- **AND** 结论文字不出现逐字竖排

#### Scenario: 窄屏回退

- **WHEN** 视口宽度为 1280px 或 390px
- **THEN** 页面为单列，顺序与分栏前一致
- **AND** 区块之间保留间距，页面没有横向溢出

#### Scenario: 窄栏吸附

- **WHEN** 视口宽度 ≥1400px 且分析记录长于一屏
- **THEN** 向下滚动时窄栏保持在可视区内
- **AND** 主栏内容不被窄栏遮挡
