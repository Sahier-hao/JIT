# Proposal

## Why

用户实看上一版后明确要求删除团队凭证及无用入口。三空间仍围绕旧能力堆叠，首屏只剩凭证拦截，实验室存在多层导航和重复标题；这次以项目分析的完整任务重新组织界面。

## What Changes

- **BREAKING**：彻底删除团队 Bearer 凭证、成员/管理员角色与配置，HTTP API 无凭据直接按业务规则工作；本机监听和模型/输入/持久化准入不变。
- **BREAKING**：删除手工预测、模型目录管理、按编号重开、交互演示及连接设置的产品页面；旧链接明确说明入口已撤下，不假装仍有对应工作流。服务端模型/预测存档能力供实际分析及维护使用，数据不删除。
- 产品以项目首页—接入/分析状态—固定分析提交—详情/审查计划为主线，验证报告是次级独立入口。主题改为轻量偏好控件，没有设置空间。
- 重做视觉与层级：简洁导航、清楚的标题/主操作、标题优先的提交列表、渐进披露来源、单一详情面板；移除重复标题、默认展开技术身份和无关工具。
- 保留固定分析身份、稳定检索、真实异步阶段、来源/分数边界与计划隔离；测试随已删除功能退役，核心行为继续验证。

## Capabilities

### New Capabilities

- `focused-project-review`: 无凭证的项目主线、次级验证报告、退役入口和一致的任务界面。

### Modified Capabilities

- `team-api-access`: 退役成员/管理员凭证能力，由本机无凭证业务访问取代。
- `model-prediction-workbench`: 退役独立浏览器模型登记、手工预测与批次重开产品；底层业务 API 与已有结果保留。
- `workspace-navigation`: 改为项目与报告，删除连接设置与三空间要求，旧已删除入口明确退役。
- `interface-presentation`: 新增聚焦任务、首屏与渐进披露约束。
- `commit-risk-review`: 仓库审查为主，演示入口明确退役，公开历史归入报告。
- `defect-trend-dashboard`: 将实验室历史入口改为独立验证报告。

## Impact

后端移除鉴权模块并保留错误/诊断中间件，OpenAPI 删除认证要求。前端删除凭证上下文、旧工具页面和专属样式，重构 App/导航/请求层/首页/接入/审查。需求、设计、运行说明与测试按新范围更新。旧冻结证据/历史模型/数据库保留，源代码回退基线为干净提交 `1531e4c`。

本次用户明确要求实际删除并重构，规划文件是实施依据，不再单独等待开始授权。新证据不自动冻结，新旧 change 不自动归档。
