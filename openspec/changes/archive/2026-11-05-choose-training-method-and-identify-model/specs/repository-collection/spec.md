## MODIFIED Requirements

### Requirement: RCL-09 同步产物串联打分，并允许用户选择打分模型

同步成功后系统 SHALL 把采集产物登记为数据集版本并给提交打分。创建时可选择自动、只用兼容现成模型或强制训练；自动与强制训练 MAY 选择已注册、兼容且依赖可用的方法，缺省逻辑回归，选择现成模型时 MUST NOT 指定方法。方法 MUST 在创建时校验并固定，不满足 schema、输入宽度或依赖时 MUST 拒绝，MUST NOT 静默替换。自动判定按训练窗口提交数与正例数，样本不足且有默认模型时 MUST 降级并注明原因与“未在该仓库验证”；降级 MUST NOT 声称使用所选方法训练。强制训练无法切分时 MUST 失败。训练 MUST 以最新提交前 90 天为截止，分区统计 MUST 与真实成员一致。失败 MUST 保留数据集版本，MUST NOT 覆盖既有版本或模型身份。作业、结果与重试 MUST 保留方法身份，方法不可用 MUST 明确失败并要求重选。

#### Scenario: 自动模式按数据量选择

- **WHEN** 用户未指定打分模型来源并提交同步
- **THEN** 系统在采集完成后按训练窗口的提交数与正例数决定训练或降级
- **AND** 作业记录实际执行的路径与判定依据，界面能说明为什么没有训练

#### Scenario: 数据充足时训练并使用本仓库模型

- **WHEN** 采集完成且训练窗口内的提交数与正例数达到门槛
- **THEN** 使用该数据集训练模型、完成准入登记，并用它给该来源的提交打分
- **AND** 训练、验证与测试分区不包含截止时间及之后的近期提交

#### Scenario: 使用所选方法训练

- **WHEN** 用户在自动或强制训练中选择一个已注册且兼容的方法
- **THEN** 训练使用该方法，产物与模型登记记录该方法身份
- **AND** 结果页面显示实际方法与训练指标，不把它表述为逻辑回归

#### Scenario: 未选择方法

- **WHEN** 用户发起自动或强制训练但没有选择方法
- **THEN** 使用逻辑回归，作业与结果标明该默认方法

#### Scenario: 方法不兼容或依赖缺失

- **WHEN** 所选方法与当前 schema、输入宽度不兼容，或运行依赖未安装
- **THEN** 创建请求被拒绝并说明原因，不创建作业，也不改用其他方法

#### Scenario: 自动降级时不伪造方法

- **WHEN** 自动模式因样本不足降级使用现成模型
- **THEN** 作业仍完成并注明实际模型与降级原因
- **AND** 不声称已使用用户选择的训练方法训练

#### Scenario: 近期提交不参与训练

- **WHEN** 采集结果同时包含截止时间之前和之后的提交，且策略允许训练
- **THEN** 近期提交仍获得本次模型的风险分数，但不出现在训练、验证或测试分区
- **AND** 产物记录的截止时间、可训练样本数、分区数量与真实成员一致

#### Scenario: 样本不足时降级使用兼容模型

- **WHEN** 自动模式下训练窗口的提交数或正例数低于门槛，或时间切分后的测试段没有正例
- **THEN** 作业仍完成，改用提交任务时绑定的、已启用且特征口径兼容的默认模型打分；绑定模型不可用则明确失败
- **AND** 作业与界面注明实际使用的模型、降级原因，以及该模型未在此仓库验证、不展示公开数据集的测试指标

#### Scenario: 用户强制训练但样本偏少

- **WHEN** 用户选择强制训练而训练窗口的提交数或正例数低于建议门槛
- **THEN** 只要时间切分能得到训练集与测试集的两类标签，系统仍执行训练并完成登记
- **AND** 结果页显著标注训练区实际提交数、正例数与指标波动风险

#### Scenario: 强制训练无法切分时失败

- **WHEN** 用户选择强制训练，而时间切分后训练集或测试集缺少某一类标签
- **THEN** 作业失败并说明数据量不足、无法完成时间切分，建议改用特征口径兼容的既有模型
- **AND** 不通过扩大训练范围或加入近期提交来规避失败

#### Scenario: 训练失败但保留数据

- **WHEN** 数据集登记成功而训练或打分失败
- **THEN** 数据集版本仍可查询，作业如实说明未产出可用模型

#### Scenario: 没有兼容模型时明确失败

- **WHEN** 数据不足以训练且用户选择只用既有模型，但模型目录中不存在特征口径兼容的可用模型
- **THEN** 请求或作业失败并说明缺少可用默认模型，不产出没有模型来源的风险列表

#### Scenario: 按原方法重试

- **WHEN** 用户对失败作业按原参数重试
- **THEN** 新作业保留原方法与方法身份
- **AND** 原方法已不可用时明确失败并提示重新选择，不自动换成默认方法

#### Scenario: PR 分析复用特征并跳过重复登记

- **WHEN** PR 分析的目标提交均已有可复用特征，且本次不训练
- **THEN** 分析使用已保存特征完成打分，不重复登记相同数据集版本
- **AND** 记录固定模型、特征来源与打分覆盖，界面不把跳过登记表述为采集失败

#### Scenario: 分支分析仍登记独立数据集

- **WHEN** 用户发起分支分析
- **THEN** 采集产物仍登记为新的数据集版本，即使部分提交可复用既有特征
- **AND** 不因 PR 分析的跳过规则改变分支分析的登记与训练行为
