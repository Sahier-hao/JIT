# Spec Delta

## ADDED Requirements

### Requirement: ADM-05 管理员模型策略操作

管理工作区 SHALL 提供默认模型、启用及停用操作，显示已校验、不可用、已停用和默认标记。策略写入 MUST 要求有效管理员会话并检查来源，普通用户仅能读取必要选择元数据。界面 SHALL 说明停用对新任务及历史结果的影响，提供确认、取消、保存中和失败恢复反馈。

#### Scenario: 完成设置和停用
- **WHEN** 管理员将另一兼容模型设为默认，再确认停用旧模型
- **THEN** 页面显示真实保存状态，默认模型的停用按钮不可用；停用说明告知历史保留、未开始使用模型的任务失败及已开始使用的任务可完成

#### Scenario: 未登录或跨来源写策略
- **WHEN** 未登录、会话到期或未经允许来源直接调用策略更新
- **THEN** 服务端分别拒绝会话或来源，不因页面按钮隐藏而省略校验，不保存更改

#### Scenario: 取消停用或保存失败
- **WHEN** 管理员取消确认，或保存遇到业务冲突、存储或网络错误
- **THEN** 取消不发送策略写入；保存失败展示原因且不显示成功状态，用户可以刷新记录后重试
