# Spec Delta

## MODIFIED Requirements

### Requirement: AWW-03 数据集详情与训练入口

数据集页 SHALL 展示数据集版本、schema、时间范围、纳入/正例/排除统计、字段缺失、来源、文件哈希和简化标签限制。管理员 SHALL 能从明确选择的版本和方法创建训练任务，请求 MUST 使用固定数据集版本且不得接受任意路径。数据集页 SHALL 提供清洗入口：可预览配方影响、生成不可变派生版本、查看来源与派生谱系、对比前后差异并导出派生数据；派生版本 MUST 作为独立版本出现在列表和训练入口中。

#### Scenario: 查看大型仓库数据集

- **WHEN** 管理员打开由仓库采集生成的数据集版本
- **THEN** 可核对提交数量、正例、时间范围、来源、schema、哈希和两条数据限制

#### Scenario: 从数据集发起训练

- **WHEN** 管理员选择数据集版本、已注册方法和指标集
- **THEN** 创建训练任务并跳转或显示对应任务状态，不复制或修改数据集

#### Scenario: 数据集不可训练

- **WHEN** 描述文件不可用、schema 不兼容或方法未注册
- **THEN** 页面显示可定位失败且不显示成功或示例指标

#### Scenario: 清洗并生成派生版本

- **WHEN** 管理员在数据集页预览配方并确认生成
- **THEN** 页面显示派生版本、来源谱系、前后统计和可用的训练入口
- **AND** 原版本仍可按原样查看和训练
