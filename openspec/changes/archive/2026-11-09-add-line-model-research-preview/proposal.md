# 行级模型研究预览

## Why

行级实验已经产出可复现的指标与结论：TypeScript 跨仓库留出时 PR-AUC 约 0.706（测试集正例率 0.523），但信号弱、校准不足，不能作为通用逐行概率或进入项目分析主流程。当前产品只展示提交级风险与静态规则候选，用户无法查看已完成的真实行级实验，也无法亲手验证模型行为。

用户明确要求把行级模型作为“明确标注的研究预览”单独接入。目标是在不污染模型目录、不改变提交级口径、不影响项目与 PR 分析的前提下，提供一个可复现、可试用的独立研究页面。

## What Changes

- 新增可移植的行级研究模型导出：从固定实验配置训练紧凑逻辑回归，导出特征名、系数、截距、输入哈希、切分与留出指标到 JSON；不生成 pickle，不登记模型目录。
- 新增只读研究接口：读取并校验研究模型元数据；对粘贴的 TypeScript 代码按行打分并返回排序；不持久化请求或结果。
- 新增独立前端页面 `#/research/line-model`：产品页提供入口，页面明确标注“研究预览、非缺陷概率、不参与项目分析”，同时展示训练/留出口径、指标和限制。
- 边界：研究预览不出现在模型目录、默认模型、项目模型选择和 PR 分析中；不改提交级风险分数；不改变现有行级实验与主规格中“暂不产品化”的研究结论。

## Capabilities

### Modified Capabilities

- `line-level-prediction`：允许在明确标注、与主流程隔离的前提下提供行级模型研究预览，并约束其数据来源、接口、页面与不可登记性。

## Impact

- 后端：新增 `line_features` 共享特征口径、`line_preview` 只读服务与研究路由；`line-train` 增加可移植系数导出参数。
- 前端：新增研究预览页、路由、客户端与样式；产品介绍页增加独立入口。
- 数据：新增 `backend/research/line-model-v1.json` 研究产物与固定实验报告 `P1-compact.json`；不写目录库、不写模型目录。
- 文档：补充研究预览审计与产品口径。
