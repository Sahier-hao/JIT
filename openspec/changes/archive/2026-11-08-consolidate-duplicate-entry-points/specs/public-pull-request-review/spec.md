## ADDED Requirements

### Requirement: PPR-07 待处理 PR 栏

PR 审查页 SHALL 以左侧清单作为唯一完整 PR 列表；右侧栏 MUST NOT 复制完整清单，只 SHALL 展示需要处理的子集：分析中、需处理失败、尚无分析的 PR，并为每项沿用左侧的真实状态、模型与时间。右栏为空时 SHALL 说明「没有待处理 PR」，不得用已完成 PR 填充。两侧点击进入同一固定快照工作流时 MUST 保留项目上下文。

#### Scenario: 只列待处理

- **WHEN** 当前页同时存在已完成、分析中、失败和尚未分析的 PR
- **THEN** 右栏只显示分析中、失败和尚未分析的 PR
- **AND** 已完成的 PR 只出现在左侧完整清单

#### Scenario: 没有待处理

- **WHEN** 当前页的 PR 全部已完成
- **THEN** 右栏显示「没有待处理 PR」，不重复列出已完成项

#### Scenario: 进入同一工作流

- **WHEN** 用户从右栏打开一个待处理 PR
- **THEN** 进入该 PR 的固定快照或工作单，项目上下文与左侧入口一致

### Requirement: PPR-08 可寻址的只读预览模式

PR 工作单地址 SHALL 支持显式的只读预览模式（`mode=preview`）。已有个人工作单时，用户 SHALL 能从工作单返回该 PR 的只读预览；只读模式 MUST NOT 创建或改写个人草稿，MUST NOT 隐藏当前工作单的状态。只读模式中的创建入口在已有工作单时 SHALL 变为「进入工作单」，不得再创建第二份工作单。

#### Scenario: 从工作单查看只读版本

- **WHEN** 用户在工作单点击「查看只读版本」
- **THEN** 地址带上只读模式参数并展示该快照的只读预览
- **AND** 个人草稿、阅读进度和问题不被修改

#### Scenario: 刷新保持只读

- **WHEN** 用户在只读模式下刷新页面
- **THEN** 仍停留在只读预览，不自动进入工作单

#### Scenario: 已有工作单

- **WHEN** 只读模式的 PR 已有个人工作单
- **THEN** 主操作显示「进入工作单」，点击后回到原工作单
