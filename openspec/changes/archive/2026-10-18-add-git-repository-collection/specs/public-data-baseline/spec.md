# Spec Delta

## MODIFIED Requirements

### Requirement: PDB-01 公开数据来源与完整性

系统 SHALL 为固定公开项目或仓库采集产出的派生数据集引用已登记的数据集描述文件，由该文件提供发布者、原始地址、不可变版本、文件校验值、引用、字段定义和数据质量统计；采集产出的数据集还 MUST 记录仓库标识、采集范围与采集器版本。运行声明 MUST 记录所用描述文件及其校验值。文件校验不匹配、提交标识重复、必需时间或选用特征无效 MUST 阻止生成可用基线，不得静默修补身份、删除失败记录或改用合成数据。

#### Scenario: 核验指定版本
- **WHEN** 获取的公开文件与锁定版本和校验值一致，必需数据通过校验
- **THEN** 来源记录包含原始及纳入记录数、排除规则与各规则数量，并能定位原始文件及字段依据

#### Scenario: 数据内容不符合约定
- **WHEN** 文件校验值不一致，或纳入记录包含重复标识、无效时间、缺失或非有限选用特征
- **THEN** 处理失败并给出可定位的原因，不产生标为可用的新模型或实验记录

#### Scenario: 描述文件缺失或与来源不符
- **WHEN** 运行声明引用的数据集描述文件不存在，或其校验值与运行声明记录不同
- **THEN** 处理失败并给出可定位原因，不退回内建常量或改用其它数据集

#### Scenario: 采集来源可追溯

- **WHEN** 数据集由仓库采集产出
- **THEN** 描述文件记录仓库标识、采集范围与采集器版本，且可按这些字段复核来源

### Requirement: PDB-02 特征与标签语义独立

系统 SHALL 从注册的具名特征 schema 取模型输入：首轮 schema `openstack-six-v1` 为发布者的 ns、nd、nf、ent、la、ld 六字段；后续 schema（如 `kamei14-v1`、`kamei14-git-v1`）按注册表逐字段声明来源列、语义核验状态、是否入模与变换方式。系统 MUST 记录字段原始语义，且 MUST NOT 把未注册的字段宣称为完整 Kamei14。标签 SHALL 按已核验发布者规则或已登记的 SZZ 规则转换并标明其历史观测性质；标识、时间、bugcount、fixcount、审查结果与耗时 MUST 不进入模型输入。原始缺失度量不得伪装成测量值：来源缺少 schema 声明为必需字段的行 MUST 显式排除并记录数量与原因，不得以零值或推算值填补；仅当发布者规则或 SZZ 规则本身定义了该空缺的取值时才可作例外，并 MUST 作为规则记录且不得推广到计数或间隔类字段。采集来源下由仓库历史计算的字段 MUST 记录其计算口径，不得与发布者列混称。

#### Scenario: 形成首轮输入与评价标签
- **WHEN** 转换通过校验的发布者数据，并声明当前运行的 schema
- **THEN** 模型输入仅含该 schema 声明为入模的字段及其变换结果，标签与身份、时间和原始度量单独保存
- **AND** 标签记录解释 bugcount 大于零为观测到的缺陷引入，空值与零按发布者规则作为未观测到缺陷引入，不称为已证实无缺陷

#### Scenario: 标签或字段含义无法确定
- **WHEN** 标签出现约定之外的值，或字段被要求替换成含义不同的经验或审查字段
- **THEN** 处理停止并报告不兼容，不通过填零、猜测别名或增加输入列继续训练

#### Scenario: 来源缺少必需字段

- **WHEN** 某些纳入候选的行缺少 schema 声明为必需的字段
- **THEN** 这些行被显式排除，并记录排除数量与原因，产物中不出现被零值补齐的该字段

#### Scenario: 采集来源的字段可用性

- **WHEN** 数据集由仓库采集产出，且 schema 将某字段声明为可用
- **THEN** 该字段由仓库历史计算并带计算口径，不再标记为不可得
