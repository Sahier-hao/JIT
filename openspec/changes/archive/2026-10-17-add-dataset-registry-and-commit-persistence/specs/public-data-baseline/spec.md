# Spec Delta

## MODIFIED Requirements

### Requirement: PDB-01 公开数据来源与完整性

系统 SHALL 为固定公开项目引用已登记的数据集描述文件，由该文件提供发布者、原始文件地址、不可变版本、文件校验值、引用、字段定义和数据质量统计；运行声明 MUST 记录所用描述文件及其校验值。文件校验不匹配、提交标识重复、必需时间或选用特征无效 MUST 阻止生成可用基线，不得静默修补身份、删除失败记录或改用合成数据。

#### Scenario: 核验指定版本
- **WHEN** 获取的公开文件与锁定版本和校验值一致，必需数据通过校验
- **THEN** 来源记录包含原始及纳入记录数、排除规则与各规则数量，并能定位原始文件及字段依据

#### Scenario: 数据内容不符合约定
- **WHEN** 文件校验值不一致，或纳入记录包含重复标识、无效时间、缺失或非有限选用特征
- **THEN** 处理失败并给出可定位的原因，不产生标为可用的新模型或实验记录

#### Scenario: 描述文件缺失或与来源不符
- **WHEN** 运行声明引用的数据集描述文件不存在，或其校验值与运行声明记录不同
- **THEN** 处理失败并给出可定位原因，不退回内建常量或改用其它数据集

### Requirement: PDB-07 运行记录可追踪与复现

系统 SHALL 为可用基线记录所用数据集描述文件及其校验值、字段与标签规则、纳入规则、分区清单、预处理与模型参数、环境版本、模型校验值、风险结果、评价与限制，并以运行标识关联。使用相同输入、规则和锁定环境重跑 MUST 得到相同分区与在约定数值误差内一致的风险和指标；检查报告必须区分真实结果与测试夹具。

#### Scenario: 复现固定基线
- **WHEN** 按记录命令使用相同数据、配置和锁定环境重新处理、训练及评价
- **THEN** 分区成员一致，风险和已定义指标在记录容差内一致，并有独立比较证据

#### Scenario: 上下文变化或记录不全
- **WHEN** 数据、字段规则、模型或产物发生变化，或关联校验值缺失
- **THEN** 新上下文不能沿用旧记录冒充同一可用运行，缺少必要证据的产物不得标为可用

#### Scenario: 运行声明缺少描述文件校验值
- **WHEN** 运行记录没有数据集描述文件或其校验值
- **THEN** 该运行不得标为可用，也不得用当前代码常量补全记录
