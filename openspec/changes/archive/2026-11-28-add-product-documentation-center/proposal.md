# Proposal

## Why

首次使用者需要从产品首页找到可执行的审查教程，已有用户需要在分数、代码线索、私有仓库和模型兼容等具体场景中得到可检索的答案。当前知识分散在历史 Markdown 与页面文案中，部分内容已过期，且没有与当前界面共享发布节奏的公开入口。

## What Changes

- 新增公开文档路由 `#/docs` 与 `#/docs/:slug`，匿名可读，不依赖项目、模型或报告接口。
- 文档首页突出《完成第一次 PR 审查》，并提供「快速开始」「使用指南」「背景知识」「常见问题」四组真实文章入口。
- 桌面文章页采用左侧章节、中间正文、右侧本页目录；窄屏折叠章节导航，正文、表格、图片和代码在 390px 宽度下可读且不产生页面级横向滚动。
- 使用 `#/docs/:slug?section=<id>` 定位稳定小节；小节链接支持直接打开、刷新、前进后退和无效小节提示。
- 提供本地中文搜索，覆盖标题、小节、正文和常用同义词；标题与小节匹配优先，结果显示上下文并可直接定位。
- 以 `frontend/content/docs/` 中的 Git Markdown 为唯一正文来源，通过发布清单控制纳入构建的文章、导航和搜索范围，不引入管理员、私有仓库或真实账号内容。
- 在公开首页和登录后的工作区提供「文档」入口，并在分支分析、PR 预览／工作单和模型评估接入直达相关小节的上下文帮助。
- 首版交付 9 篇中文文章，操作步骤以当前界面、真实模型身份、标签成熟度、私有仓库条件和失败反馈为准。

## Capabilities

### New Capabilities

- `product-documentation`: 公开产品文档的发布来源、路由、阅读布局、小节定位、中文搜索、内容范围和业务页面上下文帮助。

### Modified Capabilities

- `workspace-navigation`: 在公开首页和登录工作区增加可发现的文档入口，并保证文档地址可独立刷新与分享。

## Impact

- 前端：新增文档内容目录、文档功能模块、公开路由、搜索与帮助组件；调整首页与工作区页头入口。
- 内容：新增 9 篇受发布清单管理的中文 Markdown 文章，并提供维护说明。
- 构建与测试：文档正文随 Vite 构建打包；新增路由、小节链接、搜索、未知文章、响应式布局和帮助入口测试。
- 权限：文档匿名可读；现有登录、项目、模型、管理员和数据权限不变。
