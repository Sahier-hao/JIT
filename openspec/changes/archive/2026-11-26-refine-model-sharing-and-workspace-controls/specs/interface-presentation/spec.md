## MODIFIED Requirements

### Requirement: IP-22 仓库更新入口

仓库更新与自动检查必须（MUST）以项目页签栏右侧的单一入口呈现，入口包含图标、固定文案「检查分支更新」与当前状态词；入口不得（MUST NOT）占据结果卡内部或结果卡下方的独立行，且 MUST 在所有项目页签可见。

点击入口必须（MUST）打开对话框，对话框内提供立即检查、自动检查开关、跟踪分支与检查频率设置、保存；触发按钮文案不得（MUST NOT）让用户误以为会同步整个仓库或拉取 main 分支。PR 列表的「刷新 PR 列表」是独立的 PR 级动作，只刷新远端 PR 列表，不拉取分支代码或运行模型。

#### Scenario: 查看仓库更新状态

- **WHEN** 用户进入任一项目页签
- **THEN** 页签栏右侧显示「检查分支更新」与当前状态词
- **AND** 最近一次检查未完成时状态词为「未完成」并使用警示色

#### Scenario: 打开更新设置

- **WHEN** 用户点击「检查分支更新」
- **THEN** 打开标题为「订阅分支更新」的对话框
- **AND** 对话框内可以立即检查、切换自动检查、修改分支与频率并保存

#### Scenario: 区分仓库检查与 PR 刷新

- **WHEN** 用户查看 PR 审查页
- **THEN** 「刷新 PR 列表」只读取远端 PR 列表
- **AND** 页面说明它不拉取分支代码、不运行模型；实际采集与打分仍由「分析分支提交」发起

### Requirement: IP-25 趋势视图的读数、覆盖与折叠数据表

趋势视图 SHALL 先给结论性读数，再给图，最后给可核对的明细：读数以一行四格呈现（已分析提交、平均风险分、高分提交、高分占比），每格带单位或一句说明。未证明覆盖的时间段 MUST NOT 被画成 0 或连线跨越，MUST 在图上以底纹加文字标注，并在图上方用一句文字说明有多少时间段有已评分提交、多少未证明覆盖；不得（MUST NOT）再单独呈现无语义的覆盖色带。逐周数据表 SHALL 默认折叠，一次激活即可展开，且 MUST NOT 与图争夺首屏。

当已评分提交少于最小样本时，页面 SHALL 明确说明趋势只能作为个别记录，不足以判断风险升降。当所有时间段的「高分占比」都不可用时，页面 MUST NOT 渲染整块空比例图，SHALL 改为紧凑说明并保留逐周数据；高风险或无评分缺口的标注 MUST 区分「无已评分提交」与「比例不可用」，不得把样本不足误写成没有提交。

#### Scenario: 只有部分时间段有样本

- **WHEN** 趋势视图的时间窗内只有少数时间段含已评分提交
- **THEN** 页面给出四格读数与一句覆盖说明
- **AND** 图上没有样本的时间段显示为底纹与「无已评分提交」，不是 0 值连线
- **AND** 页面不出现无语义覆盖条带

#### Scenario: 已评分样本少于最小样本

- **WHEN** 已评分提交总数少于最小样本
- **THEN** 页面显示样本不足提示，说明只能作为个别记录
- **AND** 平均风险分仍按已评分提交计算并标明样本数

#### Scenario: 高分占比整体不可用

- **WHEN** 所有时间段的高分占比都因样本不足或规则不满足而不可用
- **THEN** 页面不渲染空的比例折线图，改为紧凑说明
- **AND** 逐周数据仍可展开查看每个时间段的计数与空值原因

#### Scenario: 展开逐周数据

- **WHEN** 用户需要核对某一周的具体数值
- **THEN** 一次激活展开逐周数据表，表内同时给出该周的提交数、已评分数与平均风险分
- **AND** 折叠状态下列表不占据首屏的图与读数区域

#### Scenario: 口径与来源可核对

- **WHEN** 用户需要确认时间窗、聚合方式与数据来源
- **THEN** 口径表单与来源说明在不超过一层交互内可达，且不把原始 JSON 直接铺在页面上

## ADDED Requirements

### Requirement: IP-35 模型选择、日期与确认控件

工作区 SHALL 使用统一组件承载模型选择、日期范围和不可逆操作确认，不得（MUST NOT）在业务页面直接渲染浏览器原生模型下拉、原生日期输入或调用 `window.confirm`。

模型选择器 SHALL 只列出当前用户可用且 schema 兼容的模型，按「我的模型 / 共享模型」分组；同名模型 MUST 可区分。原选模型不在可用范围时，选择器 SHALL 保留为禁用项并阻止提交，MUST NOT 静默替换为默认模型或第一个可用模型。

日期字段 SHALL 通过弹层日历选择，支持手动输入、最小/最大值、今天、清除和应用；日期仍以 `YYYY-MM-DD` 字符串参与请求。危险或不可逆操作 SHALL 使用产品内确认对话框，确认按钮文案必须说明实际后果。

#### Scenario: 选择模型

- **WHEN** 用户打开分支分析、PR 批量分析或模型试算的模型选择器
- **THEN** 只看到本人模型与管理员已开放模型中的可用兼容项
- **AND** 选择器按来源分组，不显示不可用或不兼容模型

#### Scenario: 原选模型不可用

- **WHEN** 用户打开带有原选模型的分析草稿，而该模型已停用、未开放或不再兼容
- **THEN** 选择器保留一个禁用的原选项，页面提示重新选择
- **AND** 提交按钮禁用，不自动改用默认模型

#### Scenario: 选择日期范围

- **WHEN** 用户点击趋势、审查工作台或数据构建中的日期字段
- **THEN** 打开中文日历弹层并定位到已选月份
- **AND** 可手动输入、选择今天或清除；开始日期与结束日期的先后约束生效

#### Scenario: 确认不可逆操作

- **WHEN** 用户停用共享模型、停止开放模型或导入完整草稿备份
- **THEN** 页面显示产品内确认对话框，说明结果是否保留
- **AND** 不使用浏览器原生确认框
