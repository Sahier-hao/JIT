## MODIFIED Requirements

### Requirement: PPR-07 待处理 PR 栏

PR 审查页 SHALL 以一张列表卡承载当前页的完整 PR 清单；状态筛选、排序、自动分析设置与批量分析 MUST 位于同一卡内工具条，MUST NOT 再复制一份右侧「待处理 PR」清单。状态筛选 SHALL 至少区分全部、未分析、分析中、可重试与已分析，计数只统计当前页；每行 MUST 沿用真实远端状态、模型与检查时间。筛选为空时 SHALL 说明该状态没有 PR，不影响其他状态或远端数据。右栏移除后，待处理项通过状态筛选查看，不另存一份状态。

#### Scenario: 只列待处理

- **WHEN** 用户在当前页选择「可重试」或「未分析」
- **THEN** 列表只显示对应状态的 PR
- **AND** 已完成 PR 不被复制到另一个待处理栏

#### Scenario: 没有待处理

- **WHEN** 当前页没有符合所选状态的 PR
- **THEN** 列表说明该状态没有 PR，保留筛选控件与其他状态入口
- **AND** 不伪造待处理项或重复展示其他状态的 PR

#### Scenario: 进入同一工作流

- **WHEN** 用户从列表打开一个 PR 或发起批量分析
- **THEN** 进入该 PR 的固定快照工作流或批次，项目上下文与列表入口一致
- **AND** 已保存的个人草稿不被批次或自动发现改写

#### Scenario: 按状态筛选

- **WHEN** 当前页同时存在已完成、分析中、失败和尚未分析的 PR
- **THEN** 选择「可重试」只显示失败或可重试项，选择「已分析」只显示已完成项
- **AND** 计数只统计当前页，不把其他页数量混入
