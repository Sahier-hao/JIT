# Spec Delta

## Purpose

为每次代码变更和定期完整验证提供可追溯的回归反馈，使开发者能够核对实际检查范围、失败原因及环境身份，并在不依赖个人开发数据和服务的条件下持续保护已有用户流程。

## ADDED Requirements

### Requirement: CRG-01 变更触发的关键回归

仓库 SHALL 在 PR 创建、更新、重开及主分支推送时运行独立回归检查，覆盖明确列出的关键后端测试、完整前端单元测试、类型检查、构建和扩展测试。检查 MUST 针对候选变更代码，并记录测试选择与实际执行数量；模型风险报告成功 MUST NOT 代替回归成功。

#### Scenario: PR 更新

- **WHEN** PR 新提交改变实现或测试
- **THEN** 新检查针对该候选版本执行，结果可核对提交与检查范围

#### Scenario: 关键检查失败

- **WHEN** 必需测试、类型检查或构建返回非零状态
- **THEN** 对应回归检查失败，保留错误和执行范围，不使用忽略错误或空测试冒充通过

#### Scenario: 新提交替代旧检查

- **WHEN** 相同 PR 的新版本到达且旧版本检查仍运行
- **THEN** 可取消旧版本，取消状态与新版本结果分开，不把取消视为通过

### Requirement: CRG-02 定期与手动完整回归

仓库 SHALL 提供定期及手动完整回归入口，运行完整后端、完整前端检查、扩展测试和登记的浏览器旅程。报告 MUST 区分完整与关键检查、通过、失败、取消及跳过，并列出未运行项目的具体原因。浏览器范围 SHALL 包含模型包恢复及一个固定仓库的项目分析到 PR 续审流程，使用真实隔离服务。

#### Scenario: 手动执行完整检查

- **WHEN** 开发者从工作流选择完整回归
- **THEN** 各完整检查执行并保留汇总，未执行的检查不计入通过数

#### Scenario: 浏览器依赖不可用

- **WHEN** 必需浏览器、服务或夹具无法准备
- **THEN** 对应检查明确失败并保留准备日志，不无提示跳过整个旅程

#### Scenario: 定期执行

- **WHEN** 定期触发到达
- **THEN** 对固定记录的代码版本运行完整检查，结果不依赖人工启动本机服务

### Requirement: CRG-03 干净环境与数据隔离

回归 SHALL 能从干净检出准备锁定依赖、受校验夹具和一次性数据库、模型副本及端口。检查 MUST 不依赖开发机未跟踪数据、既有账户或私有密钥，不覆盖历史证据和正式产物，不停止其他会话服务。缺少必需夹具 MUST 明确失败；确有条件限制的检查 MUST 显示限制，不能伪造完成。

#### Scenario: 空运行目录

- **WHEN** runner 仅拥有仓库检出及公开声明的依赖
- **THEN** 能按固定准备步骤运行检查，无需复制个人 SQLite 或未登记数据

#### Scenario: 端口冲突

- **WHEN** 选定端口被其他进程占用
- **THEN** 使用隔离方案或明确失败，不结束已有进程

#### Scenario: 归档保护

- **WHEN** 测试、构建或浏览器验证运行
- **THEN** 输出进入运行工作区，归档证据、主规格、归档 change 和正式模型字节保持不变

### Requirement: CRG-04 失败产物与检查身份

每次回归 SHALL 记录提交、触发类型、检查范围、环境、命令、数量与终态。检查失败后仍 SHALL 尝试保留日志、机器可读测试结果及浏览器失败追踪，并提供可定位到失败步骤的汇总。报告或产物上传失败 MUST 明确记录，不覆盖测试原始失败状态。

#### Scenario: 后端中途失败

- **WHEN** 一个后端检查返回非零或超时
- **THEN** 失败日志和已产生的测试报告仍被收集，独立检查可继续或分别报告状态

#### Scenario: 浏览器断言失败

- **WHEN** 浏览器旅程断言失败
- **THEN** 保留相关截图、追踪和服务日志，以便定位到该提交和该用例

#### Scenario: 任务被取消

- **WHEN** runner 收到取消或超时
- **THEN** 终态保留取消或超时身份，不能生成完整回归通过结论

### Requirement: CRG-05 回归权限与风险报告边界

回归 SHALL 使用完成检查所需的最小仓库权限，并允许无密钥的 fork PR 执行普通检查。工作流 MUST 不以特权事件执行外部分支代码，不部署、评论 PR、更改分支保护或按模型分数决定合并；真实测试失败可使回归检查失败，与模型风险报告保持独立。

#### Scenario: fork PR

- **WHEN** 变更来自 fork 且无仓库密钥
- **THEN** 普通回归能运行，私有凭据不可读取，不因无模型报告变量跳过回归

#### Scenario: 模型分析不可用

- **WHEN** 独立模型报告因模型包配置缺失失败
- **THEN** 回归仍按自身测试结果显示状态，不自动放行或阻断与模型分数有关的合并决策
