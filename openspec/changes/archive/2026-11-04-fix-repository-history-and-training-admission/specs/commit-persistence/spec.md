# Spec Delta

## MODIFIED Requirements

### Requirement: CMP-03 特征与标签持久化

系统 SHALL 按提交保存其 schema 声明为入模的字段值与标签；不可用字段 MUST NOT 写入，标签 MUST 记录来源规则。标签记录 MUST 区分来源算法、规则版本、二值化规则和零标签语义；有证据的正例 MUST 保存修复提交、候选引入提交、文件路径、证据时间和观察终点，同一提交的多条证据 MUST 分别保存。字段值与 schema 声明不一致 MUST 拒绝写入。来源或证据缺失的旧记录 MUST 明确标注未知，MUST NOT 从列名或二值化规则反推来源。

#### Scenario: 按 schema 写入特征

- **WHEN** 导入使用某 schema 的提交特征
- **THEN** 只有该 schema 声明为入模的字段被写入并可查询

#### Scenario: 写入不可用字段

- **WHEN** 导入包含 schema 声明为不可用的字段
- **THEN** 拒绝写入并指出该字段，不用零值或推算值替代

#### Scenario: 保存标签来源与证据

- **WHEN** 导入一个带有简化 SZZ 正例证据的提交
- **THEN** 该提交的标签保存来源算法、规则版本、二值化规则、零标签语义和正例证据

#### Scenario: 同一提交多条证据

- **WHEN** 同一提交由多个修复提交或文件产生多条证据
- **THEN** 全部证据分别保存并可查询，不因主键相同而互相覆盖

#### Scenario: 旧记录缺少来源

- **WHEN** 读取迁移前没有来源算法或证据的标签记录
- **THEN** 返回明确的未知状态，不改写原标签值，也不声称该标签已复核

### Requirement: CMP-05 提交与特征只读查询

系统 SHALL 提供按数据集版本查询提交列表与按提交标识查询单条提交及其特征与标签；列表 MUST 分页且有上限、MUST 返回总数、MUST NOT 在单次响应中携带全部特征；来源提供模块时支持按模块过滤。单条查询 MUST 返回标签来源、规则版本、二值化规则、零标签语义和全部可用正例证据；列表 MAY 只返回标签值与状态。未知标识或版本 MUST 返回明确错误，MUST NOT 返回空成功。

#### Scenario: 分页查询提交列表

- **WHEN** 请求某数据集版本下指定 limit 与 offset 的提交列表
- **THEN** 返回不超过上限的摘要项（标识、时间、标签、模块）与总数，完整特征不随列表返回

#### Scenario: 超出上限的分页参数

- **WHEN** 请求的 limit 超过声明上限、为负数或不是整数
- **THEN** 返回可定位的输入错误，不截断为上限继续返回

#### Scenario: 按版本查询

- **WHEN** 请求某数据集版本下的提交
- **THEN** 返回该范围内的提交、特征与标签

#### Scenario: 查询未知提交标识

- **WHEN** 按一个不存在的提交标识查询
- **THEN** 返回可区分的未找到错误

#### Scenario: 单条查询返回标签来源与多条证据

- **WHEN** 查询一个带有多条简化 SZZ 证据的提交
- **THEN** 响应包含来源算法、规则版本、二值化规则、零标签语义和全部证据，不把二值化规则当作完整来源
