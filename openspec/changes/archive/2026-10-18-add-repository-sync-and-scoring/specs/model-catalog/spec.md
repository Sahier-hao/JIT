# Spec Delta

## ADDED Requirements

### Requirement: MC-07 同步训练模型的登记与来源

系统 SHALL 为同步作业训练出的模型登记其数据集版本、同步作业标识、算法版本与 schema，并在模型列表中与管理员登记的模型一并展示来源与可预测范围。列表 MUST 区分模型来自同步自动训练还是管理员显式登记；自动训练 MUST NOT 修改既有模型的可用状态、业务身份或预测能力声明。

#### Scenario: 自动训练模型出现在目录

- **WHEN** 一次同步作业训练出模型并完成登记
- **THEN** 模型列表出现该模型，可查看其数据集版本、同步作业、方法与 schema，并可被选择用于该来源的提交打分

#### Scenario: 自动训练不影响既有模型

- **WHEN** 同步训练产生新模型
- **THEN** 既有模型的身份、可用状态与预测能力声明保持不变，不因新模型出现而被替换或标记失效

#### Scenario: 同步模型不可用时的如实呈现

- **WHEN** 同步模型的产物被删除、损坏或与登记不一致
- **THEN** 列表标为不可用并给出原因，不退回其他来源模型，也不影响该来源数据集版本的查询
