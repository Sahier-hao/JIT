# Spec Delta

## ADDED Requirements

### Requirement: RCL-07 服务端同步入口与创建校验

系统 SHALL 提供经授权的同步创建入口，接受仓库地址、分支、起始日期、提交上限与打分模型来源选择，在创建时完成校验并返回作业标识。地址不可读、不是 Git 仓库、分支不存在、范围内提交数超过上限或起止日期颠倒 MUST 在创建阶段拒绝并给出可定位原因，MUST NOT 创建注定失败的作业，MUST NOT 以空数据集冒充成功。

#### Scenario: 创建合法同步作业

- **WHEN** 成员提交一个可访问的公开仓库地址、分支与提交上限
- **THEN** 系统创建作业并返回作业标识与初始状态，不再要求用户改用命令行

#### Scenario: 参数在创建时被拒绝

- **WHEN** 地址打不开、仓库不是 Git 仓库、分支不存在、日期颠倒或范围内提交数超过上限
- **THEN** 创建失败并指明具体字段与原因；不产生作业记录，也不产出空数据集

### Requirement: RCL-08 同步作业状态与可操作失败

系统 SHALL 记录每个同步作业的状态、创建与更新时间、当前阶段与失败原因，状态至少区分排队、采集中、登记中、训练中、完成和失败。失败 MUST 说明失败阶段与用户可采取的下一步，MUST NOT 只返回无信息的通用失败。同一仓库同一参数在同一时刻 MUST 只存在一个进行中的作业，重复提交 SHALL 复用该作业而非并行采集。

#### Scenario: 查询进行中与完成的作业

- **WHEN** 客户端按作业标识轮询一个进行中的同步
- **THEN** 依次看到阶段推进与最终完成状态，并能据状态判断还需等待还是可以查看结果

#### Scenario: 失败给出阶段与下一步

- **WHEN** 克隆失败、没有可打标签的提交、训练样本不足或提交范围为空
- **THEN** 作业标为失败并说明发生在哪一步、用户可调整哪个参数后重试

#### Scenario: 并发重复提交合并

- **WHEN** 同一仓库与参数在作业未结束时被再次提交
- **THEN** 系统返回既有作业标识，不启动第二次采集

### Requirement: RCL-09 同步产物串联打分，并允许用户选择打分模型

同步成功后系统 SHALL 把采集产物登记为新数据集版本，并让该来源的提交在工作台获得风险值。创建同步时用户 SHALL 能选择打分模型的来源：自动（按数据量决定）、只用特征口径兼容的既有模型、或强制用该数据集训练；未选择时默认取自动。自动与建议判定 MUST 参考训练窗口内的提交数与正例数；样本不足时 MUST 降级使用兼容模型并在作业与界面注明使用的模型、降级原因与"未在该仓库验证"，MUST NOT 静默产出无意义模型。用户强制训练时 MUST 给出训练区实际样本数与正例数；时间切分无法同时得到训练集与测试集的两类标签时 MUST 失败并建议改用既有模型。训练或打分失败 MUST 保留已登记的数据集版本供查询；MUST NOT 覆盖既有数据集版本或模型身份。

#### Scenario: 自动模式按数据量选择

- **WHEN** 用户未指定打分模型来源并提交同步
- **THEN** 系统在采集完成后按训练窗口的提交数与正例数决定训练或降级
- **AND** 作业记录实际执行的路径与判定依据，界面能说明为什么没有训练

#### Scenario: 数据充足时训练并使用本仓库模型

- **WHEN** 采集完成且训练窗口内的提交数与正例数达到门槛
- **THEN** 使用该数据集训练模型、完成准入登记，并用它给该来源的提交打分

#### Scenario: 样本不足时降级使用兼容模型

- **WHEN** 自动模式下训练窗口的提交数或正例数低于门槛，或时间切分后的测试段没有正例
- **THEN** 作业仍完成，改用特征口径兼容的既有模型打分
- **AND** 作业与界面注明实际使用的模型、降级原因，以及该模型未在此仓库验证、不展示公开数据集的测试指标

#### Scenario: 用户强制训练但样本偏少

- **WHEN** 用户选择强制训练而训练窗口的提交数或正例数低于建议门槛
- **THEN** 只要时间切分能得到训练集与测试集的两类标签，系统仍执行训练并完成登记
- **AND** 结果页显著标注训练区实际提交数、正例数与指标波动风险

#### Scenario: 强制训练无法切分时失败

- **WHEN** 用户选择强制训练，而时间切分后训练集或测试集缺少某一类标签
- **THEN** 作业失败并说明数据量不足、无法完成时间切分，建议改用特征口径兼容的既有模型

#### Scenario: 训练失败但保留数据

- **WHEN** 数据集登记成功而训练或打分失败
- **THEN** 数据集版本仍可查询，作业如实说明未产出可用模型

#### Scenario: 没有兼容模型时明确失败

- **WHEN** 数据不足以训练且用户选择只用既有模型，但模型目录中不存在特征口径兼容的可用模型
- **THEN** 作业失败并说明缺少可用模型，不产出没有模型来源的风险列表
