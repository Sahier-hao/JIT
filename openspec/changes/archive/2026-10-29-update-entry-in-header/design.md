# 设计与取舍

## Context

项目页已经有「当前分析结果」与「分析记录」两块主体。仓库更新是后台行为，频率低、信息量小，却占了一整行入口。

## Goals / Non-Goals

**Goals**：入口不占主体版面；状态一眼可见；展开后有完整设置。

**Non-Goals**：不做常驻状态条，不在页面上直接暴露开关。

## Decisions

- 放在页头标题行、与「已有分析结果」徽标同排——与 GitHub 仓库页把 Watch/Fork 放头部的做法一致。
- 入口显示图标 + 状态词，不用长句；细节进对话框。
- 对话框宽 560，两列设置表单，保存按钮右对齐。

## Risks / Trade-offs

- 入口只有状态词，用户可能不知道「未完成」指什么；靠图标颜色与点开后的说明补足。

## Migration Plan

纯展示层改动。
