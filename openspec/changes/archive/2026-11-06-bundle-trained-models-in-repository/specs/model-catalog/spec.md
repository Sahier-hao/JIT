## MODIFIED Requirements

### Requirement: MC-14 可移植模型包

系统 SHALL 支持将明确选择的已登记模型导出为可移植模型包，并在另一环境导入、校验和登记；包 MUST 包含模型文件、manifest、摘要、来源、数据集、schema、依赖声明和逐文件校验值。导出 MUST NOT 复制或交付 SQLite 目录库作为迁移格式，MUST NOT 把未登记实验或不可服务结果自动包装成服务模型。经维护者批准的版本化压缩发布包 SHALL 可随仓库交付；原始运行目录和 SQLite 目录库 MUST NOT 提交到 Git。导入 MUST 使用不透明运行身份保持幂等，只接受包内规范相对路径，拒绝路径越界、指向链接、哈希不符、manifest 冲突和依赖无法实际加载的包项。

#### Scenario: 导出可移植模型包

- **WHEN** 维护者选择已登记且产物可用的九种标准模型执行导出并提交发布包
- **THEN** 生成的模型包记录九个运行身份、产物文件、manifest 哈希、schema、数据集和依赖，可被其他环境取得和导入
- **AND** 仓库只提交压缩模型包和校验文件，不提交解包后的原始运行目录或 SQLite 目录库

#### Scenario: 空环境导入后模型可用

- **WHEN** 一个新环境具有空目录库，并导入通过完整性校验的九模型包
- **THEN** 九个运行逐项登记为相同运行身份的 ready 模型，用户仓库模型选择能读取这些模型
- **AND** 首个合法兼容模型可按既有规则建立初始默认，来源包的默认、启用或“最佳模型”声明不会覆盖目标环境策略

#### Scenario: 重复或部分冲突导入

- **WHEN** 同一模型包被重复导入，或包内某一运行与目标环境已有运行身份或位置冲突
- **THEN** 无冲突项保持幂等复用，冲突项逐项失败并给出原因，不产生重复模型、第二个默认或部分发布模型

#### Scenario: 损坏或不可加载的模型包

- **WHEN** 包缺失文件、校验失败、包含越界路径或符号链接，或声明的运行依赖无法加载
- **THEN** 整体或对应包项被拒绝，返回可定位错误，不把示例指标、其他模型或其他文件版本当作导入结果

## ADDED Requirements

### Requirement: MC-16 仓库内置模型包初始化

标准目录初始化 SHALL 校验仓库内受控目录中的版本化模型包及其 SHA-256，并使用与维护导入相同的安全校验和登记路径导入。初始化 MUST 在完整包尚未成功应用时尝试导入；已成功应用且预期运行身份均可用时 SHALL 幂等跳过。导入 MUST NOT 覆盖目标环境默认、启停或历史结果，包文件、清单或摘要数量 MUST NOT 冒充用户可用模型。

#### Scenario: 全新拉取后恢复九模型

- **WHEN** 用户拉取包含内置模型包的提交，没有既有目录库和运行产物，并执行标准目录初始化
- **THEN** 九个模型按包内相同运行身份登记为 ready，用户模型选择出现九种方法
- **AND** 初始化后生成的 SQLite 和解包运行目录仍不进入 Git

#### Scenario: 既有环境重复初始化或升级包

- **WHEN** 已有目录执行同一内置包的重复初始化，或拉取到包含新增模型的后续包版本
- **THEN** 既有模型、管理员默认、启停策略和历史结果保持不变；已应用包不重复生成模型，新版本只增补可验证且无冲突的模型

#### Scenario: 内置包不可用或部分应用

- **WHEN** 内置包缺失、SHA-256 不符、依赖不可加载、运行冲突或只有部分模型可登记
- **THEN** 初始化结果明确列出整包及逐项状态，成功项保持可用，失败项不得显示为 ready 或用户可选，既有目录数据不被删除

#### Scenario: 仓库交付边界

- **WHEN** 维护者检查提交内容
- **THEN** Git 含版本化压缩模型包及 SHA-256，不含 SQLite、未打包运行目录或运行期夹具
