# Spec Delta

## ADDED Requirements

### Requirement: RCL-32 时间衰减近期作者经验的独立采集

系统 SHALL 允许按 `kamei14-git-v3` 采集，其中 `rexp` 只累计当前提交父链上同一作者更早提交的衰减权重。每个历史提交权重 MUST 为 `1 / (1 + age_days / 365.25)`，`age_days` 按当前提交与历史提交的 UTC 时间差计算；当前提交、未来提交、并行分支和合并提交 MUST NOT 计入。既有 v2 的 90 天计数 MUST 保持默认和历史兼容。

#### Scenario: 计算单个作者的衰减经验

- **WHEN** 当前提交之前该作者有 365.25 天和 0 天前的两个提交
- **THEN** 两者贡献分别为 `0.5` 和 `1.0`，不把当前提交计入

#### Scenario: 分支与负年龄

- **WHEN** 某历史作者提交只存在于并行分支，或作者时间晚于当前提交
- **THEN** 该提交不贡献权重；负年龄必须报告并拒绝冒充未来经验

#### Scenario: v2 与 v3 并存

- **WHEN** 同一仓库分别按 v2 和 v3 采集
- **THEN** 生成不同 schema 与版本身份的数据集
- **AND** v3 记录衰减公式，v2 原有 90 天计数和模型不被重算

#### Scenario: 尝试用 v2 模型消费 v3

- **WHEN** 训练、分析或预测请求把 v2 模型用于 v3 数据
- **THEN** 系统以 schema 不兼容拒绝，不按同名字段继续
