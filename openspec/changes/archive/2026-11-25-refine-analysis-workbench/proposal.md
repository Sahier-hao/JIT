# Proposal

## Why

分支分析页把「当前结果」拆成多张卡片和多个下拉折叠：结果卡、分数分布、模型与数据来源各自成块，展开时页面突然变高；左侧分析记录卡高度随记录数量变化，与右侧结果不对齐。切到「风险趋势」后子导航被趋势视图接管，模型身份和查询窗口消失，没有可拼接来源时页面缺回程；算法库与训练入口之间也没有路径，读完算法无法带着方法去训练。

## What Changes

- 「当前分析结果」合并为一张卡：分数分布图在最上方，其次是优先回查的提交，最后一行是模型与数据来源摘要。
- 分数分布改为按 0.05 一档的直方图，按 0.25 / 0.10 分档着色并附分档数量图例；提交数超过上限时退回按分档统计并注明，不抽样。
- 页面内下拉展开改为对话框：模型完整口径、原始变更度量、来源与局限、解释方法与来源都从对话框打开。
- 左侧分析记录卡与右侧结果卡同高，记录在卡内滚动并固定显示总数；每条记录有悬停反馈；新分析完成后回到最新一条，不再分页。
- 状态词移入项目头部，「分析结果 / 风险趋势」切换固定在工具栏左侧，主操作在右侧。
- 风险趋势标题显示分支、模型、聚合粒度、查询窗口和来源分析次数；没有可拼接来源时说明原因并保留返回入口；未覆盖时间段用图内底纹和文字说明，不再单列无语义覆盖条。
- 图表容器跟随所在栏目宽度，窗口缩放后不再保持旧宽度或撑出横向滚动。
- 算法库支持方法深链 `#/algorithms/{method}`；可训练方法提供「以此方法训练」，回到训练入口并预选该方法，方法不可用或不兼容时给出真实原因；训练记录和我的模型中的方法名链回算法库对应方法。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `interface-presentation`: 分析记录卡与结果卡的布局、分数分布图、对话框式补充信息、趋势视图读数与覆盖标注、图表宽度跟随。
- `project-risk-trends`: 趋势视图的模型与窗口身份、无来源状态和覆盖表达。
- `configurable-training-parameters`: 算法库方法深链、训练入口预选与跨入口方法链接。

## Impact

- 前端：`frontend/src/features/projects`（分析结果卡、记录卡、趋势视图）、`frontend/src/features/training`（算法库、训练弹窗）、`frontend/src/components/shared/EChartCanvas.tsx`、路由与项目页工具栏。
- 后端与数据：无接口、无迁移、无模型或数据集变更。
- 文档：`docs/当前产品.md`、`docs/项目文件索引.md`。
- 测试：项目页、分析结果卡、趋势视图、算法库与训练弹窗的前端测试。
