## 2. 四种训练口径

- [x] 2.1 实现 `local` 口径：只用目标项目 train 训练并只用目标 test 评价；用注入记录集测试训练来源和测试成员
- [x] 2.2 实现 `pooled` 口径：用四项目 train 并集训练一个模型并评价四个目标 test；测试模型只拟合一次、四个测试结果独立归属
- [x] 2.3 实现 `leave-one-project-out` 口径：逐目标项目排除其全部数据后训练，再评价目标 test；测试每个目标的训练来源严格为其余三项目
- [x] 2.4 实现 `global+local` 口径：训练留一全局模型和目标本地模型，在目标 validation 上以固定网格选择融合权重；测试权重选择不读取 test，且报告记录权重、验证样本和 Brier
- [x] 2.5 为四种口径增加单方法失败隔离，验证某方法或项目中训练、预测、融合失败时其余组合继续并保留阶段、错误码和原因
