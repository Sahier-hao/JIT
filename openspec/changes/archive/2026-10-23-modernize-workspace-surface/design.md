# Design

## Context

项目工作区已有项目、分析记录与固定结果路由，呈现样式由既有 token 和 product.css 承载。当前结果切换使用既有 PATCH 接口，动机见 proposal.md。

## Goals / Non-Goals

**Goals:** 在现有组件和主题约束下统一表面与操作反馈，提供可访问的折叠和选择控件，并在详情重取时保持页面上下文。

**Non-Goals:** 不改模型、数据、接口及路由身份，不替换布局系统，不新增依赖。

## Decisions

1. **新增 `modern.css` 而不是改写 `product.css`**：`product.css` 承载布局与既有语义类名，`material`、`typography`、`tokens` 三组样式守卫测试依赖其中的具体声明。把表面、悬停、焦点、选中状态放到最后加载的 `modern.css`，只增强不删除，既保住测试也便于整体回退。
2. **令牌只增不改**：新增 `--r-xs`、`--r-md`、`--r-xl` 与 `--sh-3`，不改 `--r`、`--r-lg`、`--sh-1/2` 的既有含义；`charcoal` 主题同步补 `--sh-3` 的深色阴影，避免暗色下浮层发灰。
3. **分析选项用按钮 + `hidden` fieldset**：原生 `details` 无法同时把摘要 chips 放在 summary 内并保持 `aria-expanded` 的稳定语义，因此用按钮控制 `hidden` 字段组；摘要 chips 由当前表单值派生，提交按钮放在折叠区之外，收起时仍可直接开始。
4. **当前结果用原生 radio**：同一 `name` 的单选组天然提供方向键与选中语义，整条记录包在 `label` 里，点文字也能切换；打开、重试、删除保持独立按钮，不触发选择。
5. **返回控件按层级命名**：审查页属于某个项目，返回写「返回项目」并回到 `#/projects/<id>`；项目页属于项目列表，返回写「全部项目」并回到 `#/projects`。同名「项目」不再指向两个层级。
6. **重取不替换整页**：项目详情加载态只在 `repository === null` 时占据整页；已有数据时保持页面挂载，局部更新结果与记录，因此滚动位置不会被浏览器重置。
7. **不改 API、不加依赖**：本轮只动呈现与交互；切换当前结果所需的 `PATCH /api/v1/repositories/{id}` 已在 `select-current-analysis` 中实现。

## Risks / Trade-offs

- `modern.css` 增加了选择器覆盖面，后续改组件需要同时看两个文件；用注释标出「仅表面，不布局」。
- 折叠表单会隐藏字段名，首次使用者可能不知道能改分支/范围；用参数摘要 chips 明示当前值，并保留「分析选项」按钮。
- 单选点选是即时请求，网络慢时依赖行内「正在切换…」文本反馈；不做乐观更新，避免失败后状态与界面不一致。

## Migration Plan

随前端构建发布，无数据迁移。回退时恢复原样式导入与对应组件版本；项目、分析和结果身份保持原存储语义。
