# 设计：把 PR 分析的有效信息收进只读详情

## Context

`PRModelClues` 目前同时负责取数、契约校验、轮询、派生风险表，并用回调把结果推回 `PullRequestPreview` 与 PR 工作单；三个挂载点各自请求一次快照分析与模型名。顶部「打开分析」跳到 `#/projects/{id}/analyses/{syncId}/commits`，该页以分支分析为模型（标题“仓库分析 · 分支”），对 PR 来源的独有内容是逐提交模型解释和提交筛选。

## Goals / Non-Goals

**Goals**

- 只读详情不再离开本页即可完成提交风险排序、提交搜索和逐提交模型解释。
- 同一固定快照的分析只请求一次，切换快照或提交时不显示旧请求结果。
- 保留旧版 HEAD 绑定、覆盖不完整和模型不可用的如实说明。

**Non-Goals**

- 不把分支分析页的日期筛选、分页、原始度量与数据集来源整体搬入 PR 详情。
- 不改变分析生成、任务重试、模型选择等写路径；不新增后端接口。
- 不改写任何已保存分数、解释事实或个人草稿。

## Decisions

1. **共享查询**：新增 `useSnapshotAnalyses(snapshotId, totalCommits)`，用已接入的 `@tanstack/react-query` 按快照缓存分析列表，存在运行中作业时每 2 秒轮询；模型名复用同一个缓存查询。切换快照即切换 queryKey，过期响应不会落到新上下文。
2. **组件职责**：`PRModelClues` 只渲染风险概览与旧版绑定说明，接收查询结果；父组件直接使用同一结果里的提交/文件风险映射，删除 `onFileRisks` / `onCommitRisks` 回调及父组件副本状态。
3. **逐提交解释**：复用 `RepositoryExplanation`，上下文取当前有效分析（已完成、上下文有效、有分数）的 `repositoryId`、`syncId`、`modelId`、`runId`、`datasetVersion` 与该提交已保存分数。解释生成属于该分析的保存事实，不改变风险分数；模型不可用时按组件既有文案说明，不切换模型。
4. **提交搜索**：在快照已载入的提交上做标题与完整/短 SHA 的本地过滤，与现有排序并用；不新增接口，避免为一次搜索重新拉取远端。
5. **入口移除**：只读详情不显示「打开分析」。项目「分析」页仍保留该分析记录，需要时从项目页进入；不新增反向跳转按钮。
6. **展示位置**：解释放在提交范围栏下方、Diff 上方，默认折叠；展开后才显示解释的表格与来源，避免挤压 Diff 高度。
7. **提交工具条分组**：标题与覆盖计数归为左侧一组，搜索与排序归为右侧一组；两者都是 30px 的次级控件。排序沿用项目 PR 清单已验证的下拉按钮（「排序：按风险 / 按提交顺序」），不再与搜索挤在同一行分段控件里。窄屏时两组换行，搜索占满剩余宽度；640px 以下隐藏「变更行 / 文件」两列并允许提交标题换行，避免表格横向溢出。
8. **作者说明读取 Markdown**：新增只读 `Markdown` 组件（`react-markdown` + `remark-gfm`），不启用原始 HTML，链接新开标签页；正文限制 74ch 行长、标题降级到 18px 以内，代码块与表格沿用界面令牌。作者未填写时只显示一句说明。PR 工作单的「查看已保存意见」复用同一组件。
9. **提交区表面**：只读详情的提交表恢复为一张卡片表面（边框、圆角、表头底边），与作者说明卡片形成同一层级；不再使用虚线空状态框，改用表尾的一行操作提示。
10. **模式可见**：只读详情在 crumb 标明「只读预览」，主操作改为「创建审查工作单」，按钮提示说明创建后可标记阅读进度、记录问题并导出意见；工作单页标明「个人工作单」。两页共享同一快照与风险数据，区别只在于是否持有个人草稿和笔记，避免用户把只读页误认为已在审查。

## Risks / Trade-offs

- **只读语义边界**：解释生成会写入该分析的保存事实。规格明确只允许“解释”，不允许选择模型、生成分析、重试或取消；生成失败时原分数保持不变。
- **少一条跨页入口**：习惯从 PR 详情进入分支分析页的用户需要改从项目页进入。项目「分析」记录与地址不变，旧书签仍可用。
- **本地搜索的边界**：只匹配已载入提交；`totalCommits` 大于已载入数量时继续显示既有“提交 x/y”说明，不把搜索无结果表述为 PR 没有相关提交。
- **轮询迁移**：把手写 `setInterval` 换成查询库的 `refetchInterval`，需确认离开页面后不再轮询；由查询库在组件卸载时停止。
