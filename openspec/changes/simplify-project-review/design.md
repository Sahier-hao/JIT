# Design

## Context

源码基线为 `1531e4c`，工作区干净，8000/4173 是本聊天启动的开发服务。团队凭证横跨 FastAPI 中间件、错误模块、全部前端请求和多个页面；仅删输入框会使核心流程不可用。默认库可能仍是 v4，HTTP 启动不会自动迁移，预览升级前需 SQLite backup。

## Goals / Non-Goals

**Goals:** 打开即用、项目主线、真实采集与推理、清楚的结果阅读、现代统一界面。删除前端独立模型/手工预测/结果编号/演示页面及凭证生命周期。

**Non-Goals:** 不删除已保存模型、预测结果、数据库或冻结证据；不新增账户、云部署、训练平台、虚假 diff 或仓库效果。

## Decisions

1. 后端以 `api_errors.py` 承接 RequestError、错误信封、requestId/no-store 与诊断，删除 team_access、hmac、角色和凭据环境配置；create_app 删除 token 参数，业务输入/模型校验照常。服务仍监听 127.0.0.1。
2. 前端请求不再接收/发送 token；取消凭据 provider 与所有 credential-required 分支。请求取消/对象上下文隔离独立存在，不用假 token 或固定 generation 伪装删除。
3. 顶层只保留项目及次级验证报告，外观是小控件。旧模型/预测/结果/演示/连接地址进入明确的已移除反馈，保留非秘密对象地址无须为旧工具保留页面。
4. 项目首页展示真实项目、明确的新建分析主操作与空态；接入页聚焦地址和分析范围，高级模型策略折叠；作业卡默认只显示仓库、阶段、时间和打开结果，详细身份一次展开。
5. 审查页用一次标题、一次来源摘要、提交标题为主的列表和右侧详情；计划是列表内分段视图，无常驻队列；完整 ID/数据/模型置于来源披露。原始度量可展开，不把未提供的解释做成大块空白。保留真实来源和未校准分数边界。
6. 验证报告只描述已配置历史运行，保留趋势/文本下钻与来源校验；去掉重复的外层/内层标题和实验室工具导航。单运行不造运行目录。
7. 已退役界面用例删除，领域解析/输入/推理/不可变存储/固定分析/计划行为测试继续使用。新增无认证真 API、无凭证首屏、入口移除、对象返回、两桌面/窄屏真实链路测试。

## Risks / Trade-offs

- 删除凭据是明确的产品变更，原 401/403/配置错误不再是有效验收目标，OpenAPI 与维护说明同步清理。
- 旧深链接可提示入口移除，服务端原结果不重算/不删除。项目与固定分析地址继续可用。
- 删除 UI 会减少测试总数，报告按现行覆盖与退役清单说明，不通过保留旧断言或 skip 冒充覆盖。
- 开发预览升级只用 SQLite backup 后的显式 additive 迁移；停止/重启仅操作本聊天创建的服务，保留用户数据。

## Migration Plan

源代码可通过本次分组提交或基线 `1531e4c` 在独立分支回退；不 reset 当前共享工作区。记录受保护文件哈希；新 UI 不修改冻结证据。按任务先验证旧行为确实失败，再实施。全部核验通过后更新文档/任务，运行主规格严格校验；不自动冻结或归档。
