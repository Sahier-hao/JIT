## Why

训练参数、解释方法和 IDE 交接已经分别具备后端能力，但用户仍难理解参数影响、无法从训练表单准确跳到对应算法说明，也缺少一页完整的插件使用指南。与此同时，PR 和固定提交详情中的风险证据分散在提交分、特征解释、代码行、规则与历史修复记录之间；用户看不出这些证据各自的来源和边界。

## What Changes

- 在训练参数输入处就地展示人话说明、默认值、范围和已修改状态，并提供恢复默认及定位到当前算法参数的算法库入口。
- 新增 IDE 插件使用指南页面，说明报告生成、导入、身份核对、定位和常见不可定位状态，不把尚无稳定下载源的 VSIX 伪装成可下载安装包。
- 扩展行级研究模型，使其对固定 PR 快照和固定仓库提交中的真实代码候选返回排名、前 3 个 `log-odds` 行级特征贡献及完整性状态；不改变提交风险、默认模型或模型目录。
- 在 PR 与固定提交详情中按对象实际拥有的数据组织证据链，展示提交风险、提交级解释、行级贡献、规则命中和历史修复证据；缺失的来源明确标为不可用，不跨对象补齐。
- 保持不同单位和方法相互独立：不将概率贡献与 `log-odds` 相加，不跨方法统一排名，不自动选择“最佳解释”，不把行级贡献称为缺陷原因或修复优先级。
- 模板化摘要只复述已保存或已返回的证据；本轮不接入自由生成式 LLM。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `configurable-training-parameters`: 增加训练表单中的参数就地解释、默认值差异、恢复默认和当前算法参数深链。
- `ide-report-consumption`: 增加 Web 端插件使用指南、身份状态说明和交付边界展示。
- `line-level-prediction`: 允许固定 PR 与固定提交详情在真实代码候选上展示受控的行级特征贡献，同时保留研究预览、未校准和非根因边界。
- `prediction-explanation`: 增加按对象组装的多层证据链、行级贡献可视化及缺失来源的如实呈现。
- `workspace-navigation`: 增加 IDE 插件指南入口和可恢复地址。

## Impact

- 前端训练弹窗、算法库、PR 审查工作区、固定提交详情、路由和主导航。
- 后端行级研究预览接口、PR 快照代码候选读取、固定仓库提交代码候选读取，以及证据链组合接口。
- OpenAPI 契约、前后端类型、解析器、单元测试、组件测试、隔离服务 E2E 和可访问性验证。
- 不修改训练算法、模型风险算法、默认模型、模型目录、原提交风险或现有解释的保存身份。
