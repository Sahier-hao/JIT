## 2. 批量共享与特征复用

- [x] 2.1 批次执行期间为同一仓库获取一次租约，批次内条目复用同一仓库副本；验证批次结束、取消和失败都释放租约
- [x] 2.2 单 PR 分析在没有活动批次时自行获取并释放租约；验证并发与串行执行都不泄漏租约
- [x] 2.3 实现目标提交特征查找：同仓库、同 schema 的已完成分析中收集保存特征；验证全部命中时跳过采集
- [x] 2.4 全部命中时直接计算风险，不登记重复数据集版本，并在分析记录保存特征来源与 schema；验证界面显示复用说明与打分覆盖
- [x] 2.5 缺失提交或 schema 不一致时整段重新采集计算，不做部分拼接；验证复用的风险分数仍由本次模型重新计算
- [x] 2.6 增加全命中、部分命中、schema 不一致和复用来源测试；验证分支分析不受跳过规则影响
