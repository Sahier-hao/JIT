## MODIFIED Requirements

### Requirement: ADM-02 服务端维护权限

服务端 MUST 对模型目录/候选及登记、数据集记录、训练任务创建/查询/取消/重试、提交维护查询、维护预测/批次、特征 schema 和历史验证接口要求有效管理员会话。界面是否提供入口 MUST 不影响授权检查。公开项目和模型选择元数据 SHALL 无需管理员登录。

#### Scenario: 直接请求受保护接口

- **WHEN** 匿名或过期会话直接请求维护 API
- **THEN** 服务端返回 401 和可定位错误信封，不返回维护数据

#### Scenario: 登录后读取管理记录

- **WHEN** 管理员使用有效会话读取维护 API
- **THEN** 按原业务校验返回实际记录；模型选择公共接口仅包含选择所需字段

#### Scenario: 匿名请求训练任务

- **WHEN** 客户端未登录即读取、创建、取消或重试训练任务
- **THEN** 服务端拒绝请求，不披露训练指标、运行或模型谱系
