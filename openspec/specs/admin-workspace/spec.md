# admin-workspace Specification

## Purpose
为本机模型维护、数据记录及历史验证提供独立的管理员工作区，以可撤销、可到期的服务端会话保护维护接口，并提供首次账户设置和本机密码恢复，使普通项目审查与系统维护具有清楚的访问边界。

## Requirements

### Requirement: ADM-01 独立管理员工作区与首次初始化

系统 SHALL 在独立管理工作区提供模型维护、数据记录和验证报告。未登录 MUST 先以居中弹窗显示管理员登录；没有管理员账户时 SHALL 在同一弹窗提供一次性首次设置，无默认账户或默认密码。关闭登录弹窗或按 Esc SHALL 返回用户工作区，且 MUST NOT 展示维护记录正文。管理工作区 MUST 使用独立外壳，不显示用户项目侧栏。项目工作区 MUST 不展示维护记录正文。

#### Scenario: 首次建立本机管理员
- **WHEN** 本机尚无管理员且用户提交合法账户名及 12–256 位密码
- **THEN** 建立管理员并进入管理区；后续初始化请求被拒绝，不创建第二个初始账户

#### Scenario: 未登录进入管理区
- **WHEN** 浏览器没有有效会话并打开模型、数据或报告管理地址
- **THEN** 显示管理员登录或首次设置弹窗，不展示维护内容；普通项目继续可用

#### Scenario: 关闭登录弹窗
- **WHEN** 未登录用户关闭管理员登录弹窗、按 Esc 或点击遮罩
- **THEN** 返回用户工作区，维护内容不出现

### Requirement: ADM-02 服务端维护权限

服务端 MUST 对模型目录/候选及登记、数据集记录、提交维护查询、维护预测/批次、特征 schema 和历史验证接口要求有效管理员会话。界面是否提供入口 MUST 不影响授权检查。公开项目和模型选择元数据 SHALL 无需管理员登录。

#### Scenario: 直接请求受保护接口
- **WHEN** 匿名或过期会话直接请求维护 API
- **THEN** 服务端返回 401 和可定位错误信封，不返回维护数据

#### Scenario: 登录后读取管理记录
- **WHEN** 管理员使用有效会话读取维护 API
- **THEN** 按原业务校验返回实际记录；模型选择公共接口仅包含选择所需字段

### Requirement: ADM-03 密码和会话生命周期

系统 MUST 以独立盐的 PBKDF2 摘要保存密码，以随机 token 建立会话且仅保存 token 摘要。会话 cookie MUST 设置 HttpOnly、SameSite=Strict，8 小时到期，HTTPS 下设置 Secure。登录 SHALL 限制重复尝试，维护写请求 MUST 拒绝不受允许的 Origin；秘密 MUST 不存入 localStorage 或响应正文。

#### Scenario: 会话到期或退出
- **WHEN** 会话到期或管理员退出管理区
- **THEN** 后续维护请求被拒绝；退出后的旧 token 不再有效

#### Scenario: 跨来源维护写请求
- **WHEN** 未允许的 Origin 或 cross-site 浏览器请求尝试初始化、登录或维护写入
- **THEN** 返回 403，不建立账户/会话或修改维护数据

#### Scenario: 密码连续猜测
- **WHEN** 同一客户端在一分钟内达到五次失败登录尝试
- **THEN** 后续尝试返回限流反馈，管理员可以等待窗口后重试

### Requirement: ADM-04 本机密码恢复

维护者 SHALL 能在本机通过 CLI 隐藏输入并确认新密码，重置已存在管理员的密码并撤销其所有会话。密码 MUST 不通过命令行参数或日志输出。

#### Scenario: 忘记管理员密码
- **WHEN** 维护者通过 admin-reset-password 对已存在账户提交一致的合法新密码
- **THEN** 原密码和旧会话失效，新密码可登录；输出不包含密码

### Requirement: ADM-05 管理员模型策略操作

管理工作区 SHALL 提供默认模型、启用及停用操作，显示已校验、不可用、已停用和默认标记。策略写入 MUST 要求有效管理员会话并检查来源，普通用户仅能读取必要选择元数据。界面 SHALL 说明停用对新任务及历史结果的影响，提供确认、取消、保存中和失败恢复反馈。

#### Scenario: 完成设置和停用
- **WHEN** 管理员将另一兼容模型设为默认，再确认停用旧模型
- **THEN** 页面显示真实保存状态，默认模型的停用按钮不可用；停用说明告知历史保留、未开始使用模型的任务失败及已开始使用的任务可完成

#### Scenario: 未登录或跨来源写策略
- **WHEN** 未登录、会话到期或未经允许来源直接调用策略更新
- **THEN** 服务端分别拒绝会话或来源，不因页面按钮隐藏而省略校验，不保存更改

#### Scenario: 取消停用或保存失败
- **WHEN** 管理员取消确认，或保存遇到业务冲突、存储或网络错误
- **THEN** 取消不发送策略写入；保存失败展示原因且不显示成功状态，用户可以刷新记录后重试

### Requirement: ADM-06 管理工作区独立外壳与分区导航

管理工作区 SHALL 使用独立外壳，按模型管理、数据集、训练任务、模型比较和验证报告分区，并显示当前分区、管理员账户、退出管理和返回用户工作区。页面 SHALL 以标题、卡片和表格呈现状态与数据；说明性文案 MUST 限于状态、数据与操作提示。外观偏好 SHALL 可在管理工作区切换并在刷新后保留。

#### Scenario: 切换管理分区
- **WHEN** 已登录管理员在左侧导航选择管理分区
- **THEN** 当前分区高亮，地址与页面内容对应，刷新后仍停留在同一分区

#### Scenario: 退出或返回用户工作区
- **WHEN** 管理员选择退出管理或返回用户工作区
- **THEN** 退出后会话撤销并返回用户工作区，再次打开管理地址时显示登录弹窗；返回用户工作区不保留管理正文

#### Scenario: 窄屏访问管理工作区
- **WHEN** 在 768px 宽视口打开任一管理分区
- **THEN** 导航折叠到内容上方，页面不产生横向滚动，管理操作仍可到达

#### Scenario: 切换外观偏好
- **WHEN** 管理员在管理工作区切换主题或密度并刷新
- **THEN** 管理页面按所选偏好呈现，不改变数据与权限语义
