# commit-persistence Specification

## Purpose

把提交级数据（身份、时间、模块、变更规模、特征与标签）持久保存到可查询的目录库，使预测、分析与后续模型接入共享同一份提交事实，而无需重跑离线脚本。

## Requirements

### Requirement: CMP-01 提交身份与时间持久化

系统 SHALL 为每个纳入提交保存 40 位提交标识、带时区时间、模块（来源提供时）与所属数据集版本；同一提交在同一数据集版本内 MUST 唯一，重复导入 MUST 幂等而不产生重复行。来源不提供模块时该列 MUST 为空，不得以占位值填充。

#### Scenario: 首次导入提交
- **WHEN** 导入一批纳入提交
- **THEN** 每个提交按标识、时间、模块与数据集版本落库并可查询

#### Scenario: 重复导入同一提交
- **WHEN** 同一提交被再次导入同一数据集版本
- **THEN** 不产生重复行，原记录保持可查询

### Requirement: CMP-02 变更规模持久化

系统 SHALL 为每个提交保存来源提供的变更规模（文件数、新增行数、删除行数、涉及目录数）；来源不提供文件明细时 MUST 只保存聚合，不得生成或猜测文件路径。提交缺少纳入规则要求的规模字段 MUST 被拒绝。

#### Scenario: 保存变更规模
- **WHEN** 导入一个含文件数与增删行数的提交
- **THEN** 其文件数、增删行数与目录数可按提交标识查询

#### Scenario: 缺少要求的规模字段
- **WHEN** 导入的提交缺少纳入规则要求的规模字段
- **THEN** 拒绝该提交并报告缺少字段，不静默补零

### Requirement: CMP-03 特征与标签持久化

系统 SHALL 按提交保存其 schema 声明为入模的字段值与标签；不可用字段 MUST NOT 写入，标签 MUST 记录来源规则；字段值与 schema 声明不一致 MUST 拒绝写入。

#### Scenario: 按 schema 写入特征
- **WHEN** 导入使用某 schema 的提交特征
- **THEN** 只有该 schema 声明为入模的字段被写入并可查询

#### Scenario: 写入不可用字段
- **WHEN** 导入包含 schema 声明为不可用的字段
- **THEN** 拒绝写入并指出该字段，不用零值或推算值替代

### Requirement: CMP-04 导入事务整体提交

一次导入 MUST 在单个事务内完成；任一行或任一表写入失败 MUST 整体回滚，MUST NOT 留下半批提交、文件或特征。

#### Scenario: 导入中途失败
- **WHEN** 导入在写入若干提交后遇到无效行
- **THEN** 整批回滚，库中不新增任何该批数据，并返回可定位错误

#### Scenario: 导入成功
- **WHEN** 整批提交、文件、特征与标签均写入成功
- **THEN** 一次提交后全部可见，导入记录标记为成功

### Requirement: CMP-05 提交与特征只读查询

系统 SHALL 提供按数据集版本查询提交列表与按提交标识查询单条提交及其特征与标签；列表 MUST 分页且有上限、MUST 返回总数、MUST NOT 在单次响应中携带全部特征；来源提供模块时支持按模块过滤。未知标识或版本 MUST 返回明确错误，MUST NOT 返回空成功。

#### Scenario: 分页查询提交列表
- **WHEN** 请求某数据集版本下指定 limit 与 offset 的提交列表
- **THEN** 返回不超过上限的摘要项（标识、时间、标签、模块）与总数，完整特征不随列表返回

#### Scenario: 超出上限的分页参数
- **WHEN** 请求的 limit 超过声明上限、为负数或不是整数
- **THEN** 返回可定位的输入错误，不截断为上限继续返回

#### Scenario: 按版本查询
- **WHEN** 请求某数据集版本下的提交
- **THEN** 返回该范围内的提交、特征与标签

#### Scenario: 查询未知提交标识
- **WHEN** 按一个不存在的提交标识查询
- **THEN** 返回可区分的未找到错误

### Requirement: CMP-06 存储不可用与失败语义

存储不可用或事务提交失败 MUST 返回明确存储错误，MUST NOT 声明导入成功；部分成功不得以成功响应返回。

#### Scenario: 数据库不可写
- **WHEN** 导入时数据库文件不可写或锁定
- **THEN** 返回存储错误并说明原因，不产生部分可见数据

#### Scenario: 迁移版本不匹配
- **WHEN** 库的迁移版本低于当前代码要求
- **THEN** 拒绝导入并提示先执行迁移，不静默降级
