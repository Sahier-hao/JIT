# line-level-prediction Specification

## Purpose
用可复现的离线实验评估行级样本、特征与跨仓库泛化能力，明确定位指标与产品化边界，不把研究分数冒充可用行级概率。

## Requirements

### Requirement: LLP-01 行级基线训练与评估

系统 SHALL 能从 `line-szz-v1` 样本训练行级基线并给出可复现的评估报告。切分 MUST 按仓库留出或按提交分组，MUST NOT 让同一提交的行同时进入训练与测试。报告 MUST 记录输入文件、样本/提交/仓库数、切分方式、特征与模型参数、正负例数和指标；测试集单类或指标不可计算时 MUST 返回空值并说明原因。训练 MUST NOT 登记模型、修改默认模型、写回数据集或产品结果。

#### Scenario: 仓库内分组切分

- **WHEN** 未指定测试仓库
- **THEN** 按提交分组切分训练/测试，同一提交的行只出现在一侧
- **AND** 报告记录训练与测试的提交数和仓库分布

#### Scenario: 跨仓库留出

- **WHEN** 指定 `--test-repo`
- **THEN** 该仓库的全部行只用于测试，其他仓库用于训练
- **AND** 报告将其标注为跨仓库评估

#### Scenario: 指标不可计算

- **WHEN** 测试集只有正例或只有负例
- **THEN** ROC-AUC、PR-AUC 与 Brier 返回空值并说明单类原因，不伪造数值

#### Scenario: 不写回

- **WHEN** 基线训练完成
- **THEN** 输入 JSONL、数据集、目录库与模型目录保持不变

### Requirement: LLP-02 可移植复现清单

行级实验 SHALL 输出可移植 manifest，记录源仓库与 revision、数据与 JSONL 哈希、SZZ 版本与限制、采样策略与种子、train/validation/test 成员摘要、特征与模型配置、运行环境和复现命令。报告 MUST NOT 只引用临时绝对路径；大型原始数据 MAY 不入版本库，但 MUST 提供哈希与获取说明。

#### Scenario: 生成 manifest

- **WHEN** 完成一次行级训练与评估
- **THEN** manifest 包含输入哈希、切分成员摘要、特征/模型配置、环境与复现命令

#### Scenario: 输入缺失

- **WHEN** 报告引用的输入文件不存在或哈希不符
- **THEN** 报告明确标为不可复现，不声称已复现

### Requirement: LLP-03 分语言与仓库评估

行级评估 SHALL 分语言、按仓库留出或在训练内按仓库分组，并报告各仓库结果。需要选择方案时 MUST 使用验证仓库或训练内分组，MUST NOT 用被留出的测试仓库选择方案。已用于观察结果的仓库 MUST NOT 被重新称为全新盲测。补数据时 SHOULD 优先增加每语言多个足量仓库，而不是只放大一个仓库。

#### Scenario: 分仓库结果

- **WHEN** 执行固定实验计划
- **THEN** 报告按语言与留出仓库列出样本量、正例率与指标

#### Scenario: 样本不足

- **WHEN** 某语言留出仓库样本过少
- **THEN** 标注为探索性结果，不据此宣称可泛化

### Requirement: LLP-04 定位指标与诚实结论

行级评估 SHALL 在完整且有意义的提交/文件候选集上报告 IFA、Top-k 命中或 Recall@行预算；只有抽样正负列表时 MUST 明确其代理性质，MUST NOT 冒充真实审查收益。Brier 与校准结论 MUST 说明采样分布。零收益或负结果 MUST 保留。行级研究模型 MUST NOT 登记为通用逐行概率模型，MUST NOT 改变提交级风险口径或默认模型。产品 MAY 在固定 PR 快照与固定仓库提交详情中展示该模型的独立行级研究证据，但 MUST 使用固定源码或 diff 中的真实候选，MUST 标注研究预览、未校准、语言覆盖和候选完整性，MUST NOT 将该证据用于计算或替换提交风险、PR 结论或缺陷概率。

#### Scenario: 代理指标

- **WHEN** 评估数据来自正负抽样列表而非完整候选集
- **THEN** 定位指标标注为上限代理，不表述为实际审查节省

#### Scenario: 结论为暂缓

- **WHEN** 跨仓库泛化或校准证据不足
- **THEN** 报告明确“暂不上线”，产品继续使用提交级风险与 SZZ 数据层

#### Scenario: 独立研究预览

- **WHEN** 固定 PR 或固定提交详情请求行级研究证据
- **THEN** 页面只展示来自真实候选行的排序与特征贡献，并固定标注非缺陷概率、未校准、不参与提交风险

#### Scenario: 缺少真实候选

- **WHEN** 固定对象没有可验证的源码、diff 或合格候选行
- **THEN** 行级证据显示不可用及原因，不根据提交统计、文件路径或语言猜测行号

### Requirement: LLP-05 行级模型研究预览

系统 SHALL 从固定行级实验导出可移植、经 `artifactSha256` 校验且不使用 pickle 的系数模型，并 MUST NOT 将其写入目录库或模型目录。系统 SHALL 提供只读元数据、按请求代码打分和固定 PR/提交候选证据接口，全部复用训练特征实现。证据 MUST 返回逐行身份、0–1 研究排序分、`log-odds` 贡献和覆盖状态，前 3 个非零贡献按绝对值排序；排序分与贡献 MUST 分字段且不可相加。系统 MUST 拒绝未覆盖语言、超限候选和不可读固定 diff，MUST NOT 为生成证据实时读取完整源码，MUST NOT 持久化请求代码或回退其他模型。若模型产物依赖完整文件位置特征，系统 MUST 以明确不可用状态失败。页面 MUST 展示样本、留出指标与限制，并标记“研究预览”“不是缺陷概率”。

#### Scenario: 读取研究模型

- **WHEN** 客户端请求行级研究模型元数据
- **THEN** 返回训练/留出摘要、指标、特征口径、限制和产物校验值

#### Scenario: 按行打分

- **WHEN** 用户提交 TypeScript 代码
- **THEN** 返回按分数降序排列的行号、代码、分数和前 3 个行级特征贡献，并跳过空行
- **AND** 响应固定说明分数不是缺陷概率、未校准、不参与提交风险

#### Scenario: PR 固定快照证据

- **WHEN** 用户打开一个具有完整 diff 的受支持语言 PR 文件
- **THEN** 系统只对固定快照中真实新增/修改候选行生成行级证据，并返回路径、侧别、候选覆盖和前 3 个特征贡献

#### Scenario: 固定提交证据

- **WHEN** 一个仓库提交能够解析到固定提交的合格代码候选
- **THEN** 行级证据绑定该提交、路径和行号，不读取当前工作树或替代为另一提交

#### Scenario: 贡献单位独立

- **WHEN** 响应包含 `log-odds` 行级贡献
- **THEN** 每个贡献只校验为有限数，贡献合计可由各行贡献核对，绝对值大于 1 不被错误拒绝
- **AND** 行分数仍作为 0–1 研究排序分单独展示，不与贡献相加

#### Scenario: 产物损坏

- **WHEN** 研究模型文件缺失、结构无效或校验值不匹配
- **THEN** 元数据、请求打分和固定对象证据接口返回明确不可用错误，不回退到其他模型或目录库模型

#### Scenario: 隔离于主流程

- **WHEN** 用户查看 PR 或提交详情
- **THEN** 行级研究证据不改变提交风险、解释方法目录、默认模型、模型目录或历史结果

#### Scenario: 只用 patch 文本打分

- **WHEN** 当前行级模型未启用位置特征且固定对象具有完整 patch
- **THEN** 系统直接使用 patch 新侧新增行文本打分，不请求完整文件内容
- **AND** 覆盖信息返回 `textSource: patch` 与 `usesFullFile: false`

#### Scenario: 模型依赖完整上下文

- **WHEN** 模型产物声明启用位置特征，而接口只有 patch 文本
- **THEN** 系统返回 `LINE_PREVIEW_CONTEXT_REQUIRED` 或等价明确状态，不伪造缺失上下文

#### Scenario: 候选超过上限

- **WHEN** 固定 patch 的可分析新增行超过研究预览上限
- **THEN** 返回明确的 `patch-candidate-limit` 原因和空候选列表，不截断后假装完整

#### Scenario: 不支持的语言

- **WHEN** 固定对象的语言不在模型覆盖范围，或固定 diff、候选行不可读取
- **THEN** 返回明确的不可用状态与原因，不使用其他语言模型、文件级指标或当前默认模型代替

### Requirement: LLP-06 完整候选集上的行级定位评价

行级评价 SHALL 以引入提交中全部合格新增/修改代码行为主要候选总体，从真实 Git diff 与固定快照导出，并记录仓库、revision、提交、路径、侧别、行号、标签状态与证据。候选 MUST NOT 从标签挑选、补齐或删除；正例不在已声明总体中时 MUST 记为不可覆盖。系统 MUST 在完整、同一候选总体上报告 IFA、Top-1/5/10、行预算召回与正例覆盖，并与既有抽样结果区分口径。

#### Scenario: 导出完整候选集

- **WHEN** 对真实仓库的引入提交导出候选
- **THEN** 输出逐行候选与覆盖/排除统计，重命名、删除、二进制与无法映射的行给出明确状态

#### Scenario: 正例无法映射

- **WHEN** SZZ 标记的引入行不在可覆盖候选总体中
- **THEN** 记为不可覆盖并计入覆盖率，不用全文件正例替代行级正例抬升命中

#### Scenario: 随机基线

- **WHEN** 报告随机排序基线
- **THEN** 使用相同候选规模与正例密度的固定种子，并说明并列与预算取整的处理

### Requirement: LLP-07 行级定位影子门槛

系统 SHALL 使用冻结研究模型在完整候选集上按仓库留出执行影子评估，不重训练或调参；报告 MUST 包含 Recall@1/5/10、MRR、首个正例检查行数、随机排序与文件顺序基线。只有至少两个此前未见且样本充足的仓库在全部指标上稳定优于基线时，才允许宣称产品定位收益；否则 MUST 保留研究预览并明确不产品化，MUST NOT 宣称定位收益、审查节省或自动决策，MUST NOT 把行级排序冒称为缺陷概率。

#### Scenario: 完整候选集影子评估

- **WHEN** 对冻结行级模型执行影子评估
- **THEN** 报告按仓库列出支持行、含正例提交、正例率、Recall@1/5/10、MRR、首个正例检查行数与基线

#### Scenario: 门槛未通过

- **WHEN** 不足两个未见且样本充足的仓库稳定优于全部基线
- **THEN** 报告明确门槛未通过；如需在 PR 文件视图展示，只能按 LLP-09 标注为研究排序，不得作为定位结论或自动决策

#### Scenario: 已观察仓库

- **WHEN** 某仓库已参与原留出观察
- **THEN** 报告不得把它重新称为全新盲测

### Requirement: LLP-08 研究预览逐行贡献

研究预览打分 SHALL 为每行保留原排序分数并返回截距、原始 logit 和绝对贡献最大的前三项特征；每项 MUST 包含特征名、本次值、权重和 `value × weight` 的贡献值。响应 MUST 提供全部贡献合计或等价余项，使“截距 + 全部贡献”等于该行 logit。

#### Scenario: 分解恒等

- **WHEN** 对任意非空代码行打分
- **THEN** 截距加全部特征贡献近似等于该行原始 logit
- **AND** 前三项贡献加其余贡献合计也等于全部贡献

#### Scenario: 页面展示

- **WHEN** 用户展开一条排序结果
- **THEN** 页面用中文特征名显示前三项、截距与其余贡献合计
- **AND** 固定说明“行级特征贡献，不是缺陷原因”

#### Scenario: 空行和未支持语言

- **WHEN** 输入混有空行或模型未覆盖的语言
- **THEN** 空行继续跳过；未覆盖语言明确拒绝，不生成贡献或替换模型

### Requirement: LLP-09 PR 文件的行级研究排序

PR 文件视图 SHALL 对当前固定快照中真实新增/修改的 JavaScript/TypeScript 行提供只读研究排序；候选 MUST 来自完整 diff 的新侧行，MUST NOT 把删除行、整份源码或未覆盖语言凑入。排序只使用新增行文本与结构特征，MUST NOT 为生成排序实时读取完整文件。每条 MUST 显示行号、代码和 0–1 研究排序分，并固定标注“研究排序，不是缺陷概率”；点击只定位到该行，MUST NOT 创建或修改个人草稿、提交级分数、默认模型或合并状态。模型不可用、diff 不完整、候选超过上限或无新增行时 MUST 显示原因，MUST NOT 用其他模型或提交级分数替代。

#### Scenario: 显示当前文件新增行排序

- **WHEN** 用户打开一个含 JavaScript/TypeScript 改动的固定 PR 文件并选择「行级排序」
- **THEN** 只显示该文件真实新增/修改行，按研究模型排序分降序排列
- **AND** 固定说明研究排序不是缺陷概率

#### Scenario: 点击定位

- **WHEN** 用户点击一条行级排序结果中的「在代码中定位」
- **THEN** 代码区定位到该目标行
- **AND** 不创建或修改个人草稿、提交级分数和合并状态

#### Scenario: 不支持或不完整

- **WHEN** 文件语言不在模型覆盖范围、diff 不完整、候选超过上限或没有新增行
- **THEN** 显示具体原因，不把整份源码或其他分数当作行级结果
