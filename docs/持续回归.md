# 持续回归

`.github/workflows/regression.yml` 独立于模型风险报告运行。它只表达工程检查结果，不用模型分数决定合并，不自动部署、评论 PR 或修改分支保护。

## 层级

| 层级 | 触发 | 范围 |
| --- | --- | --- |
| 关键层 | PR 创建/更新/重开、main 推送 | 明确列出的后端测试、完整前端单元测试、类型检查、构建、VS Code 扩展测试 |
| 完整层 | 每日 UTC 19:00、手动 | 全部后端测试、同一前端与扩展检查、模型包恢复浏览器旅程、项目分析到 PR 续审浏览器旅程 |

同一 PR 的新提交可取消旧的关键层运行；定期完整层使用独立并发组，不互相取消。

## 检查清单

`backend/scripts/regression_scope.py` 是唯一清单来源。清单为空、文件不存在或完整层缺少浏览器配置时直接失败，不产生空收集通过。

- 关键后端：模型包、冻结运行身份、schema、切分、数据集、成熟准入、训练任务、用户权限、目录接口、项目数据集、仓库同步与更新、PR 审查与更新、API 与 OpenAPI 契约。
- 前端：`npm ci`、`npm run typecheck`、`npm test`、`npm run build`。
- 扩展：`npm ci`、`npm test`。
- 浏览器：`playwright.model-package.config.ts`（模型包恢复）与 `playwright.regression-pr.config.ts`（项目分析到 PR 续审，两个账户隔离）。

新增能力合入后应更新清单；完整层始终运行全部 `backend/tests`，新测试自动纳入。

关键层显式排除两个依赖开发机历史状态的用例，并在清单输出中列出：

- `test_old_model_without_supplement_marks_train_and_validation_not_recorded`：依赖旧 baseline 产物缺少新诊断的语义；干净检出会重建 baseline，不能复现该历史状态。
- `test_real_dataset_commits_page_stays_bounded`：依赖开发机真实目录库快照，不是 CI 必需夹具；缺省时显式排除，避免把 skip 计为通过。

## 干净环境准备

`backend/scripts/regression_environment.py` 在运行根创建 `databases/`、`artifacts/`、`output/`、`logs/`：

- 缺少 `backend/data/openstack/*` 时从配置中的固定公开地址下载并按 SHA-256 校验；校验失败即失败。
- `backend/artifacts/baseline` 与运行根的隔离基线缺失时，从公开固定数据构建；不使用开发机个人运行目录。
- 校验 `backend/model-packages/*.zip` 及其 `.sha256`；模型包缺失或哈希不符即失败。
- 不复制个人 SQLite、账户、未跟踪数据集或已启动服务状态。

安装顺序：Python 3.12 → CPU `torch==2.14.1` → `backend/requirements.txt` → `backend/scripts/requirements-contract.txt`；前端与扩展使用各自 `package-lock.json` 执行 `npm ci`。Node 固定为 22。

## 端口、输出与清理

- 浏览器服务使用 `reuseExistingServer: false` 与显式端口；PR 续审配置使用 18860/18861，模型包配置沿用其专用端口。
- 每次运行输出写入 `$RUNNER_TEMP/jit-regression`；浏览器失败截图、trace 和服务日志写入 `docs/evidence/_run` 下的运行目录，不写正式数据或归档证据。
- 不结束占用默认端口的其他进程；端口被占用时由 Playwright 明确失败。
- 上传使用 `if: always()`，测试命令本身不使用 `continue-on-error`；上传缺失只警告，不覆盖测试失败状态。

## 本地等价运行

```bash
cd backend
./.venv/Scripts/python.exe scripts/regression_environment.py --root D:/tmp/jit-regression
./.venv/Scripts/python.exe scripts/regression_scope.py --layer key
./.venv/Scripts/python.exe scripts/regression_scope.py --layer key --pytest-junit D:/tmp/jit-regression/logs/key.xml
```

```bash
cd frontend
npm run typecheck
npm test
npm run build
JIT_PYTHON=../backend/.venv/Scripts/python.exe JIT_PREVIEW_BASELINE=D:/tmp/jit-regression/artifacts/baseline npx playwright test --config=playwright.regression-pr.config.ts
```

```bash
cd vscode-extension
npm ci
npm test
```

本地使用 `.venv` 仅影响命令路径；工作流使用 `python`。完整层本地等价执行以 `--layer full` 和两个专用 Playwright 配置为准。

## 平台与远端边界

- 当前采用 Windows runner 与 Edge，未声明 Linux/macOS 支持。
- 新工作流首次合入默认分支前，定期和手动入口不能在默认分支触发；合入前只做本地等价与工作流 YAML 校验，不把本地结果写成远端通过。
- fork PR 使用普通 `pull_request`、只读权限和公开依赖；不读取仓库变量中的模型报告配置，不执行特权事件代码。
- 浏览器依赖（Edge、Playwright 包）不可用时对应步骤失败并保留准备日志，不静默跳过整个旅程。
