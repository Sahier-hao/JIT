## 维护约定

- 产品行为变化先更新相关规格与[当前产品](当前产品.md)，再在[审计](审计/)记录真实验证。
- 文档中的相对链接必须可解析；运行 `python backend/scripts/check_docs_links.py` 自检。
- 不向 Git 提交原始运行日志、大体积中间产物或本机采集数据集；冻结证据只保留可复核的结论与哈希。
