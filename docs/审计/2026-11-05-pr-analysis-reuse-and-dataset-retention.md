# PR 分析复用与数据集保留验收（2026-11-05）

## 范围

对应 change `reduce-pr-analysis-storage-and-latency`：仓库克隆缓存、PR 特征复用、数据集来源标记与 PR 数据集清理。

## 实际验证

### 仓库缓存

在临时缓存目录中对公开仓库 `octocat/Hello-World` 连续采集两次：

| 次数 | 缓存命中 | 耗时 | 记录数 |
| --- | --- | --- | --- |
| 第一次 | 否 | 2.10 s | 2 |
| 第二次 | 是 | 1.81 s | 2 |

两次生成的 CSV 字节完全一致；缓存目录只保留一个裸克隆。缓存命中只影响准备仓库的成本，不改变采集结果。

### 特征复用

隔离测试中，同一 PR 快照的全部提交在同仓库、同 `kamei14-git-v2` 已完成分析中都有保存特征时：

- 复用分析不调用采集，数据集版本为 null；
- 分析记录写入 `featureSource`，指向来源分析与 schema；
- 任一提交缺失或 schema 不同时整段重新采集，不复用部分字段；
- 风险分数仍由本次模型重新计算。

### 数据集来源与清理

- 新登记数据集写入 `usage=branch/pr` 与来源分析标识；旧描述文件缺少来源字段时按分支读取。
- 列表与版本查询返回来源类型、来源分析和引用类型。
- 可清理列表只包含来源为 PR、超出保留数量且未被分析或模型引用的版本；分支数据集不进入列表。
- 显式清理删除登记、提交、特征与文件；被引用版本和分支版本会被跳过。
- 自动清理默认关闭，仅在 `JIT_PR_DATASET_AUTO_PRUNE` 显式开启时于服务启动执行。
