# 训练实验页结果展示精简

基线为 `main@a71e3bd`。本轮只改前端展示，不改变训练、比较或登记语义。

## 问题

用户打开“我的训练”中的三模型实验时，页面同时出现：

- “三档结果比较”一次只显示一个指标，且“训练档/验证档/测试档”不是常用说法；
- 默认展开的“验证集阈值对比”占用大量空间；
- 单模型测试指标和阈值预览又在“训练过程”里重复出现；
- 顶部没有数据集、切分和模型数的概览，“登记本次模型”也没有说明登记后的用途。

## 调整

- 实验页顶部增加实验概览：数据集、时间切分、模型数/完成数、登记状态；实验状态放到标题行。
- 比较区改为“模型对比”：默认直接展示测试集 AP、ROC-AUC、F1、精确率、召回率、Recall@20%LOC，并标出每列最高值；训练集与验证集指标收进折叠区。
- 阈值调整、模型参数与训练详情、训练过程全部收起；阈值区标题说明“在验证集选阈值，用测试集复核”。
- 术语统一为训练集/验证集/测试集；指标统一用 AP（Average Precision），不再与 PR-AUC 混用。
- 登记按钮改为“登记为可用模型”，概览显示“尚未登记/已登记 N 个”。
- Kamei 2013 ZIP 导入的数据版本显示为“Kamei 2013 · <项目>”加时间范围，完整版本号保留在悬停提示和模型详情中。
- 管理员实验页同步使用同一比较组件和术语。

## 验证

- `npm run typecheck`、`npm run check:styles`、`npm run check:modules` 通过。
- `npm run lint` 无错误，保留既有警告。
- `npm test`：72 个文件、609 项通过。
- `npm run build` 通过，保留既有分块体积警告。
- 用实验实际数据在 1280px 和 390px 视口渲染：新结构与指标显示正常；390px 下文档宽度等于视口宽度，没有横向溢出。
- 浏览器渲染时在 API 边界替换了登录会话与实验/比较响应，仅用于本地查看版式，不作为登录旅程或 e2e 证据。

## 边界

- 比较表展示的是测试集点估计；标“最高”只表示该列数值最大，不做显著性判断，也不自动选择模型。
- 未运行完整 Playwright 验收套件；更新了管理员多方法实验 e2e 的标签断言。
- 没有后端、数据库或模型产物变更。
