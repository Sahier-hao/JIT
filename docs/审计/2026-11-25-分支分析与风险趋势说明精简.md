# 分支分析与风险趋势说明精简

基线为 `main@a71e3bd`。本轮调整分支分析页的按钮层级与风险趋势页的说明，不改变分析、分桶或样本规则。

## 问题

- 分支分析页同时出现“分析分支提交”和“查看提交明细”两个主按钮，层级冲突。
- 风险趋势页使用“调整口径”等内部术语；一条无图例的覆盖色条难以理解；在只有 7 条已评分提交时仍渲染大面积空图表，且高分占比不可用的时间段被误标为“无已评分提交”。

## 调整

- “查看提交明细”降为次级 outline 按钮；页面只保留“分析分支提交”一个主操作。
- “分析分支提交”弹窗补充流程说明：将采集该范围的提交、登记数据版本，然后用已有模型逐条打分；结果与缺陷引入证据并排显示。
- 风险趋势页：
  - 标题统一为“风险趋势”；
  - “调整口径”改为带滑块图标的“统计范围”，“可比分析口径”改为“分支与模型”，“口径与来源/说明”改为“数据来源/数据说明”；
  - 顶部说明改为“按时间查看已评分提交的风险分变化，不是缺陷率”；
  - 删除无图例的覆盖色条，改为一行可核对的“4 / 14 个时间段有已评分提交”说明；
  - 当已评分提交少于最小样本 20 时显示明确提示，说明只能作为个别记录，不足以判断风险升降；
  - 当所有时间段的“高分占比”都不可用时，不再渲染整块空图表，改为紧凑说明；逐周数据仍可展开查看；
  - 高分占比不可用的图表缺口标签改为“比例不可用”，不再误写成“无已评分提交”。

## 验证

- `npm run typecheck`、`npm run lint`、`npm run check:styles`、`npm run check:modules` 通过。
- `ProjectTrends`、`ProjectPage`、`ProjectPullRequests` 共 44 项测试通过；前端全量 72 个文件、610 项通过；生产构建通过。
- 用真实 claude-scholar 数据渲染：7 条已评分提交、4 / 14 个时间段覆盖；显示样本不足提示，只保留平均风险趋势图，高分占比改为紧凑说明；1440px 下无横向溢出。
- 浏览器渲染在 API 边界替换登录会话与响应，仅用于版式查看，不作为真实登录验收。

## 边界

- 最小样本 20、按周分桶、日期左闭右开、训练分区覆盖判断均未改变。
- 风险趋势仍保留；只是样本不足时不再用空图表冒充趋势。
- 没有后端、数据库或模型产物变更。
