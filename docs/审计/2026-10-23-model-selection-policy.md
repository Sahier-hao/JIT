# 模型策略验收

## 行为

- 管理员可以设置默认模型、启用及停用模型。当前默认不能直接停用，须先设置另一已启用兼容模型。
- 用户明确指定模型优先；现成模型及自动回退使用提交时绑定的默认。默认变化不改变排队任务，同参数但绑定模型不同的请求不合并。
- 执行选取前复查启用状态。已停用模型的新请求被拒绝，排队任务给出明确失败；已开始使用该模型的任务可以完成。
- 停用不删除产物、历史分数或审查计划。历史名称仍可读取，失败重试保留原模型，失效选择需要用户重新选择。
- 模型元数据未返回时显示读取中，不误报目录为空或原模型已停用。
- 策略写接口保持管理员会话和来源检查；公共选择元数据不包含维护证据。

初轮完整回归及单独复测发现预测时延超过原 250ms 预算。分段测量显示重复加载和解析产物占主要耗时，策略查询约 4ms。加载改为每个目录实例最多 16 项缓存；每次命中前后仍检查所有服务文件 hash，并重新读取策略。缓存后篡改测试通过，100 次真实预测 P95 为 231.2ms，随后完整后端回归通过，原门槛未修改。

浏览器服务、目录库、模型及本地 Git 数据均使用隔离副本；此验收不提供新模型效果结论。
