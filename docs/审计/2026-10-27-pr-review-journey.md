## 原生下载与反馈边界

实际浏览器下载取得工作单 JSON 与 Markdown 文件，内容包含固定目标 SHA；Markdown 的未覆盖计数与该浏览器实际进度一致。反馈文件只包含选中问题、来源、证据及反馈，没有测试用个人笔记 `PRIVATE_NOTE_MUST_NOT_EXPORT`、完整工作单或未选人工判断。
