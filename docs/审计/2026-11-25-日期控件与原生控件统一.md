# 日期控件与原生控件统一

基线为 `main@a71e3bd`。本轮把散落的原生日期、滑块、确认框和手写按钮换成现成组件，不改变页面业务语义。

## 调整

- 新增日期选择组件：`Popover + react-day-picker（Calendar）`，中文 locale，支持最小值/最大值、已选月份定位、手动输入、今天、清除和“应用日期”。
- 替换 10 个日期字段：
  - `ReviewWorkbench` 起始/结束日期；
  - `VerificationReport` 历史提交起始/结束日期；
  - `ProjectTrends` 趋势开始/结束日期；
  - `DatasetBuildParts` 构建范围开始/结束日期；
  - `DatasetCurationDialog` 保留日期范围的开始/结束日期。
- 新增 `Slider` 组件（Radix Slider），替换 4 个原生 range：
  - 模型试算初始阈值、结果阈值；
  - 训练阈值对比和验证集阈值试算。
- 新增共享 `ConfirmDialog`（AlertDialog），替换 2 处 `window.confirm`（完整草稿备份导入）。
- 其他原生控件统一：
  - 我的数据自定义 tablist → `Tabs`；
  - 算法库分类手写按钮组 → `ToggleGroup`；
  - 训练阈值对比的目标召回率原生 number 输入 → `Input`；
  - 账号资料卡、项目提醒行、试算记录、数据集列表、导入记录、算法列表等手写可点击卡片 → `Button`；
  - 检查训练准入、移除字段等裸按钮 → `Button`。

## 依赖

- `react-day-picker@^9.14.0`
- `date-fns@^4.4.0`（中文 locale 与 Calendar 格式）

## 剩余原生元素

- 2 个隐藏的文件选择 `<input type="file">`：浏览器原生文件选择器，保留。
- 语义 `<table>`、`<details>/<summary>`：保留原生 HTML，不引入包裹组件。
- 浏览器原生 `window.confirm` 已全部移除。

## 验证

- `npm run typecheck`、`npm run lint`、样式来源、模块边界检查通过。
- 前端全量：73 个文件、612 项通过；生产构建通过。
- 浏览器渲染：趋势筛选中的日期按钮打开日历，默认定位到已选月份；1440px 下无横向溢出；日期范围、手动输入、清除和今天均可用。
- 数据集构建与清洗流程的日期断言已按新控件更新；预测页阈值滑块测试改为键盘 End 与重置校验。

## 边界

- 没有后端、数据库或模型产物变更。
- 日期仍以 `YYYY-MM-DD` 字符串参与现有查询与请求，组件只负责选择与展示。
- 日期选择器新增为本地前端依赖，需要随 package-lock 一起提交。
