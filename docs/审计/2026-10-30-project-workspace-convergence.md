日期：2026-10-30。范围：项目页三视图收敛、PR 审查优先级与文件级风险排序、分支分析移除个人审查计划、迁移 017。对应变更 `deliver-project-continuous-review` 与 `retire-branch-review-plan`。

## 交付行为

| 能力 | 实现与验证范围 |
| --- | --- |
| 项目页三视图 | 概览、分析（页内切换「分析结果 / 风险趋势」）、PR 审查；风险趋势不再单列页签，旧 `/trends[/viewId]` 地址落到分析页趋势视图。 |
| 风险趋势 | 进入未指定 viewId 时按当前口径（优先当前结果所属口径）自动准备固定视图并写回地址；主图为平均模型风险分与高分占比两张单轴折线，等价表格同时给出提交量与平均分。 |
| PR 审查优先级 | 只读详情与工作单先展示提交风险排序；点击提交把文件列表限定为该提交触及文件，可切回全部文件；文件默认按风险排序并可切回路径；PR 清单支持当前页按更新/按风险排序，未分析 PR 排后并说明不能视为低风险。 |
| 提交文件映射 | 迁移 017 新增 `repository_commit.file_paths_json`；采集与任务完成时保存提交触及路径（含改名前的旧路径）；PR 读取返回每个提交的文件、增删行、文件数及 `fileRisks`。旧任务无映射时返回空文件列表并标注限制。 |
| 分支计划退役 | 删除 `review-plan/validate` 端点、`ReviewPlanService`、三个错误码与 OpenAPI 模型；前端删除 shortlist、计划转移与导入导出；提交详情改为对话框；旧 `/plan` 地址显示同一份提交明细。 |
| 浏览器旧数据 | 旧计划键保留、不迁移、不读取、不改写；界面不再展示或声称可恢复。 |
