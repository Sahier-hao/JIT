# 缺陷预测、无标签输入与评估交接

## 交付

- 用户入口由「模型试算」改为「缺陷预测」，侧栏、页头和面包屑一致；`#/my-predictions` 与 `#/my-predictions/:batchId` 保留，并新增 `/defect-predictions` 兼容别名。
- 单条预测支持数据版本选行、项目已保存分析提交、手工填写入模字段；批量预测支持完整数据版本、模型冻结分区、注册时间预设和无标签 CSV。
- 单条与批量统一使用 `predict_risks(snapshot.model, ..., snapshot.schema)` 和 `in_model_names()`。服务测试和隔离浏览器均比较同一模型同一记录的分数。
- `045_prediction_modes_and_sources.sql` 重建预测批次表：增加 `mode`、来源、可空标签、`label_availability`、分区/预设/成员摘要与真实模型身份列。升级前已备份本机目录库；v44→v45 测试覆盖旧批次复制与标签映射。
- 结果页提供记录标识、提交级预测分数、当前阈值分类、真实标签/无标签、时间/来源、归因入口、搜索/排序/分页、刷新重开和 CSV 导出。阈值变化只重算页面分类，不调用模型。
- 只有同时具备可用正负真实标签的批次显示「去评估」。新增 `#/my-evaluation?batchId=...&modelId=...&datasetVersion=...&partition=...&splitPreset=...`，回显批次/模型/数据/分区/预设，展示阈值工作点、混淆矩阵和精确率/召回率/F1 曲线。
- 无标签 CSV 不接收标签列，不写回 `commit_record`；未成熟、未知和无标签记录不进入阈值或评估指标。

## 契约

- 新增/文档化 `/api/v1/user/prediction-models`、`/prediction-samples`、`/prediction-splits`、`/prediction-batches` 单条/批量/无标签、`/{batchId}`、`/{batchId}/evaluation`、`/{batchId}/export`。
- 人工 OpenAPI、`openapi.generated.yaml` 和 `frontend/src/lib/api-generated/types.gen.ts` 同步更新。
- 单条缺字段、schema 不匹配、未知字段或非有限数值返回明确 `FEATURES_INVALID`，不保存部分结果。
