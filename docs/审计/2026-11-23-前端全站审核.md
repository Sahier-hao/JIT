# JIT 前端全站审核

审核覆盖公开入口、普通用户工作区、管理工作区和兼容地址。按正常使用顺序检查页面入口、主次按钮、搜索与筛选、记录与详情、弹窗、加载与空态、失败恢复、键盘操作和窄屏布局。页面修改复用项目现有的主题和控件。

## 共用界面

| 检查项 | 发现 | 本次处理 |
| --- | --- | --- |
| 两端工作区 | 顶栏、页标题和操作区在不同页面的间距、样式和对齐不同。最近项目容易因文本长度显得缩进不一。 | 两端收口顶栏和页面标题。窄屏时页面操作可换行。修正最近项目和管理端品牌入口对齐。用户、管理员仍分别使用已有账户菜单。 |
| 按钮与表单 | 描边按钮在多种底色上缺乏一致边界。输入框和选择器的阴影抢过内容。 | 统一按钮描边、悬停和键盘焦点。输入和选择器用同一组主题背景与边界。 |
| 弹窗和浮层 | 升高字号或减少视口高度时，默认弹窗可能超出可视区。浮层和对话框边界样式不统一。 | 默认对话框限高并允许内部滚动。菜单、选择器、浮层统一外观和边界。保留现有训练弹窗的独立滚动区。 |
| 加载、空状态和报错 | 有些短提示重复写加载文案并嵌入骨架；空状态和请求失败容易混淆。 | 页面仍可用内容骨架。行内加载保留单条状态说明。空态、告警和长错误消息共用反馈组件。 |

## 普通用户和公开入口

| 页面或场景 | 检查与处理 |
| --- | --- |
| 首页、登录、注册、研究预览 | 首页和研究预览共用入口外壳。缩短登录入口说明，突出身份和表单。用户与管理员身份使用同一个可用方向键操作的标签组件。注册和首次配置仍使用原入口。 |
| 账户与个人中心 | 检查顶栏账户菜单、个人中心弹窗及旧地址。保留已确认的账户菜单外观，个人中心沿用共用浮层。 |
| 站内提醒 | 增加铃铛、未读数和最近提醒。查看列表可留在当前页面，进入具体提醒时携带原固定来源。完整提醒按类型、时间、标题、动作排列，并保留分页、刷新和本页已读。损坏的浏览器已读记录会显示错误，仍可打开提醒来源。 |
| 项目列表、新建及管理 | 统一标题和新建入口。项目卡片在窄屏可缩至容器宽度，保留改名和删除流程。新建、确认和错误反馈使用共用浮层。 |
| 项目概览、分支分析、PR、趋势 | 项目名和仓库地址可换行。项目视图切换可在窄屏换行。检查分支分析、批量 PR、自动打分、趋势切换及指向已有结果的操作。 |
| 我的审查、PR 工作区与固定快照 | 审查队列使用统一标题。PR 工作区把版本、更新、关注和输出放到独立操作区，窄屏可换行。固定快照标题可以容纳长标识。 |
| 分析对比、历史提交和旧审查计划 | 对比使用统一标题。历史地址保留原有兼容流程。提交列表、提交弹窗和错误反馈纳入共用样式检查。 |
| 我的数据 | 自有数量和导入、构建操作归到同一标题区。覆盖自有、共享、构建与导入记录入口，以及数据明细、采集和清洗弹窗。 |
| 我的训练 | 使用统一标题和主操作。训练记录的时间与状态列更稳定。筛选无结果可直接清除筛选。空数据弹窗可以一步进入「我的数据」。训练详情用更明确的所选任务样式。 |
| 算法库与算法详情 | 算法库在读取时仍显示页面标题，完成后显示实际方法数。检查方法筛选、结构图和详情浮层。 |
| 我的模型 | 用统一空状态和模型卡片。空状态按钮进入训练页。读取失败时直接重试，登录过期仍走会话恢复。 |
| 模型试算 | 设置或结果先呈现，历史记录在桌面右侧，窄屏在下方。保留记录选中状态和阈值键盘焦点。 |

## 管理工作区和兼容入口

| 页面或场景 | 检查与处理 |
| --- | --- |
| 管理员账户、模型管理与模型详情 | 使用同一套顶栏和标题布局。模型目录的筛选区域和选中行更易区分。详情、策略和确认操作继承共用控件。 |
| 数据集与版本 | 数据集目录与模型目录共用筛选头、选中样式和滚动细节。核对数据版本直达及详情入口。 |
| 训练任务、任务详情、多方法实验 | 纳入两端共用标题、按钮、确认和反馈。检查任务分页、状态、详情以及取消、重试入口。 |
| 模型评估、模型比较、多项目实验和登记产物 | 评估首页采用统一标题和带键盘焦点的入口卡片。比较页、实验报告和产物详情共用标题和状态反馈。 |
| 验证报告、历史提交和趋势 | 统一标题、来源摘要和视图入口。日期和提交搜索可在窄屏分行。报告保留数据来源和指标含义。 |
| 旧地址与未知页面 | 核对旧入口、旧同步和未知页面的路由与状态反馈。 |

## 验证范围

- 53 个地址包含正式入口、兼容入口、未知地址和查询参数示例。在 390 与 1440 像素浏览器视口巡检页面级横向溢出和运行时异常。
- 浏览器使用隔离的 API 测试数据。缺少来源的深链接覆盖读取失败或不可用状态。PR 真实补丁、历史报告真实数据、模型登记与服务端训练未在这轮浏览器巡检中使用线上数据。
- 前端单测覆盖训练提交和进度、管理员目录和训练、审查流程、数据导入与构建、试算、路由及接口校验。构建保留 Vite 的分包体积提示。

- 106 次浏览器地址与尺寸组合检查均未发现页面级横向溢出或未捕获的页面异常。另验证了四套主题下的提醒浮层、Esc 焦点归还、提醒已读与固定来源跳转、登录身份键盘切换、训练空态跳转、清除筛选和管理员菜单。
- 前端全量 593 项单测通过。最后修正后，43 项相关单测和生产构建、样式、模块边界、Lint 检查通过。改动已落入本地工作区，尚未部署。
