# 仓库概览与只提醒验收

日期：2026-10-30。范围：新建项目只登记、仓库概览（公开 GitHub 元数据与活跃度图）、项目页概览/分析拆分、分支检查改为只提醒、迁移 016 与真实库升级。

## 交付行为

| 能力 | 实现与验证范围 |
| --- | --- |
| 新建项目 | 只登记仓库，不自动分析、不自动开启提醒；建立后落在项目「概览」。前端请求显式 `autoUpdate:false`，后端不 enroll。 |
| 项目页拆分 | 四个子视图：概览（仓库信息）、分析（当前结果与分析记录双栏）、PR 审查、风险趋势。概览不随分析结果变化；旧 `/analyses` 落到分析。 |
| 仓库概览 | `GET /api/v1/repositories/{id}/overview` 读取公开 GitHub 元数据、语言、最近 100 条提交和最近 12 周活跃度；缓存约 10 分钟。非 GitHub、限流或失败时显示缓存/原因，不画空图。 |
| 图表 | 活跃度单轴周提交柱图，附等价数据表、键盘焦点和提示；语言横向条形。均标注“仓库活跃度不是模型分数或缺陷率”。 |
| 分支提醒 | watch 只检查远端 HEAD；发现与当前分析 HEAD 不同的新 HEAD 时写 `branch-updated` 事件，不创建分析。同一 HEAD 去重；分析完成同一 HEAD 后不再待处理。 |
| 用户发起分析 | 概览/提醒的「分析这次更新」预填分支，用户选择模型、日期和提交上限；原分析不受影响。 |
| 升级 | 迁移 016 新增 `repository_overview` 缓存表；显式初始化旧库前自动生成一致 SQLite 备份。 |


## PR 审核入口收敛

- 项目 PR 清单改为先打开只读详情，不再自动创建工作单；只有「开始审查」才写入个人草稿并出现在「我的审查」，已有工作单显示「继续审查」。
- 只读详情展示来源、作者说明、提交、文件 Diff 和模型线索；打开时不写入 localStorage；读取失败保留返回项目 PR 的入口。
- 工作单保留项目侧栏和页面留白，三栏卡片化；≤1024px 保留文件栏并将问题面板下移，≤720px 单列堆叠；PR 页面包屑统一为「PR 审查」。
- 验证：`ProjectPRJourney.test.tsx` 5 项、`ProjectPullRequests.test.tsx` 5 项通过；桌面/手机 E2E 各 1 项通过（17.5 秒）；预览截图 `desktop-1440-pr-preview.png`、`mobile-390-pr-preview.png`，工作单截图 `desktop-1440-workbench.png`。

## PR 审查页布局收敛

- PR 清单改为工具栏加单卡片列表：范围切换用分段控件，右侧是「自动分析」与「检查远端 PR」；每条 PR 一行（编号与标题、状态、作者、更新时间、分析状态），空态、分页和检查时间收进同一张卡片。
- 原先吊在列表底部的「项目 PR 自动跟踪设置」折叠块取消，改为工具栏「自动分析」按钮打开的对话框；模型、间隔、启用范围与显式确认流程保持不变。该入口只负责后台发现与固定快照分析，与项目头部只查分支的「分支提醒」区分开。
- 页面正文不再堆叠 11–12px 辅助说明：只保留一行 14px 只读说明，列表元信息 13.5px、页脚 13px。
- 下拉层叠顺序修正：`.ui-select-content` 提高到对话框之上，避免对话中的模型与间隔下拉被遮罩盖住。
- 本轮按用户要求先完成改动，未重跑组件测试与 E2E；`ProjectPullRequests.test.tsx`、`project-workspace.spec.ts` 已按新入口和 Radix 下拉更新。已在真实服务上实际检查桌面、768px、375px 与深色主题；类型检查通过。

## 分支分析移除个人审查计划

- 已合并到 main 的提交无法在审查中阻止进入，分支分析改为只承担风险度量与复盘：项目「分析」页保留当前结果、提交明细、筛选与单条详情，不再提供「审查计划」分段视图、加入清单按钮和计划导入导出。
- 入口按钮从「查看提交与审查计划」改为「查看提交明细」，面包屑从「提交审查」改为「提交明细」；旧 `/plan` 地址兼容为同一份提交明细。
- 旧版本保存在浏览器的计划数据没有删除，也没有迁移或改写；当前界面不再展示或写入。PR 的审查进度、问题和证据仍在 PR 工作单与「我的审查」。
- 本轮按用户要求先完成改动，未重跑组件测试与 E2E；`ProductWorkspace.test.tsx`、`ProjectPage.test.tsx`、`repositoryExplanation.test.tsx` 与 `e2e/focused-review.spec.ts` 已按新行为更新。类型检查通过；已在真实服务上确认提交列表、详情与旧 `/plan` 地址。
