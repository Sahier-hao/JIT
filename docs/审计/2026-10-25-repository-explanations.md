# 固定项目分析的提交模型解释验收

日期：2026-10-25。范围：固定成功分析的解释读取、主动生成、原模型核对、保存、恢复与提交详情。对应 change：`explain-repository-commit-risks`。

## 产品行为

- GET 只读取保存结果，尚未生成时明确返回 `not-generated`；POST 使用原分析的模型及运行，核对原输入和分数后生成。
- 原模型不可用、身份不符、字段缺失或分数不一致时返回公开原因，不换模型、不改风险；失败可恢复后重试。
- 成功结果保存完整上下文、模型哈希、方法、基线来源及时间；重复 POST 和重开原样返回，无需再次加载模型。
- 详情展示最多五个带符号非零影响；均值、混合或零基线明确可辨，不声称缺陷结论、因果解释或代码定位。
- 迁移 010 新增解释表，外键随分析删除清理。生成不改变个人计划键和已有选择。

## 边界

- 沿用单后端实例，单服务内串行生成；未验证分布式重复请求协调。
- 基线是模型绑定数据集的已登记字段均值，不宣称仅来自训练划分。缺失字段显式归零，遮挡贡献不是可加因果分解。
- 未执行 GPU 试验、新仓库概率校准或缺陷准确率验证；不把功能验收作为模型效果证据。
