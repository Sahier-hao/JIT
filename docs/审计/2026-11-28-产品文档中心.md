# 产品文档中心实施与验收

对应 OpenSpec change：`add-product-documentation-center`。

## 交付范围

- 新增公开路由 `#/docs` 与 `#/docs/:slug`，匿名可读，登录判断之前挂载。
- 新增 9 篇中文 Markdown 文章、4 组导航、61 个稳定小节标识和本地中文搜索。
- 新增桌面三栏阅读、窄屏折叠章节导航、文章内直接定位、无效小节提示和未知文章空状态。
- 新增首页文字「文档」入口、用户工作区右上角文档入口，以及分支分析、PR 预览／工作单、模型评估的业务帮助链接。
- 新增公开内容发布清单 `frontend/src/features/docs/catalog.ts`、维护说明和 `check:docs` 命令。

## 浏览器验收

验收脚本：`frontend/scripts/docs-acceptance.mjs`。运行在独立生产构建预览 `http://127.0.0.1:14273`，不启动、不停止其他业务服务。

### 匿名与离线

- 首页文字「文档」入口可匿名进入文档。
- 所有 `/api/**` 返回 503 时，首页、文章和搜索仍正常；实际只触发既有 `/api/user/session` 检查，未请求项目、模型或报告数据。
- 1280px 首页文档滚动宽度 1280 / 可视宽度 1280；390px 首页、首次审查文章和 VS Code 文章均为 390 / 390。
- 桌面三栏和右侧本页目录可见；390px 可展开「章节导航」，图片、表格和代码块可读。

### 地址与搜索

- 直接打开 `#/docs/reading-results?section=commit-score` 后标题顶部为 92px；刷新后仍为 92px。
- 从本页目录进入 `code-clues` 后，浏览器后退恢复 `commit-score`，前进恢复 `code-clues`。
- 无效小节保留文章并显示提示；未知文章显示文档内空状态与返回首页按钮。
- 点击搜索「私有仓库」定位到 `#/docs/faq?section=private-repository`。
- 键盘输入「VS Code」后方向键选择、Enter 打开，定位到 `#/docs/vscode-commit-check` 的相关小节。
- 390px 首次审查表格外层为 `overflow-x: auto`，表格 544px 在 358px 容器内滚动；代码块同样在自身容器内滚动，页面本身仍为 390 / 390。

### 业务入口与现场保留

- 登录夹具下，从工作区右上角「文档」打开新标签文档页，再从文档内「项目」进入受登录保护的 `#/projects`。
- 分支分析夹具的项目结果卡显示「怎么看分数」，新标签打开 `#/docs/reading-results?section=commit-score`；关闭后原项目页仍在。
- PR 工作单夹具预置了选中文件 `src/token.py`、问题草稿和「个人笔记」`Draft scratch text`。点击「怎么看代码线索」后文档在 `code-clues` 新标签打开；关闭新标签后，原工作单仍保留同一 Diff、选中文件和草稿。

## 公开边界

- 文档分包包含九篇公开文章和公开 SVG，不包含 `/admin/datasets`、`C:\Users\...`、`docs/evidence` 或目录库路径；脚本与测试同时检查内部链接、图片和未发布内容。
- 后端代码、接口、数据库和既有管理员权限未修改。文档路由在登录边界前公开，但正文中的项目、工作单等地址继续走现有登录流程。
- 页面只请求既有会话接口；项目、模型和报告接口全部离线时，文档正文与搜索仍可用。
