# 行级特征贡献（2026-11-26）

## 范围

研究预览 `#/research/line-model` 与 `POST /api/v1/research/line-model/score` 新增逐行
特征贡献。模型产物、默认模型、项目分析、PR 审查与提交级分数均未改变。

## 响应口径

- 原有 `score` 字段与按分数降序的排序保留；`score` 仍是未校准的排序分数，不是缺陷概率。
- 响应新增 `intercept`、`contributionUnit = "logit"` 与固定文案
  “行级特征贡献，不是缺陷原因。”
- 每行新增 `logit`、`contributions`、`contributionTotal` 与 `otherContribution`。
- `contributions` 返回绝对值最大的前三项，每项包含特征名、本次值、模型权重与
  `value × weight` 的贡献值。
- `contributionTotal` 是全部特征的贡献和；`otherContribution` 是未进入前三项的其他
  特征贡献合计。

分解恒等：

```text
intercept + contributionTotal = 该行原始 logit
sum(contributions[].contribution) + otherContribution = contributionTotal
```

展示概率使用原逻辑回归的 sigmoid，并在极端值上保留原有 `[-60, 60]` 数值保护；恒等校验
针对未截断的原始 `logit`。因此没有减少或更换模型特征，也没有改变排序。

## 前端

- 结果行可展开“行级特征贡献”，显示前三项与“其余特征”合计、截距。
- 特征名使用现有产品中文名：行长度、缩进、赋值、调用、标识符、TypeScript 语言项等。
- 展开文案固定为“行级特征贡献，不是缺陷原因。”
- 旧响应没有贡献字段时仍显示排序结果，展开按钮不可用，不报错。
