# PR 分析流程与界面收敛验收

日期：2026-10-30。范围：PR 批量分析入口、模型选择、PR 分析记录与分析记录分离、只读详情收敛、界面文案规则。对应变更 `refine-pull-request-analysis`。

## 交付行为

| 能力 | 实现与验证范围 |
| --- | --- |
| 批量分析入口 | 项目页头部「分析全部 PR」弹出模型选择，确认后调用 `POST /api/v1/repositories/{id}/pull-requests/analyze`，后台逐个固定快照分析；已有完成分析的 PR 跳过。 |
| PR 分析记录 | PR 审查页改为左侧清单、右侧「PR 分析记录」；记录显示状态、模型名、最高提交分与时间，点击进入详情。 |
| 记录分离 | 项目「分析记录」接口排除 `source_kind='pr'`，分支分析记录不再出现 PR 任务；PR 任务只在 PR 页可见。 |
| 状态如实 | `queued`/`running`/`completed`/`interrupted`/`cancelled`/`failed` 按实际状态显示，中断不再显示为「分析中」；只有完成才计算最高分。 |
| 模型身份 | 手动 PR 分析返回实际 `model_id`/`resolved_model_id`，前端用模型目录显示名称（如「逻辑回归 · 六字段」）。 |
| 只读详情 | 只读详情移除模型选择、生成、重试与取消，只展示已保存分析结果；分析统一从列表发起。 |
| 文案规则 | 删除 PR 页解释性段落与重复汇总，只保留状态、数据与操作；规则写入 `AGENTS.md`（UI copy）。 |
| 契约 | `docs/api/openapi.yaml` 新增批量与单 PR 分析路径及请求/响应 schema。 |

## 验证

- 后端全量：**584 通过**，2 条既有警告，313.53 秒。
- 前端全量：**38 个文件、301 项通过**；类型检查、构建通过。
- 浏览器检查（隔离服务）：项目页「分析全部 PR」弹出模型选择；PR 页两栏布局（764px + 340px）与记录渲染；记录显示「分析完成 · 逻辑回归 · 六字段 · 最高 0.658」；中断任务显示「已中断」。
- 修复项：分析记录查询改为 API 层过滤（内部测试与后台仍可读全量）；导航测试等待懒加载页面最多 5 秒；Mantine 测试环境禁用过渡。

## 未验证与边界

- 未重跑隔离浏览器 E2E（桌面 1440 / 手机 390）。
- 批量分析在单 worker 下逐个执行，62 个开放 PR 需要数分钟；中断后可再次点击批量入口补齐。
- 页面文案清理以 PR 审查页为主，其他页面的解释性文字将在后续改版中按同一规则处理。
