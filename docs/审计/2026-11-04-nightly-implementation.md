| 训练类别策略 | 训练任务可选加权或采样，只作用于训练分区；记录策略、种子和前后数量；数据集详情提供选择 |
| 解释背景 | 基线改为训练分区均值；保存背景哈希；合法扰动稳定性；旧解释标注背景未知 |
| 代码候选 | Python AST 候选规则、候选表、PR 快照接口、工作单候选区域和确认/驳回/暂缓判断 |
| PR 检查报告 | `pr-check-export` / `pr-check-report`，JSON/Markdown，身份与覆盖校验，退出码，默认非阻断；GitHub Actions 示例 |
