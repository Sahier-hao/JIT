## 隔离测试

`backend/tests/test_pr_updates.py` 使用临时 SQLite 与可控 GitHub 夹具覆盖：

| 行为 | 结果 |
| --- | --- |
| 全部、前 N 个、当前页三种范围 | 范围固定为条目；前 5 个只处理 1–5；第 2 页只处理本页编号 |
| 非法范围 | 0、501、页码 0/101、未知类型均在创建前拒绝，未产生批次 |
| 取消进行中批次 | 待处理条目变为已取消，已提交条目保持原状态；重复取消幂等 |
| 取消已结束批次 | 返回 `PR_BATCH_NOT_CANCELLABLE`，原状态不变 |
| 分组重试 | 默认只重试失败项；中断项需要显式选择，两者不会混在一起 |
| 同模型复用与换模型 | 同快照同模型仍只有一个任务；不同模型新增独立分析并保留旧结果 |
| 旧库升级 | v24 批次补 `scope_kind=all` 与空取消字段，外键检查通过 |
