# 证据目录约定

本目录保存**已冻结、可复核**的结论、清单与少量关键产物。代码与测试引用的证据目录继续保留：

- `model-diagnostics/`：九个历史模型的三档诊断报告。
- `model-card-benefits/`：与当前模型包身份绑定的审查收益报告。
- `evaluation-matrix/`：多模型评价矩阵。
- `review-benefit-2026-11-16/`、`label-observation-2026-11-15/` 等按 change 冻结的报告。
- 其他按日期或 change 命名的目录：历史交付与验收证据，只读保留。

## 运行工作区

`_run/` 是可覆盖、被 `.gitignore` 忽略的运行工作区，用于浏览器结果、临时日志、截图与性能基线。它不属于交付事实，可随时重建。

## 提交规则

- 冻结证据必须包含可复核的结论、输入身份与 SHA-256；不提交原始逐次运行日志和大体积中间产物。
- 新的运行结果先写入 `_run/`，经筛选、去敏、确认可复核后再显式冻结到按 change 命名的目录。
- 不把本机绝对路径、账户凭据、数据库或模型二进制提交到本目录。
- 代码或测试依赖的证据文件不得删除；删除前必须确认零引用。
