# JIT-Fine 大型 14 维基准证据

本目录冻结 `add-large-jit-benchmark` 的可公开验证事实：JIT-Fine 数据审计、规范化数据描述、九种方法的同口径结果、逐运行身份、测试结果和 OpenSpec 严格校验结果。

## 数据边界

- 来源：`https://github.com/jacknichao/JIT-Fine`
- revision：`584799fdec6095ab75a45fd2a5f8db5b12163aa5`
- `data.zip` SHA-256：`9e5ca1a393b70ee7e87c410b162005958775f3f3732f9f83da9dd24a7dfe2b47`
- 规范化 CSV SHA-256：`89a0715bd82e87dc283933b7420453a365861dbf02082bd8bc06ca63c056a0d4`
- 纳入样本：25,602 条，其中 2,217 个正例、21 个项目
- 时间切分：训练 17,912 / 1,751，验证 3,847 / 310，测试 3,843 / 156

JIT-Fine 仓库未声明许可证（GitHub 报告为 `NOASSERTION`）。因此原始 ZIP、规范化 CSV、模型二进制和逐条测试输入均未进入本证据目录；这里只保留来源、哈希、字段映射、统计和实验结果。复现者必须自行取得固定快照并确认使用条件。

## 冻结内容

- `audit.md`：候选来源、字段、标签、样本门槛和许可证审计。
- `dataset-manifest.json`：数据版本、14 维字段声明、来源成员哈希、质量统计和纳入规则。
- `suite.json`：九种方法、数据版本、schema、指标集及运行状态。
- `method-comparison.json`：同一测试成员上的指标、混淆矩阵、努力口径和训练耗时。
- `runs/<method>/`：每个方法的运行清单、指标和摘要，用于核对运行身份及限制说明。
- `verification/`：全量测试、逐运行校验、OpenSpec 校验和受保护范围检查。
- `failure-records.json`：本次方法失败记录；本轮为空，因为没有方法失败。
