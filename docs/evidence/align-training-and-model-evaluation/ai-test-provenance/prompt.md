# AI 测试生成与修改来源

来源：Codex，基于用户提供的正确图片「B 同学 · 模型训练与评估」及以下明确要求：

- 自定义训练、验证、测试比例，保留默认与既有预设。
- 预览时间范围、样本数、正例数和失败原因。
- 训练完成后登记精确模型，并在评估页选择同一模型。
- 独立模型评估页提供「评估本次训练」和「评估预测结果」。
- 正式测试使用固定分区和预先确定的缺陷阈值，阈值探索在验证集。
- 未成熟、未知标签单独显示，缺少可靠标签时不得生成正式评估。
- 使用真实隔离服务 E2E，不能以 mock API 响应代替浏览器旅程。
- 不修改训练算法、模型风险算法、默认模型或原分析口径。

本次新增或修改的测试集中在切分、训练任务、精确登记、标签资格、评估页面、路由、OpenAPI 清单、四类矩阵和真实浏览器旅程。
