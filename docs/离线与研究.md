# 提交解释、离线报告与行级研究

本页承接[当前产品](当前产品.md)中的离线集成细节；这些能力不进入在线项目分析或 PR 合并决定。

## 提交模型解释

在固定分析的提交列表点开一条提交，可「生成模型解释」。读取详情不运行推理；生成仅使用该分析登记的模型、运行和字段，核对保存分数，成功后保存至多五个非零特征影响、本次值、基线、方法和来源。基线来自原模型训练分区字段均值；缺失时退回零基线并显示缺失字段。归因说明单特征敏感度，不是缺陷结论、因果解释或代码定位；排序不稳定时明确标注。新解释另保存只由本次贡献项生成的中文模板摘要；旧解释缺少该字段时回退原摘要，不重算或改写。原模型损坏、运行不匹配或重算不一致时显示原因并保留旧分数。接口为固定项目提交的 `/explanation` GET/POST，必须显式传入 `viewSyncId`；删除分析会一并清理解释。

## PR 检查报告

`pr-check-export` 从本机目录库的固定快照与分析导出可移植分析包，包含身份、逐提交分数、候选位置、已保存的后续修复证据和覆盖说明，不含个人草稿。`pr-check-report` 读取分析包生成 JSON 或 Markdown，读取已保存分数，不要求模型可加载；身份不匹配时失败。Markdown 的修复证据表可链接到修复提交 diff 的文件与行号；证据只作参考，不是模型生成的补丁。命令默认不阻断合并、不评论 PR、不访问本机服务；退出码区分成功、分析缺失、身份不匹配和输入无效。

`pr-check-analyze` 从本地 Git 仓库明确的 base/head 执行真实特征采集、推理和报告，记录仓库与提交身份、模型运行与参数、逐提交分数、覆盖、候选与建议；同一范围与模型幂等，无变更、身份不一致、模型缺失和 schema 不匹配有明确退出码。报告同时为每个评分提交保存提交级特征归因 `explanation`（状态、方法、贡献和中文摘要）；归因失败只降级为 `not-supported`，不改变分数，`jit-commit-analysis-v1` 保持向后兼容。`pr-check-models` 只读列出目录库中已启用、ready 且所有入模字段都能由提交采集生成的真实模型。CI 示例默认只上传报告，不评论、不阻断合并。

## 行级研究

行级研究仍不进入项目分析、模型目录、默认模型或提交级风险。`line-train` 读取 `line-szz-v1` JSONL，输出报告与可移植 manifest（输入哈希、采样摘要、切分成员哈希、环境与复现命令），按语言/仓库报告 ROC-AUC、PR-AUC、Brier 与抽样负例定位代理指标。当前证据不足以承诺逐行概率；研究预览 `#/research/line-model` 只展示固定实验口径并按行返回排序分数，固定标注“不是缺陷概率”。结果行可展开前三项行级特征贡献、截距和其余贡献合计，文案固定为“行级特征贡献，不是缺陷原因”；贡献是线性分解，不是因果解释。

PR 只读详情和审查工作单的代码阅读区提供「行级排序（研究）」页签：只对当前固定快照中真实新增/修改的 JavaScript/TypeScript 行排序，候选来自完整 diff 的新侧行；只使用这些行的文本与结构特征，不读取完整文件，因此公开 GitHub 限流或源码不可读时仍能给出同一份排序。每条显示行号、代码、排序分和前三项特征贡献，固定标注“研究排序，不是缺陷概率”。点击只定位到该行，不创建或修改个人草稿、不改提交分数、默认模型或合并状态。不支持的语言或没有可分析的新增行时显示具体原因，不静默替换模型。2026-11-26 的完整候选集影子评估仍未通过两个未见仓库全部指标门槛，见[行级定位影子评估](审计/2026-11-26-行级定位影子评估.md)、[行级特征贡献](审计/2026-11-26-行级特征贡献.md)。

## VS Code 扩展

`vscode-extension/` 提供 VS Code 扩展：提交后自动对 `HEAD~1..HEAD` 运行 `pr-check-analyze`，状态栏显示「提交级预测分数」，可疑代码行写入 Problems 并标到对应行号；也可显式导入已有报告，核对仓库提交与当前 HEAD，身份不一致或行号过期时拒绝定位。扩展不修改源码、不自动提交、不评论 PR；报告中的路径与文本按不可信数据处理。「JIT: 配置提交后检查」和「JIT: 选择模型」通过 `pr-check-models` 的 QuickPick 只列真实可用模型，CLI 不可用时才回退手工输入，绝不编造模型。「JIT: 查看提交解释」以只读虚拟 Markdown 文档展示提交 SHA、模型身份、提交级预测分数、中文摘要和 Top 特征贡献，不渲染报告 HTML 或执行命令；提交节点、通知和命令面板均可进入。每条可疑代码行显示规则 ID、命中证据和说明，点击跳转到文件和行号。「JIT: 复制报告生成命令」仍只复制 CLI 命令，不执行。扩展 `0.4.0` 由独立工作流运行测试、打包并上传 VSIX。
