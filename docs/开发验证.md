# 隔离开发验证

在项目根目录 PowerShell 执行。默认开发服务与库不由测试复用或回收；只结束本次启动的进程。端口被占用时应失败并选择其他测试端口。

```powershell
$taskTemp = Join-Path (Get-Location) '.cache/redesign-validation/temp'
New-Item -ItemType Directory -Force $taskTemp | Out-Null
$env:TEMP=$taskTemp
$env:TMP=$taskTemp
$env:PYTHONIOENCODING='utf-8'
python -m pip --python backend/.venv/Scripts/python.exe install -r backend/scripts/requirements-contract.txt
./backend/.venv/Scripts/python.exe -m pytest backend/tests/test_openapi.py -q
./backend/.venv/Scripts/python.exe backend/scripts/probe_isolated_service.py
$env:JIT_SERVICE_PORT='18223'
$env:JIT_FRONTEND_PORT='14273'
Set-Location frontend
npx playwright test
```

契约依赖是固定版本 PyYAML/jsonschema；缺依赖造成的模块 skip 不算契约通过。2026-10-19 首次执行 OpenAPI 三用例实际通过；CLI 端口四用例通过。Windows 默认系统 TEMP 拒绝访问时，使用以上工作区内独立 TEMP/TMP。

CLI `serve --port` 仅监听 127.0.0.1，范围 1–65535，省略仍为 8000。Playwright 两个 webServer 均禁止复用已存在服务，后端命令显式使用测试端口；测试目录库来自 repository-setup，独立验收另有复制模型/临时库/自有 PID 生命周期夹具。探针自行选空闲端口，检查就绪、回收、默认 8000 可达性不变；不按端口批量杀进程。

恢复基线：`.cache/redesign-baseline-20261019-0200/manifest.json` 记录 1049 个文件 SHA-256、三个源码/规划 ZIP、Git HEAD、工作区差异与索引差异。先解压到单独目录核验，再选择恢复，避免覆盖后续修改。该目录为本机恢复资产，不纳入交付。

浏览器两个套件分别写 `frontend/test-results/default` 与 `frontend/test-results/acceptance`，避免并行时互相清理 trace。验收的服务重启用例会短暂出现代理 ECONNREFUSED，这是预期故障阶段；以重启后同批次恢复和批次数不增加的断言判断结果。Node 的 NO_COLOR/FORCE_COLOR 提示只影响日志颜色。

本轮逐项执行以上验证，没有执行包含干净安装与独立 reproduction 比较的完整 `frontend/scripts/verify.ps1`，不将其称为已通过。运行记录在 `.cache/redesign-validation/`，浏览器 JSON、截图在 `docs/evidence/_run/`；都是未冻结的本次运行输出。`verify_workspace_delivery.py` 依赖这台机器保存的基线与 `spec-sync.json`，独立克隆需先建立自己的基线，不能直接照搬本次记录。
