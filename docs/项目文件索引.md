# 项目文件索引

用 **Ctrl+F** 搜索文件名。第一次接触项目，可以先读[项目代码导读](项目代码导读.md)，按一次分支分析找出页面、API、后台任务和模型怎样协作。

以 2026-11-20 的 Git 文件清单为基准。下方逐项列出应用源码、测试、主要配置、SQL 迁移和现行规格。实验素材、数据集版本和规格归档可按批次或主题查找。索引注明了工作区里尚未提交的新前端入口。

## 如何辨认文件类型

| 看到的形式 | 常见用途 |
| --- | --- |
| `.tsx` / `.ts` | TypeScript 文件。带 `.tsx` 的文件通常含界面标记，`.ts` 常用于请求、逻辑、类型与配置。 |
| `.py` / `.sql` | Python 后端或测试代码，以及创建或调整数据表结构的 SQL。 |
| `.test.ts(x)` / `test_*.py` / `.spec.ts` | 分别常见于前端测试、后端测试、Playwright 浏览器验收。OpenSpec 使用 Markdown 规格文件。 |
| `.json` / `.csv` / `.jsonl` | 结构化数据。可能是配置、测试样例、数据集描述、逐提交样本或实验报告，结合目录辨认。 |
| `.zip.sha256` | 配套 ZIP 的完整性校验摘要。 |
| `.md` / `.yaml` | Markdown 通常供人阅读。YAML 在此仓库中常作为 CI、OpenSpec 或 API 契约的配置格式。 |

| `frontend/dist/` | 前端打包后的网页文件。生成入口是 `npm run build`。 |
| `backend/storage/` | 本机 SQLite 库及其运行文件或备份。代码里的 `backend/jit_baseline/storage/` 是操作数据库的 Python 和 SQL。 |
| `backend/artifacts/` | 本机模型、训练运行和报告。目录中的 `external/README.md` 是随 Git 交付的放置说明。 |
| `backend/.cache/`、`frontend/.cache/`、`temp/`、`.dsh-tmp/` | 缓存或临时工作目录，具体内容取决于本机运行过的命令。 |
| `frontend/test-results/`、`docs/evidence/_run/` | 浏览器测试截图、日志或临时证据。 |

如果只有一个文件名，可以先在编辑器搜索。PowerShell 里也可以在仓库根目录查已跟踪的同名文件。将 `文件名` 换成想查的内容即可。

```powershell
git -c core.quotepath=false ls-files | Select-String -SimpleMatch '文件名'
```
