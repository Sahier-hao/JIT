# 界面设计规范

本文件是前端外观的施工标准。颜色与主题仍只由 `frontend/src/styles/tokens.css` 定义；本规范说明如何取用这些令牌、各层级用什么档位，以及哪些样式位置允许存在。

## 1. 样式的允许位置

迁移完成后，`frontend/src` 下只允许四个样式表：

| 文件 | 职责 |
|---|---|
| `src/index.css` | 导入顺序、`@theme inline` 令牌映射 |
| `src/styles/tokens.css` | 四套主题与密度令牌 |
| `src/styles/base.css` | 字体、文档底色、滚动条、减少动效等无法用工具类表达的规则 |
| `src/styles/content.css` | Markdown、代码差异等第三方内容的容器内规则 |

页面与组件用 Tailwind 工具类和 `src/ui` 共享组件表达外观，不新增页面级 CSS。`npm run check:styles` 会检查这一边界；`npm test` 中的守卫用例执行同一逻辑。

## 2. 取色

只用语义名，不写色值，也不用 Tailwind 默认调色板（`red-500`、`gray-100` 之类）。

| 用途 | 工具类 |
|---|---|
| 页面底 / 卡片 / 下沉区 | `bg-background`、`bg-card`、`bg-sunken` |
| 强调面 | `bg-soft`、`bg-strong` |
| 正文 / 次要 / 元信息 / 弱化 | `text-foreground`、`text-foreground-2`、`text-foreground-3`、`text-foreground-4` |
| 分隔线 | `border-border`、`border-border-soft`、`border-border-strong` |
| 主操作 | `bg-primary text-primary-foreground` |
| 强调（选中、链接、焦点） | `text-accent`、`bg-accent-soft`、`ring-ring` |
| 状态 | `text-rose` / `bg-rose-soft`（危险）、`amber`（警告）、`teal`（成功）、`violet`（信息）、`blue`（主色族） |
| 风险色阶 | `risk`、`risk-mid`、`risk-high`、`risk-strong`、`risk-track`、`risk-soft` |
| 代码与终端面 | `bg-dark`、`bg-dark-elevated`、`text-on-dark` |
| 图表 | `chart-obs`、`chart-est`、`chart-bar`、`chart-hatch` |

状态色必须同时带文字或图标含义，不得只靠颜色区分。风险色阶与状态色不得互相冒充。

## 3. 字号与行高

| 令牌 | 值 | 用途 |
|---|---|---|
| `text-2xs` | 11px | 仅等宽标识、刻度、计数 |
| `text-xs` | 12px | 元信息、表头、标签、帮助 |
| `text-sm` | 13px | 表格正文、紧凑列表、按钮 |
| `text-base` | 14px | 正文、连续中文、主要操作 |
| `text-lg` | 16px | 区块标题 |
| `text-xl` | 20px | 页面标题 |
| `text-2xl` | 24px | 入口页标题、品牌区 |
| `text-3xl` | 28px | 仅落地页主标题 |

连续中文不小于 14px，中文元信息不小于 12px。行高用 `leading-body`（1.6）、`leading-title`（1.3）、`leading-tight`（1.2）。等宽 `font-mono` 只用于标识、数字、刻度与代码；日期与中文句子使用 `font-sans`。

## 4. 间距与密度

间距以 4px 为基数。页面、区块、卡片与表格单元使用密度工具类，不写固定像素：

| 工具类 | 舒适 | 紧凑 |
|---|---|---|
| `h-row` | 40px | 32px |
| `px-cell-x` / `py-cell-y` | 12 / 10px | 12 / 6px |
| `p-card` | 16px | 12px |
| `gap-section` | 24px | 16px |
| `px-page-x` | 24px | 24px |

窄屏页面内边距改用 `px-page-x-narrow`（16px）。密度切换只改这些变量，不改字号与颜色。

## 5. 圆角与阴影

| 工具类 | 值 | 用途 |
|---|---|---|
| `rounded-sm` | 6px | 按钮、输入、标签 |
| `rounded-md` | 8px | 卡片、表格容器 |
| `rounded-lg` | 12px | 对话框、浮层 |
| `rounded-xl` | 16px | 大面板 |
| `rounded-2xl` | 20px | 入口页容器 |

阴影只用 `shadow-1`（贴地）、`shadow-2`（浮层）、`shadow-3`（对话框）。卡片默认用 `border-border-soft` 分隔，不靠投影。

## 6. 表面与层级

页面由「页面底 → 下沉区 → 卡片 → 强调面」四层构成：`background` 承载页面，`sunken` 承载分组与表头，`card` 承载内容块，`soft` 表示选中或提示面。同一层级在不同页面必须取同一令牌。

## 7. 焦点、悬停与动效

- 焦点：`focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-accent`。
- 悬停：只改底色（`hover:bg-hover`）或文字色，不改尺寸、边框宽度与位置。
- 选中：形状或底色标记加 `aria-current` / `aria-selected`，不能只改字重。
- 动效：只在状态切换时使用短过渡；`prefers-reduced-motion` 下全部关闭。

## 8. 表格、卡片与对话框

- 表格：表头 `text-xs text-foreground-3`，行高 `h-row`，单元 `px-cell-x py-cell-y`，分隔线 `border-border-soft`；数字右对齐并使用 `tabular-nums`。
- 卡片：`rounded-md border border-border-soft bg-card p-card`；标题区与动作区分开，标题用 `text-lg`。
- 对话框：标题、正文、底部操作区三段结构一致；关闭后焦点回到触发元素。
- 空状态：一句说明加一个可执行动作，不堆说明性小字。

## 9. 组件来源

控件、表格、卡片、对话框、菜单、浮层与反馈统一来自 `frontend/src/ui`。新增组件先查现有清单，再按 Radix 行为层 + CVA 变体 + `cn` 合并的方式扩展；页面只用组件与工具类组合，不复制组件内部形状。

## 10. preflight 的启用时机

旧页面样式层删除完成前不启用 Tailwind preflight，避免列表、表单与 SVG 的默认呈现提前改变。收尾批次启用时，`base.css` 只保留 preflight 未覆盖的规则，并逐页核对 1280×720、1440×900 与 768px。

## 11. 检查命令

```bash
cd frontend
npm run check:styles
npm run typecheck
npm run lint
npm test
npm run build
```
