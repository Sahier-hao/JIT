# 入口与端点分层清单（2026-11-19）

本清单把用户可见入口与后端端点按四层归类，并标出仍保留的兼容别名、依赖与退役条件。
新增页面前先在[界面入口清单](../界面入口清单.md)登记；本清单只描述现有边界，不改变 URL 或契约。

## 1. 核心项目与 PR 审查

### 页面入口

| 入口 | 地址 | 说明 |
| --- | --- | --- |
| 项目列表 | `#/projects` | 规范入口；`#/repositories` 兼容 |
| 新建项目 | `#/projects/new` | `#/connect`、`#/sources` 兼容 |
| 项目概览 | `#/projects/{id}`、`#/projects/{id}/overview` | — |
| 项目分析 | `#/projects/{id}/analyses` | 分析结果与风险趋势 |
| 分支趋势 | `#/projects/{id}/trends[/{viewId}]` | 固定视图地址；并入分析页 |
| 提交明细 | `#/projects/{id}/analyses/{syncId}/commits[/{commitId}]` | `/plan` 兼容同一份明细 |
| 分析对比 | `#/projects/{id}/compare/{baseSyncId}/{targetSyncId}` | — |
| 我的审查 | `#/reviews` | 跨项目个人工作单 |
| PR 清单 | `#/projects/{id}/prs` | — |
| PR 工作单 | `#/projects/{id}/prs/{owner}/{repo}/{number}`、`#/reviews/{owner}/{repo}/{number}` | 固定快照参数 `snapshotId`、只读参数 `mode=preview` |
| 站内提醒 | `#/notifications` | 浏览器已读状态 |
| 固定报告 | `#/admin/reports[/{runId}/{view}]` | 历史验证报告，服务端要求管理员会话 |

### 后端端点（前缀）

- `/api/v1/repositories/*`：项目、概览、同步、提交、解释、数据来源、趋势、PR 跟踪、批次。
- `/api/v1/repository-syncs/*`：分析任务创建、取消、删除与提交明细分页。
- `/api/v1/pull-requests` 相关：`/api/v1/pr-snapshots/*`、`/api/v1/pr-sources/*`、`/api/v1/review-sources`。
- `/api/v1/project-events`、`/api/v1/repository-models`。
- `/api/review-batch`：批量分析兼容入口，仍被离线脚本与回归依赖。

## 2. 用户自助建模

- 共享数据只来自管理员显式开放的版本；用户自有版本禁止共享。

## 兼容别名与退役条件

| 别名 | 替代 | 依赖 | 退役条件 |
| --- | --- | --- | --- |
| `#/welcome` | `#/` | 无测试依赖 | 下一次路由重构时删除 |
| `#/repositories/*` | `#/projects/*` | `workspaceRoutes.test.ts` | 书签迁移完成后 |
| `#/connect`、`#/sources` | `#/projects/new` | 路由测试 | 书签迁移完成后 |
| `#/projects/{id}/analyses/{syncId}/plan` | 同路径 `/commits` | 路由测试、旧书签 | 旧工作单导出功能退役后 |
| `#/legacy/sync/{syncId}/{view}` | 分析地址 | 路由测试、旧事件链接 | 旧事件清理后 |
| `#/lab/history/...`、`#/reports/...` | 管理员报告 | 路由测试、历史证据 | 历史证据只读期结束后 |
| `#/validation`、`#/trends` | `#/admin/reports` | 路由测试 | 旧书签迁移完成后 |
| `#/models`、`#/predict`、`#/predictions/*`、`#/lab/*`、`#/settings/*`、`#/shortlist` | 无（已退役） | 路由测试只验证“已移除”提示 | 永久保留提示，不恢复功能 |
| `/api/review-batch` | `/api/v1/repositories/{id}/pull-requests/analyze` | 离线脚本、回归 | 离线脚本迁移后 |
| `/api/v1/commits`、`/api/v1/feature-schemas/*` | 项目内提交与模型卡端点 | CLI、扩展、回归 | 外部消费方迁移后 |
| `/api/v1/predictions`、`/api/v1/prediction-batches/*` | 项目分析与模型卡 | 回归、旧接口契约 | 旧接口契约退役后 |

原则：兼容别名保留到替代入口稳定并完成书签迁移；删除前必须同时满足“零代码引用、零测试依赖、零规格要求”。本阶段没有删除仍被测试或规格依赖的入口。

## 分层约束

- 项目（`/api/v1/repositories/*`）继续按本机共享设计，不做多租户隔离。
- 用户工作区与管理工作区的权限边界由服务端强制，界面隐藏不作为权限。
- 模型身份在请求、任务、重试和结果中显式传递，不静默替换。
