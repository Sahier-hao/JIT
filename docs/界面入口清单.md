# 界面入口清单

新增页面或入口前，先在这张表里登记。规则：

- 同一对象只有一个**规范入口**；其他入口必须带上下文（来源、模式、固定版本）并在文案中说明后果。
- 会改变全局状态、写入个人草稿或跨工作区的动作，可见文案必须说明后果；不得只放在悬浮提示或可访问名里。
- 只读、历史、固定版本与管理区模式必须有可见标识。
- 同一屏不出现两个看起来相同、后果不同的按钮。

| 对象 | 规范入口 | 其他入口 | 模式标识 |
| --- | --- | --- | --- |
| 项目 | 项目列表卡片「打开项目」 | 侧栏最近项目 | 无 |
| 发起分析 | 项目页头「发起分析」 | 失败记录的「用这些参数重试」 | 对话框草稿保留 |
| 分析记录 | 左侧「分析记录」整行点击切换当前结果 | 操作菜单「设为当前结果」 | 当前结果图钉；切换后状态提示 |
| 当前结果 | 分析页「当前分析结果」 | 无 | 固定旧结果时标「历史固定结果」 |
| 分支分析明细 | 「查看提交明细」/记录「打开结果」 | 趋势下钻、项目事件 | 固定分析地址 |
| 构建数据集 | 项目页头「构建数据集」 | 无 | 完成后标注需要管理员会话 |
| PR 清单 | 项目 PR 审查左侧完整列表 | 右侧「待处理 PR」子集 | 待处理子集只含分析中、失败、尚无分析 |
| PR 只读详情 | PR 清单「查看 PR」 | 工作单「查看只读版本」（`mode=preview`） | 「只读预览」 |
| PR 工作单 | 只读详情的「创建审查工作单」 | 「我的审查」打开已有工作单 | 「个人工作单」 |
| 固定快照 | 站内提醒 / 旧 PR 记录 | 无 | 「固定快照」 |
| 模型卡 | 发起分析中的现成模型旁 | 管理端模型详情 | 只读；不提供启停 |
| 训练任务 | 管理区「训练任务」 | 数据集详情创建 | 成功后链接实验登记与模型 |
| 登记模型 | 实验运行页「登记实验运行」 | 模型管理页「登记本机产物」 | 文案区分来源 |
| 风险趋势 | 分析页「风险趋势」 | 固定视图地址 | 固定视图 ID；旧地址保留 |
