# 训练与模型评估工作流

## 时间切分

- 默认仍为 `temporal-70-15-15`，既有预设保持不变。
- 用户可提交训练、验证、测试三个整数百分比，必须都大于 0 且合计 100。
- 服务端把自定义策略规范化成 `temporal-custom-<train>-<validation>-<test>`，并保存实际比例、时间边界、分区计数和成员摘要。
- 切分按 UTC 去重时间组执行，同一时间组不会跨分区；比例是目标值，实际样本数受时间组大小影响，以预览和任务保存的实际计数为准。

## 失败原因

- 比例不是三个正整数、合计不为 100，或与预设同时提交时，返回 `SPLIT_POLICY_INVALID`。
- 任一分区为空，或训练、验证、测试任一分区缺少正例或负例时，不创建训练任务，并返回各分区样本数与正例数。
- 训练产物成员摘要与预览成员摘要不一致时，以 `SPLIT_MEMBER_MISMATCH` 失败，且不发布模型。
